# 🤖 RealClaudian AI 助手

> 在 Obsidian 中集成 AI 能力，辅助学习和写作

---

## 📋 插件简介

| 项目 | 说明 |
|------|------|
| **插件名** | RealClaudian |
| **功能** | AI 辅助写作、内容生成、知识问答 |
| **适用场景** | 笔记生成、问题解答、内容优化 |

---

## ⚙️ 基础配置

### 1. 获取 API 密钥

1. 访问 [Anthropic Console](https://console.anthropic.com/)
2. 注册账号并获取 API Key
3. 复制密钥备用

### 2. 配置插件

1. 打开 Obsidian 设置
2. 进入 **RealClaudian** 选项
3. 填入 API Key
4. 选择模型（推荐 Claude 3.5 Sonnet）

### 3. 推荐设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| Model | Claude 3.5 Sonnet | 平衡性能和成本 |
| Max tokens | 4096 | 最大生成长度 |
| Temperature | 0.7 | 创造性（0-1） |
| System prompt | 自定义 | 系统提示词 |

---

## 🎯 基础使用

### 1. 命令面板调用

`Ctrl/Cmd + P` 输入：
- `RealClaudian: Ask AI` - 向 AI 提问
- `RealClaudian: Generate` - 生成内容
- `RealClaudian: Explain` - 解释选中文本
- `RealClaudian: Summarize` - 总结选中文本

### 2. 选中文本操作

1. 选中笔记中的文本
2. 右键选择 RealClaudian 选项
3. 选择操作类型

### 3. 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Shift + A` | 打开 AI 面板 |
| `Ctrl/Cmd + Shift + G` | 生成内容 |
| `Ctrl/Cmd + Shift + E` | 解释选中文本 |

## 📊 考研应用场景

### 1. 知识点解释

**操作**：选中难懂的概念，使用 `Explain` 功能

**示例**：
- 选中："拉格朗日中值定理"
- AI 输出：
  > 拉格朗日中值定理是微积分基本定理之一，表述为：如果函数 f(x) 在闭区间 [a,b] 上连续，在开区间 (a,b) 上可导，那么至少存在一点 ξ ∈ (a,b)，使得 f'(ξ) = (f(b)-f(a))/(b-a)...

### 2. 错题分析

**操作**：将错题内容发送给 AI，请求分析

**示例提示词**：
```
请分析这道错题：
题目：...
我的答案：...
正确答案：...

请帮我：
1. 分析错误原因
2. 解释正确解法
3. 总结相关知识点
```

### 3. 生成学习笔记

**操作**：提供大纲，让 AI 扩展成完整笔记

**示例提示词**：
```
请根据以下大纲生成详细的学习笔记：

主题：高等数学 - 极限
要点：
1. 极限的定义
2. 极限的性质
3. 极限的计算方法
4. 常见极限公式

要求：
- 使用 Markdown 格式
- 包含公式和例子
- 添加记忆技巧
```

### 4. 生成练习题

**操作**：让 AI 根据知识点生成练习题

**示例提示词**：
```
请为"数据结构 - 二叉树遍历"生成5道练习题，包括：
- 2道选择题
- 2道填空题
- 1道编程题

请附上答案和解析。
```

## 🔧 高级功能

### 1. 自定义系统提示词

在设置中添加系统提示词，让 AI 更符合考研需求：

```
你是一个考研辅导助手，专注于清华大学 IMDT（843）考试。请用简洁明了的中文回答问题，必要时使用 Markdown 格式和公式。回答要准确、专业，适合考研学生理解。
```

### 2. 模板化提问

创建常用提问模板：

```markdown
## 错题分析模板

请分析以下错题：

**题目**：{{题目内容}}

**我的答案**：{{我的答案}}

**正确答案**：{{正确答案}}

请从以下角度分析：
1. 错误类型（计算错误/概念混淆/粗心大意/知识盲区）
2. 正确解题思路
3. 相关知识点总结
4. 类似题目练习建议
```

### 3. 批量处理

1. 选中多个段落
2. 使用 RealClaudian 批量处理
3. 选择操作类型（总结、翻译、解释等）

## 📝 提问技巧

### 1. 明确指令

❌ "帮我看看这个"
✅ "请用简洁的语言解释这个概念，并给出一个例子"

### 2. 提供上下文

❌ "这道题怎么做"
✅ "这是2023年843真题的第3题，关于数据结构的二叉树遍历，请帮我分析解题思路"

### 3. 指定格式

❌ "总结一下"
✅ "请用 bullet points 总结以下内容的要点，每个要点不超过20字"

### 4. 分步骤提问

```
第一步：请解释什么是动态规划
第二步：动态规划适用什么场景
第三步：请给出一个动态规划的例子
```

## 💰 成本控制

### 1. 减少 Token 消耗

- 精简提问内容
- 避免重复上下文
- 使用更小的模型（如 Claude 3 Haiku）

### 2. 设置预算

在 API 控制台设置使用限额

### 3. 缓存结果

将 AI 生成的内容保存到笔记，避免重复生成

---

## ⚠️ 注意事项

### 1. 内容审核

- AI 生成的内容需要人工审核
- 特别是公式和数据，要验证准确性
- 不要完全依赖 AI

### 2. 隐私安全

- 不要发送敏感信息
- API Key 不要分享给他人
- 注意使用环境的安全性

### 3. 合理使用

- AI 是辅助工具，不是替代品
- 保持独立思考能力
- 用于理解难点，而非直接抄答案
