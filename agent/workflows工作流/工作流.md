## 每日流程

```
┌──────────────────────────────────────────────────────┐
│                    每日学习流程                        │
└──────────────────────────────────────────────────────┘
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
    ┌───────┐         ┌───────┐         ┌───────┐
    │ 晨间   │         │ 学习  │         │  晚间  │
    │ 计划   │         │ 执行  │         │  复盘  │
    └───────┘         └───────┘         └───────┘
        │                 │                 │
        ▼                 ▼                 ▼
  daily-record.md     note.md          daily-record.md
  (填写计划)           error.md         (填写复盘)
```

### 步骤说明

1. **晨间**（8:00）
   - 创建/打开今日记录 `daily-record.md`
   - 填写今日计划和学习安排

2. **学习中**
   - 学习新内容 → 使用 `note.md` 记录笔记
   - 做错题目 → 使用 `error.md` 记录错题
   - 提炼知识 → 使用 `knowledge.md` 记录知识卡片

3. **晚间**（22:00）
   - 回到 `daily-record.md`
   - 填写执行记录
   - 完成今日复盘

## 每周流程

```
┌──────────────────────────────────────────────────────┐
│                    每周复盘流程                        │
└──────────────────────────────────────────────────────┘
                          │
                          ▼
                    ┌───────────┐
                    │  周日晚    │
                    │  复盘总结  │
                    └───────────┘
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
  ┌───────────┐     ┌───────────┐     ┌──────────┐
  │ 统计本周   │      │ 分析薄弱   │     │ 规划下周  │
  │ 学习数据   │      │ 环节      │     │ 计划      │
  └───────────┘     └───────────┘     └──────────┘
```

### 步骤说明

1. **周日 · 先拉日程**（前置，先做这步）

   ```bash
   cd agent/tools工具
   ./读取日历.sh upcoming 14   # 下周课程、假期、补课
   ./读取日历.sh free          # 每周空闲时段（含隔周课程的实验周/无实验周）
   ```

   用途：用**真实课表**核对周记录里的「日程协同与时段分配策略」表，替代手工抄写。
   工具说明见 [[agent/tools工具/README|读取日历工具]]。

   注意：这一步依赖 DSH 的 `danger-full-access` 策略；`workspace-write` 下会被沙箱拦截。

2. **周日 · 复盘**
   - 打开 `weekly-record.md`
   - 填写本周学习统计
   - 总结本周成就和薄弱环节

3. **规划下周**
   - **按空闲时段排，不按每周一样的强度排**：课多的一周目标调低，空闲多的一周调高
   - 填写下周计划
   - 确定重点任务

> 空闲时间多不等于会去学（9 月 W39 已证明：存在空闲时段仍零执行）。日历只作排程依据，不构成时长承诺。

## 每月流程

### 步骤说明

1. **月末**
   - 打开 `monthly-record.md`
   - 填写本月各科完成情况
   - 统计学习时长
   - 分析问题和经验教训

2. **月初 · 先核课业负担**

   ```bash
   cd agent/tools工具
   ./读取日历.sh timetable   # 本学期固定课表、各课程起止与次数
   ```

   用途：把下月的课业负担（假期、满课周、补课、隔周实验）写进月度记录的「课业负担与空闲时段」一节，再据此分配各周目标。

3. **月初 · 排下月计划**
   - 填写下月计划
   - 设定重点目标
   - 调整时间分配

## 文档架构原则

### 高内聚、低耦合

**AGENTS.md 的定位**：AI 了解项目的窗口，只做索引和概览。

**职责分离**：

| 文档 | 职责 | 内容 |
|------|------|------|
| `AGENTS.md` | 窗口 | 项目概览、目录结构、索引链接 |
| `agent/rules规范/标签规范文档.md` | 核心规范 | 标签格式、属性规范 |
| `agent/rules规范/` | 规范文档 | Git规范、变更管理 |
| `agent/ref参考/` | 参考文档 | 标签速查、模板清单、常用查询、经验教训 |
| `agent/workflows工作流/` | 流程文档 | 学习工作流、学习记录自动化 |
| `agent/tools工具/` | 工具脚本 | 日历读取等 |
| `agent/plugins-guide插件使用指导/` | 插件指南 | 各插件使用说明 |
| `agent/log工作日志/` | 工作日志 | Agent 操作记录 |

### 设计原则

1. **单一职责**：每个文档只负责一个主题
2. **依赖单向**：AGENTS.md → 规范文档 → 参考文档
3. **易于维护**：修改一处不影响其他地方
4. **AI 友好**：AGENTS.md 轻量，AI 快速理解项目

## 语音转文字整理流程

> 将听课录音的语音转文字文稿，整理为结构化的 Obsidian 笔记

### 流程

```
语音转文字文稿 → 分析内容模块 → 创建文件夹 → 拆分主题笔记 → 格式化 → 补充查证
```

### 步骤说明

1. **分析内容模块**
   - 通读全文，识别不同的知识主题
   - 每个主题对应一篇独立笔记

2. **创建文件夹**
   - 路径：`02-Notes笔记/04-专业课/主题名/`
   - 与 843 知识清单平级

3. **拆分主题笔记**
   - 每篇笔记 frontmatter：`tags: [note笔记, ds数据结构, AI-generated人工智能生成]`
   - status 默认 `待复习`
   - 笔记间用 `[[wikilink]]` 互相关联

4. **格式化**
   - 口语化内容 → 结构化知识点（表格、列表）
   - 数学公式用 LaTeX（`$...$` / `$$...$$`）
   - 关键概念用表格整理
   - 用 Callout 标记重点：`[!tip]`、`[!warning]`、`[!info]`、`[!example]`

5. **补充查证**
   - 搜索验证关键事实（年份、人名、数据）
   - 修正转文字中的错误（如 "埃bm" → "IBM"）
   - 补充遗漏的技术细节

6. **保留原始文件**
   - 原始转文字文件保留不动，作为备份

### 注意事项

- 语音转文字会有错别字和口语化表达，需人工修正
- 数学公式通常无法正确转录，需要手动用 LaTeX 重写
- 代码示例通常需要从头整理
- 每篇笔记控制在合理长度，过长则拆分

## 错题整理流程

> 将做错的题目，整理为结构化的 Obsidian 笔记

### 流程

```
截图发给我 → 我识别+填写模板 → 你确认 → 存档到对应科目文件夹
```

### 步骤说明

1. **截图发送**
   - 做错一道题，截图发给我
   - 我会自动识别题目内容

2. **模板填写**（我负责）
   - 识别题目、错误答案、正确答案
   - 判断错误类型（计算错误/概念混淆/粗心大意/知识盲区/审题不清）
   - 分析错误原因、正确思路、知识点总结

3. **确认存档**
   - 你确认内容无误后，存档到对应文件夹

### 文件夹结构

```
04-Errors错题/
├── 01-政治/
├── 02-英语/
├── 03-数学/
└── 04-843专业课/
```

### 复习机制

| 科目 | 复习方式 |
|------|----------|
| 数学 | 重做原题（间隔重复） |
| 英语 | 背单词/理解语法 |
| 843 | 理解知识点，关联知识清单 |
| 政治 | 看解析确认理解 |

### 注意事项

- 截图识别不是100%准确，需要你确认
- 每道错题整理约2-3分钟
- 843专业课错题可关联到843知识清单
- 复习时重点关注错误类型为“知识盲区”的题目
