# 📋 Obsidian Kanban 看板视图

> 使用看板管理任务、追踪进度，可视化学习计划

---

## 📋 插件简介

| 项目 | 说明 |
|------|------|
| **插件名** | Obsidian Kanban |
| **功能** | 看板视图，拖拽式任务管理 |
| **适用场景** | 任务管理、项目追踪、学习计划 |

---

## ⚙️ 基础配置

### 1. 创建看板

**方法一：命令面板**
1. `Ctrl/Cmd + P` 打开命令面板
2. 输入 `Kanban: Create new board`
3. 输入看板名称

**方法二：手动创建**
1. 新建笔记
2. 在 Frontmatter 中添加 `kanban: true`

### 2. 推荐设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| Lane width | 300 | 列宽度 |
| Link to date | ✅ 启用 | 关联日期 |
| Date format | `YYYY-MM-DD` | 日期格式 |
| Hide tags in card titles | ❌ 禁用 | 显示标签 |

## 🎯 基础语法

### 1. 看板结构

```markdown
---
kanban: true
---

## 待办事项

- [ ] 任务1
- [ ] 任务2
- [ ] 任务3

## 进行中

- [ ] 正在做的任务

## 已完成

- [x] 完成的任务
```

### 2. 卡片属性

```markdown
- [ ] 任务标题
    **截止日期**：2025-08-25
    **优先级**：高
    **科目**：数学
```

### 3. 标签支持

```markdown
- [ ] 学习高等数学 #math #urgent
- [ ] 复习数据结构 #ds
```

## 🔧 高级功能

### 1. 关联日期

```markdown
- [ ] 数学期中复习
    **截止**：2025-09-15
```

- 日期会显示在卡片上
- 可以按日期排序
- 过期任务会高亮显示

### 2. 归档功能

- 点击卡片右上角的 `...`
- 选择 **Archive**
- 已归档卡片会移到单独区域

### 3. 拖拽排序

- 直接拖拽卡片调整顺序
- 拖拽到不同列改变状态
- 支持跨列拖拽

## ⚠️ 常见问题

### 1. 看板不显示

- 确认 Frontmatter 中有 `kanban: true`
- 检查格式是否正确（使用 `- [ ]`）
- 尝试切换到阅读模式

### 2. 无法拖拽

- 确认在阅读模式下操作
- 检查插件是否启用
- 尝试刷新页面

### 3. 日期不识别

- 使用 `YYYY-MM-DD` 格式
- 确认日期设置正确
- 检查 Link to date 是否启用
