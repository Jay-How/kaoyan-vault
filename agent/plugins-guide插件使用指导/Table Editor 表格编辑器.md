# 📊 Table Editor 表格编辑器

> 可视化编辑 Markdown 表格，告别手动对齐

---

## 📋 插件简介

| 项目 | 说明 |
|------|------|
| **插件名** | Advanced Tables |
| **功能** | 可视化表格编辑、自动对齐、公式支持 |
| **适用场景** | 数据整理、对比分析、计划表格 |

---

## ⚙️ 基础配置

### 1. 启用插件

1. 打开 Obsidian 设置
2. 进入 **Community plugins**
3. 确认 **Table Editor** 已启用

### 2. 推荐设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| Auto align | ✅ 启用 | 自动对齐 |
| Padding | 1 | 单元格内边距 |
| Move to next row on Tab | ✅ 启用 | Tab 跳转下一行 |

---

## 🎯 基础使用

### 1. 创建表格

**快捷键**：`Ctrl/Cmd + Shift + T`

**或手动输入**：
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

### 2. 表格导航

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 跳到下一个单元格 |
| `Shift + Tab` | 跳到上一个单元格 |
| `Enter` | 跳到下一行 |
| `↑ ↓ ← →` | 方向键导航 |

### 3. 表格操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Enter` | 在下方插入行 |
| `Ctrl/Cmd + Shift + Enter` | 在上方插入行 |
| `Ctrl/Cmd + Shift + D` | 删除当前行 |

## ⚠️ 常见问题

### 1. 表格格式错乱

- 使用 `Ctrl/Cmd + Shift + T` 重新格式化
- 检查分隔行 `|---|` 是否正确
- 确保每行的列数一致

### 2. 快捷键无效

- 确认在编辑模式下
- 检查是否有快捷键冲突
- 尝试重启 Obsidian

### 3. 中文对齐问题

- 使用等宽字体
- 调整 Padding 设置
- 手动添加空格对齐
