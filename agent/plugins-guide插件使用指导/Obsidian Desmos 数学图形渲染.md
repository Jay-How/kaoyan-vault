# 📐 Obsidian Desmos 数学图形渲染

> 在笔记中用代码块直接渲染 Desmos 数学图形，无需截图，笔记即教材

---

## 📋 插件简介

| 项目 | 说明 |
|------|------|
| **插件名** | Obsidian Desmos |
| **功能** | 在 Markdown 中用 `desmos-graph` 代码块渲染交互式数学图形 |
| **适用场景** | 函数图像、数列点列、几何示意、极限可视化 |
| **离线支持** | ✅ 支持（渲染引擎内置，无需联网） |

---

## ⚙️ 基础语法

### 代码块结构

````markdown
```desmos-graph
left=-5; right=5; top=5; bottom=-5;
width=400; height=300;
---
函数表达式
点坐标
```
````

- **`---` 分隔符**：上方是坐标系设置，下方是图形元素
- **每个元素占一行**
- **支持中文标注**（label）

---

## 📐 坐标系设置

| 参数 | 说明 | 示例 |
|------|------|------|
| `left` / `right` | x 轴范围 | `left=-5; right=5;` |
| `top` / `bottom` | y 轴范围 | `top=3; bottom=-3;` |
| `width` / `height` | 画布像素尺寸 | `width=400; height=300;` |

> [!tip] 纵横比经验
> - **纵向窄画布**（如数轴示意）：`width=420; height=210;` 或更大 height
> - **横向宽画布**（如函数图像）：`width=550; height=180;`
> - 纵横比 = `width / (right - left)` 与 `height / (top - bottom)` 应接近，否则图形会变形
> - 若 y 轴范围很小（如 ε-邻域），适当增大 height 避免图形被压扁

## 🎨 图形元素语法

### 1. 函数曲线

```
y=表达式|条件|颜色|样式
```

| 示例 | 说明 |
|------|------|
| `y=x^2\|blue` | 蓝色抛物线 |
| `y=0\|x>0\|x<11\|#808080` | 灰色坐标轴（x 在 0~11） |
| `y=1\|x>0\|x<11\|red\|dashed` | 红色虚线 |
| `y=\sin(x)` | 默认颜色的正弦曲线 |
| `x=1\|y>-0.5\|y<0.5\|blue\|dashed` | 垂直虚线（x=1） |

**条件语法**：用 `|` 分隔，支持 `x>a`、`x<b`、`y>c` 等不等式

### 2. 散点（离散点）

```
(x,y)
(x,y)|open|label:标注文字
(x,y)|label:标注文字
```

| 类型 | 示例 | 说明 |
|------|------|------|
| 实心点 | `(1, 1)` | 默认实心 |
| 空心点 | `(-1,1)\|open\|label:(-1,1)` | 空心 + 标注 |
| 带标注的点 | `(2,0)\|label:A` | 实心 + 标注 |

### 3. 常用颜色

| 名称 | 效果 |
|------|------|
| `blue` | 蓝色（默认） |
| `red` | 红色 |
| `green` | 绿色 |
| `#808080` | 灰色（常用于坐标轴/辅助线） |
| `#800080` | 紫色 |
| `orange` | 橙色 |

### 4. 样式修饰

| 修饰 | 说明 |
|------|------|
| `dashed` | 虚线（常用于辅助线、极限带） |
| `open` | 空心点（用于开区间端点） |

## 🎯 考研数学应用示例

### 示例 1：数列点列可视化（数列极限）

````markdown
```desmos-graph
left=0; right=11; top=1.8; bottom=-1.8;
width=550; height=180;
---
y=0|x>0|x<11|#808080
(1,1)
(2,0.5)
(3,0.333)
(4,0.25)
(5,0.2)
(6,0.167)
(7,0.143)
(8,0.125)
(9,0.111)
(10,0.1)
```
````

*效果：$x_n = \frac{1}{n}$ 的点列在 x 轴上方逐渐聚集，直观展示极限为 0*

### 示例 2：ε-邻域几何（极限定义）

````markdown
```desmos-graph
left=-0.8; right=4.8; top=1.4; bottom=-1.4;
width=420; height=210;
---
y=0|x>-0.8|x<4.8|#808080
(1,0)|open|label:A-ε
(2,0)|label:A
(3,0)|open|label:A+ε
x=1|y>-0.4|y<0.4|blue|dashed
x=3|y>-0.4|y<0.4|red|dashed
```
````

*效果：极限点 A 的 ε-邻域 $(A-\varepsilon, A+\varepsilon)$，蓝红虚线之间*

### 示例 3：两函数图像对比（单射判定）

````markdown
```desmos-graph
left=-2.5; right=2.5; top=3; bottom=-3;
width=283; height=340;
---
y=x^2|blue
y=x^3|red
y=1|green|dashed
(-1,1)|open|label:(-1,1)
(0,0)|open|label:(0,0)
(1,1)|open|label:(1,1)
```
````

*效果：水平线 $y=1$ 与 $y=x^2$ 有两个交点（非单射），与 $y=x^3$ 仅一个交点（单射）*

### 示例 4：唯一性证明示意

````markdown
```desmos-graph
left=-0.8; right=4.8; top=1.6; bottom=-1.6;
width=420; height=240;
---
y=0|x>-0.8|x<4.8|#808080
(1,0)|label:A
(3,0)|label:B
(2,0)|open|label:(A+B)/2
x=0|y>-0.5|y<0.5|blue|dashed
x=2|y>-0.5|y<0.5|#800080|dashed
x=4|y>-0.5|y<0.5|red|dashed
```
````

*效果：极限唯一性反证法——A 和 B 的 ε₀-邻域至多在中点处相切，不可能重叠*

## ⚠️ 注意事项

> [!warning] 常见问题
> - **图形变形**：纵横比不合理导致圆变椭圆、点列挤压。解决：调整 `width/height` 使比例协调
> - **标签重叠**：标注文字太长时可能遮挡。解决：缩短标签或调整点位置
> - **条件范围**：`|x>a|x<b` 是**交集**（同时满足），不是或
> - **空心点必须 `open`**：默认实心，需要端点为空心时必须加 `open`
> - **乘号用 `*`**：`x*x` 而非 `x²` 或 `xx`；幂用 `^`：`x^2`
> - **反斜杠转义**：`|` 在代码块内不需要转义（与 Markdown 表格不同）

> [!tip] 写作建议
> - **先画草图再写代码**：确定坐标范围和关键点后，再填代码块
> - **图下加说明**：每张图下方用斜体写一行说明文字，解释图中元素含义
> - **辅助线用灰色虚线**：坐标轴、极限线、ε-带边界等用 `#808080|dashed`
> - **关键点用亮色实线**：函数曲线用 blue/red，点用默认实心或 open
