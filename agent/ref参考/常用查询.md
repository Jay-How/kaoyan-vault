# 📊 常用 Dataview 查询

## 📚 学习进度统计

### 各科目笔记数量

```dataview
TABLE length(rows) AS "笔记数"
FROM #note笔记
GROUP BY subject
SORT length(rows) DESC
```

### 待复习内容

```dataview
TABLE file.name, subject, priority
WHERE status = "待复习"
SORT priority DESC
```

## ❌ 错题统计

### 未掌握错题

```dataview
TABLE file.name, subject, error-type
FROM #error错题
WHERE status != "已掌握"
SORT subject ASC
```

### 各科目错题数量

```dataview
TABLE length(rows) AS "错题数"
FROM #error错题
GROUP BY subject
SORT length(rows) DESC
```

## 📅 记录统计

### 本周学习记录

```dataview
TABLE file.name, weekday
FROM #record记录 AND #daily每日
WHERE created >= date(today) - dur(7 days)
SORT created DESC
```

### 月度学习统计

```dataview
TABLE length(rows) AS "记录数"
FROM #record记录 AND #daily每日
WHERE created >= date(today) - dur(30 days)
GROUP BY dateformat(created, "yyyy-MM")
```
