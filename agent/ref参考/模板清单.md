## 🔧 模板使用方式

### 手动插入（Templater）

1. `Ctrl/Cmd + P` 打开命令面板
2. 输入 `Templater`
3. 选择模板
4. 弹窗输入信息

### 自动创建（Periodic Notes）

1. 点击左侧边栏日历图标
2. 点击日期
3. 自动创建记录文件
