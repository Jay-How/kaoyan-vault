# 🔄 学习工作流

## 📅 每日流程

```
┌─────────────────────────────────────────────────────────┐
│                    每日学习流程                          │
└─────────────────────────────────────────────────────────┘
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
    ┌───────┐         ┌───────┐         ┌───────┐
    │ 晨间  │         │ 学习  │         │ 晚间  │
    │ 计划  │         │ 执行  │         │ 复盘  │
    └───────┘         └───────┘         └───────┘
        │                 │                 │
        ▼                 ▼                 ▼
  daily-record.md    note.md          daily-record.md
  (填写计划)         error.md         (填写复盘)
```

### 步骤说明

1. **晨间**（8:00）
   - 创建/打开今日记录 `daily-record.md`
   - 填写今日计划和学习安排

2. **学习中**
   - 学习新内容 → 使用 `note.md` 记录笔记
   - 做错题目 → 使用 `error.md` 记录错题
   - 提炼知识 → 使用 `knowledge.md` 记录知识卡片

3. **晚间**（22:00）
   - 回到 `daily-record.md`
   - 填写执行记录
   - 完成今日复盘

## 📝 笔记创建流程

```

   ↓
2. 使用对应模板创建
   ↓
3. 填写标签和属性
   ↓
4. 记录学习内容
   ↓

```

   ↓

   ↓
3. 分析错误原因
   ↓

   ↓

## 🏗️ 文档架构原则

### 高内聚、低耦合

**agent.md 的定位**：AI 了解项目的窗口，只做索引和概览。

**职责分离**：

| 文档 | 职责 | 内容 |
|------|------|------|
| `agent.md` | 窗口 | 项目概览、目录结构、索引链接 |
| `agent/标签规范文档.md` | 核心规范 | 标签格式、属性规范 |
| `agent/rules规范/` | 规范文档 | Git规范、变更管理 |
| `agent/ref参考/` | 参考文档 | 标签速查、模板清单、常用查询、工作流 |
| `agent/plugins-guide/` | 插件指南 | 各插件使用说明 |

### 设计原则

1. **单一职责**：每个文档只负责一个主题
2. **依赖单向**：agent.md → 规范文档 → 参考文档
3. **易于维护**：修改一处不影响其他地方
4. **AI 友好**：agent.md 轻量，AI 快速理解项目
