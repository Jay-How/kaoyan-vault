# 🏷️ 标签与属性规范文档

> 本知识库的统一标签和属性管理规范，所有笔记必须遵循

---

## 📋 设计原则

| 原则 | 说明 |
|------|------|
| **职责分离** | 标签管分类，属性管状态 |
| **语义明确** | 看到标签/属性就知道是什么 |
| **易于扩展** | 未来可以添加新维度 |
| **便于查询** | 支持 Dataview 高效筛选 |
| **简洁统一** | 避免冗余和混乱 |

---

## 🎯 核心设计：标签 + 属性混合方案

### 职责划分

| 用 **标签（Tags）** 管理 | 用 **属性（Properties）** 管理 |
|-------------------------|------------------------------|
| 内容类型（note/error/knowledge） | 状态（status） |
| 科目（设计理论/数据结构） | 优先级（priority） |
| 记录周期（每日/每周） | 来源（source） |
| 真题年份、经验帖、资源 | 日期、作者等元数据 |

### 完整示例

```yaml
---
tags:
  - note/设计理论          # 标签：内容类型 + 科目
status: 进行中              # 属性：状态
priority: 高                # 属性：优先级
source: 教材                # 属性：来源
created: 2025-08-20
subject: 设计理论
chapter: 第一章
---
```

## 📊 属性：状态、优先级、来源

### 状态属性（status）

| 属性值 | 说明 | 适用场景 |
|--------|------|----------|
| `进行中` | 正在学习 | 新建笔记默认状态 |
| `待复习` | 需要复习 | 学完但未完全掌握 |
| `待回顾` | 定期回顾 | 已掌握但需定期复习 |
| `已掌握` | 完全掌握 | 可以不用再看 |
| `已归档` | 归档保存 | 不再关注 |

**状态流转**：
```
学习笔记：进行中 → 待复习 → 已掌握
错题记录：待复习 → 已掌握
知识卡片：进行中 → 待复习 → 待回顾 → 已掌握
```

### 优先级属性（priority）

| 属性值 | 说明 | 适用场景 |
|--------|------|----------|
| `高` | 高优先级 | 重点内容、高频考点、薄弱环节 |
| `中` | 中优先级 | 一般内容、常规知识点 |
| `低` | 低优先级 | 拓展内容、低频考点 |

### 来源属性（source）

| 属性值 | 说明 | 适用场景 |
|--------|------|----------|
| `真题` | 来自真题 | 真题中的知识点 |
| `教材` | 来自教材 | 课本中的内容 |
| `网课` | 来自网课 | 视频课程内容 |
| `经验帖` | 来自经验帖 | 学长分享 |
| `其他` | 其他来源 | 不明确来源 |

## 🔍 Dataview 查询示例

### 查询所有待复习的错题

```dataview
TABLE subject, error-type, source, priority
FROM #error
WHERE status = "待复习"
SORT priority DESC
```

### 查询高优先级的知识卡片

```dataview
TABLE subject, category, source, status
FROM #knowledge
WHERE priority = "高"
SORT subject ASC
```

### 查询某科目的所有内容

```dataview
TABLE file.name, tags, status, priority
FROM #note/数据结构 OR #error/数据结构 OR #knowledge/数据结构
SORT created DESC
```

### 查询今日学习记录

```dataview
TABLE file.name, status
FROM #record/每日
WHERE date = date(today)
```

### 统计各科目笔记数量

```dataview
TABLE length(rows) AS "数量"
FROM #note
GROUP BY subject
SORT length(rows) DESC
```

### 查询待复习的高优先级内容

```dataview
TABLE file.name, tags, source
WHERE status = "待复习" AND priority = "高"
SORT created DESC
```

## ⚠️ 使用规范

### ✅ 正确用法

```yaml
tags:
  - note/设计理论      # 标签：类型/科目
status: 进行中          # 属性：状态
priority: 高            # 属性：优先级
source: 教材            # 属性：来源
```

### ❌ 错误用法

```yaml
tags:
  - note/设计理论/进行中    # 错误：状态应该用属性
  - #status/进行中          # 错误：状态应该用属性
  - 设计理论                # 错误：标签缺少类型前缀
```

### 📌 注意事项

1. **标签不带 #**：Frontmatter 中写 `note/设计理论`，不是 `#note/设计理论`
2. **正文中带 #**：在笔记正文中写 `#note/设计理论`
3. **属性用冒号**：`status: 进行中`，不是 `status: "进行中"`（除非有特殊字符）
4. **小写字母**：标签统一使用小写（中文除外）
5. **无空格**：标签中不要有空格
