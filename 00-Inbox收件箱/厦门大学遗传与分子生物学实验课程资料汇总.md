## 二、课程模块与实验项目总览

课程分三个模块化实验教学，包含两个开放大实验。

### 模块一：经典遗传学研究方法（30学时）

| 序号 | 实验项目 | 备注 |
|------|----------|------|
| 1 | 果蝇的饲养和观察 | 基础实验 |
| 2 | 果蝇唾腺染色体制片观察 | 基础实验 |
| 3 | 细菌转导 | 基础实验 |
| 4 | 转座子引起的插入突变 | 基础实验 |
| 5 | **果蝇诱变开放大实验** | 贯穿模块一（3月-5月），占总成绩20% |

教学要求：掌握经典遗传学实验的研究背景和相关技术、方法，理解经典遗传规律，学会遗传分析方法。

应学习的技术：果蝇饲养方法、果蝇和细菌培养基配制、显微观察和拍照、细菌涂板和划线筛选、遗传分析技术等。

应学习的仪器：解剖镜、普通离心机、恒温培养箱、无菌操作台。

## 三、开放大实验详细信息

### 3.1 果蝇诱变开放大实验（主要的那个）

#### 基本要求

- 形式：四人一组，自由设计并合作完成
- 时间跨度：3月至5月（贯穿整个模块一）
- 考核占比：总成绩的20%
- 流程：
  - **开题阶段**（学期初）：小组代表上台介绍开放大实验的设计方案，需提交"开放式研究性实验项目设计书"
  - **实施阶段**（3-5月）：自主开展实验
  - **总结阶段**（学期末）：开放大实验总结汇报

#### 实验目的

采用物理法、化学法、生物法等多种实验手段，使果蝇发生诱发突变，通过其遗传现象找出突变的规律和特点。学会自主设计实验，培养独立思考和团队合作精神，模拟科研训练。

#### 实验材料

黑腹果蝇（Drosophila melanogaster）

#### 可选的诱变方法

**物理诱变：**

| 诱变剂 | 说明 |
|--------|------|
| X射线 | 波长1000-100埃的电离射线，最早的诱变射线 |
| 射线 | 波长更短（0.1-1埃），Co-60和Cs-137是最广泛应用的射线源 |
| 紫外线 | 操作简便，适合本科实验，但对成虫效果不明显 |
| 中子 | 不带电粒子，通过核反应产生 |
| 射线 | 由P-32和S-35等放射性同位素产生 |

物理诱变机理：X射线和射线引起物质电离，导致DNA链断裂，修复时不能恢复原状就会出现突变。如果击中染色体可能导致断裂，造成缺失、重复、倒位和易位等染色体畸变。

**化学诱变：**

| 诱变剂 | 类型 | 特点 |
|--------|------|------|
| EMS（甲基磺酸乙酯） | 烷化剂 | **最常用**，诱发突变率高，对处理材料损伤轻 |
| DES（硫酸二乙酯） | 烷化剂 | 应用较多 |
| EI（乙烯亚胺） | 烷化剂 | 应用较多 |
| NaN3（叠氮化钠） | 叠氮化物 | 诱变率高而安全，使DNA碱基发生替换 |

化学诱变机理（EMS）：烷化剂带有活性烷基，转移到电子密度较高的分子上，置换碱基中的氧原子，碱基被烷化后DNA复制时会导致配对错误，产生突变。

**化学诱变剂的处理方法（EMS为例）：**
1. 用EMS与轻质石蜡油混合，制备浓度为0.1-0.2%的EMS处理液
2. 收集果蝇（成虫或幼虫），放入处理液中
3. 处理约45分钟（浓度1-2x10^-3为宜）
4. 取出后用清水冲洗，转入正常培养基饲养
5. 观察F1代是否有突变表型

#### 可观察的突变表型

- 眼色变化：红眼->白眼（white基因）、朱砂眼（vermilion基因）等
- 翅型变化：残翅（vestigial）、卷翅（Curly）、小翅（miniature）等
- 体色变化：黑檀体（ebony）、黄体（yellow）等
- 刚毛形态变化：粗短刚毛、弯曲刚毛等
- 行为异常：求偶缺陷、运动异常等

#### 实验设计要点

- 设置对照组（未处理的野生型果蝇）
- 记录F1和F2代的表型分离比
- 注意实验的可重复性，每组需有足够的样本量
- 做好详细的实验记录，包括诱变条件、处理时间、观察数据等
- 需进行卡方检验等统计分析
- 需判断突变是显性/隐性、常染色体/性连锁

### 5.2 学生案例详情

该小组同时做了两个方向的诱变实验：

**案例A：化学诱变（泡菜液）**
- 选材：淳于府东北亚式酸白菜
- 制备：100ml无菌水+泡菜混合，榨汁机制成泡菜液
- 分组：配制5个培养基（空白、1%、5%、10%、20%浓度），每个放入3对果蝇
- 时间线：10.20取出亲本，10.27记录结果
- 结论：泡菜液未能使果蝇发生明显突变，但高浓度组果蝇生长更好
- 反思：选材有问题，泡菜浓度可能不够

**案例B：物理诱变（紫外线）**
- 预实验：18只成虫照射紫外线30分钟，均未死亡，子代无突变表型
- 改进：改用三龄幼虫进行实验
- 结果：紫外对成虫杀伤效果不明显，对幼虫杀伤效果明显，半致死量约30秒
- 后续：对10秒组的果蝇进行自由交配，观察子代是否发生隐性突变
- 意外发现：自然突变个体；雄性果蝇早于雌性发育；捉到野生"果蝇"并进行正反交鉴定

**该小组的反思总结：**
- 泡菜实验：选材有问题，实验细节需改进
- 紫外实验：取样数量太少，没有重复实验
- 收获：锻炼了设计实验、思考实验结果的能力，团队配合能力，实验操作技能

## 六、推荐实验方案

### 方案一：EMS化学诱变（最经典、最推荐）

**优点：** 文献报道效率高，操作相对安全，适合本科实验

**操作步骤：**
1. 用EMS与轻质石蜡油混合，配制0.1-0.2%浓度的EMS处理液
2. 收集黑腹果蝇的成虫或三龄幼虫
3. 将果蝇浸入EMS处理液中处理约45分钟（浓度1-2x10^-3）
4. 取出后用清水冲洗，转入正常培养基饲养
5. 观察F1代是否有突变表型
6. 对突变个体进行杂交，分析突变是显性/隐性、常染色体/性连锁

**遗传分析方法：**
- 让突变个体与野生型正反交，判断是否为伴性遗传
- 让F1自交获得F2，统计表型分离比
- 用卡方检验验证是否符合孟德尔遗传规律
- 用三点测交定位突变基因在染色体上的位置

### 方案二：紫外线物理诱变（操作简便）

**优点：** 设备简单（只需紫外灯），无化学药品残留

**注意事项：**
- 成虫对UV耐受性强，建议用三龄幼虫
- 幼虫照射30秒左右接近半致死量（根据学生案例）
- 需预实验摸索最佳照射时间
- UV照射需在无菌操作台中进行，注意防护

### 方案三：温度诱变（零安全风险）

**操作：**
- 利用极端温度（高温37度或低温4度）处理果蝇
- 观察是否引起发育异常或表型变化
- 适合安全条件受限的实验室

### 方案四：比较不同诱变方法的效果（综合性强）

**设计思路：**
- 同时设置EMS化学诱变组、紫外线物理诱变组和对照组
- 比较不同方法的突变率、突变类型、致死率
- 分析剂量-效应关系
- 这种比较研究的设计在汇报时更有亮点

## 十、果蝇基础知识速查

### 果蝇作为模式生物的优点

1. 生活史短：25度下约9-10天完成一个世代
2. 繁殖频率高：一对果蝇可产生数百个后代
3. 饲养方便：成本低，培养基简单
4. 染色体数目少：仅4对染色体，便于遗传分析
5. 突变表型丰富：眼色、翅型、体色、刚毛等易于观察
6. 遗传学工具丰富：平衡染色体、GAL4/UAS系统、FLP/FRT系统等

### 果蝇生活史

卵（1天）-> 幼虫（3龄，约5天）-> 蛹（约4天）-> 成虫

25度为最适宜饲养温度，60%湿度，12h光照/12h黑暗。

### 雌雄鉴别要点

| 特征 | 雌蝇 | 雄蝇 |
|------|------|------|
| 体型 | 较大 | 较小 |
| 腹部末端 | 尖而色浅 | 圆而色深（有黑色条纹） |
| 背部条纹 | 5条 | 3条 |
| 性梳 | 无 | 有（前足跗节基部） |

### 常见突变表型

| 突变名 | 基因符号 | 表型 |
|--------|----------|------|
| 白眼 | w | 眼色白色 |
| 朱砂眼 | v | 眼色浅红 |
| 残翅 | vg | 翅膀退化 |
| 卷翅 | Cy | 翅膀卷曲（显性） |
| 小翅 | m | 翅膀短小 |
| 黑檀体 | e | 体色深黑 |
| 黄体 | y | 体色黄色 |
