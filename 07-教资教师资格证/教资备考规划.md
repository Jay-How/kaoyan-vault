# 教资备考规划（初中 / 高中生物 · 福建）

> 与本库 843 考研并行推进的第二目标。院校路径分析见 [[07-教资教师资格证/任教福州一中路径|任教福州一中路径]]，官方信息与入口见 [[07-教资教师资格证/教资考试信息速查|教资考试信息速查]]。

## 目标与定位


| 项目 | 内容 |
| --- | --- |
| **目标证书** | 高级中学教师资格（生物学科，代码 408） / 初级中学教师资格（生物学科，代码 308） |
| **报考地点** | 福建省（按大三在校生身份，在厦门大学所在地考区报考） |
| **目标批次** | **2027 年上半年批次（笔试 + 面试一揽子通关）** |
| **考核闭环** | 2027 年 3 月笔试 → 2027 年 5 月面试 → 2027 年 6 月取得《考试合格证明》 |
| **与考研协同** | 843 考研初试在 2027 年 12 月；教资在上半年（5 月前）彻底收官，下半年全量备战考研初试，实现时间完全错峰 |

## 两条路径

### 路径 A：已参加 2026 下半年笔试

| 时间 | 动作 |
|------|------|
| 2026-10 至 11 月 | 不等成绩，先启动面试准备：试讲逐字稿、板书、结构化题库 |
| 2026-11 上旬 | 笔试成绩公布，确认 301 / 302 / 308 或 408 是否全部合格 |
| 2026-11 中下旬 | 面试报名与缴费（面试 280 元/人次），按公告选考区 |
| 2026-11 底 | 打印《面试准考证》，完成 3 次全流程模拟（20 分钟备课 + 20 分钟面试） |
| **2026-12-05 至 06** | 面试 |
| 2027-01 上旬 | 面试成绩公布，通过后下载《中小学教师资格考试合格证明》（有效期 3 年） |

### 路径 B：尚未参加笔试

| 时间 | 动作 |
|------|------|
| 2026-09 至 12 月 | 第一轮基础：三科大纲通读 + 生物学科知识 |
| 2027-01 上旬 | 笔试报名（预计） |
| 2027-03 上旬 | 笔试（预计，参照 2026 年上半年为 3 月 7 日） |
| 2027-04 中旬 | 成绩公布 |
| 2027-04 中下旬 | 面试报名 |
| 2027-05 中旬 | 面试（预计，参照 2026 年上半年为 5 月 16-17 日） |

> 标注"预计"的日期按官方历史节奏推算，以福建省教育考试院当次公告为准。

## 三科试卷结构

| 科目 | 代码 | 模块与比例 | 题型 | 单选 : 非选择 |
|------|------|-----------|------|--------------|
| 综合素质（中学） | 301 | 职业理念 15%｜教育法律法规 10%｜教师职业道德规范 15%｜文化素养 12%｜基本能力 48% | 单项选择、材料分析、写作 | 约 39% : 61% |
| 教育知识与能力（中学） | 302 | 教育基础·教学·学习心理·德育 68%；课程·发展心理·心理辅导·班级管理与教师心理 32% | 单项选择、辨析、简答、材料分析 | 约 30% : 70% |
| 生物学科知识与教学能力 | 308（初中）/ 408（高中） | 学科知识 47%｜教学知识 16%｜教学设计 37% | 单项选择、简答、教学设计、材料分析 | 约 33% : 67% |

**备考重心判断**：308/408 的学科知识（47%）与教学设计（37%）合计 84%，是单科分值最集中、也最容易靠练提分的部分。

## 面试要点

| 项目 | 官方规定 |
|------|----------|
| 形式 | 结构化面试 + 情境模拟；抽题 → 备课 **20 分钟** → 试讲 / 演示 → 答辩 |
| 面试时长 | **20 分钟**（接受面试时间），考官综合评分 |
| 评分权重 | 教学实施 **35**｜言语表达 15｜思维品质 15｜教学设计 10｜教学评价 10｜职业认知 5｜心理素质 5｜仪表仪态 5 |
| 科目规则 | 面试科目须与笔试科目三一致（生物）；中学增设科目为心理健康教育、俄语、日语，部分考区不接收 |

**得分点**：板书设计（8 分）、内容表述清楚准确（10 分）、教学环节与节奏（7 分）。

## 有效期管理

| 项目 | 规则 | 到期提醒 |
|------|------|----------|
| 笔试单科成绩 | 有效期 **2 年** | 2026 下半年合格科目 → 有效至 2028-12-31 |
| 面试成绩 | 单次有效 | 通过即获合格证明 |
| 《中小学教师资格考试合格证明》 | 有效期 **3 年** | 2026 下半年通过面试 → 有效至 2029-12-31 |
| 认定限制 | 每年只能认定一种教师资格，成功申领后一年内不能再申领第二本 | 初中与高中两本证需分年度认定 |
