## 报考条件（福建省）

### 基本条件

| 项目 | 要求 |
|------|------|
| 国籍与品行 | 中华人民共和国国籍；遵守宪法法律，拥护中国共产党领导，热爱教育事业，具有良好思想品德 |
| 报考地 | 户籍或居住证（有效期内）在报考所在地；港澳台居民在内地学习工作生活的可报考 |
| 在校生 | 普通高校在校三年级以上（专科层次为应届毕业生），凭学信网学籍在线验证报告在就读学校所在地考区报考 |
| 体检 | 符合申请认定教师资格的体检标准 |

### 学历门槛

| 报考类别 | 最低学历 |
|----------|----------|
| 初级中学教师资格 | 高等师范专科学校或其他大学专科毕业及其以上 |
| 高级中学教师资格 | 高等师范院校或其他大学本科毕业及其以上 |

### 不得报名

- 被撤销教师资格的，5 年内不得报名
- 受到剥夺政治权利，或故意犯罪受到有期徒刑以上刑事处罚的
- 参加教师资格考试有作弊行为的，3 年内不得再次参加

## 考试费用与考区

| 项目 | 福建标准 |
|------|----------|
| 笔试 | 70 元/科（三科 210 元） |
| 面试 | 280 元/人次 |
| 考区 | 福州（含平潭综合实验区）、厦门、莆田、三明、泉州、漳州、南平、龙岩、宁德 |

考点由考区在所属行政区域内随机安排，不按户籍区县安排，以准考证为准。

## 成绩与证书规则

| 项目 | 规则 |
|------|------|
| 笔试单科成绩 | 有效期 2 年（例：2026 下半年参加笔试，合格科目有效期至 2028-12-31） |
| 面试成绩 | 单次有效 |
| 《中小学教师资格考试合格证明》 | 有效期 3 年 |
| 命题依据 | 教育部颁布的考试标准与考试大纲（笔试大纲 + 面试大纲） |

## 认定要点（福建）

| 项目 | 要求 |
|------|------|
| 前提 | 取得《中小学教师资格考试合格证明》且在有效期内 |
| 受理机构 | 初级中学教师资格：县（区）级教育局；高级中学教师资格：设区市教育局 |
| 普通话 | 二级乙等及以上（语文教师、对外汉语教学教师需二级甲等；语音教师一级乙等）→ 生物教师按二级乙等 |
| 体检 | 认定机构指定的二级甲等（县级）及以上医疗机构，按《福建省教师资格申请人员体检标准及办法（2018 年修订）》 |
| 流程 | 中国教师资格网网上报名 → 体格检查 → 现场确认 → 审核认定 → 颁发证书 |
| 限制 | 同一申请人每年只能认定一种教师资格；成功申领后一年内不能再申领第二本 |

## 报名材料与照片要求

照片为审核不通过的高频原因：近 6 个月内免冠正面证件照，可见额头与两耳轮廓，彩色标准证件照，深色服装，白色背景，jpg/jpeg 格式，文件不超过 200K。
