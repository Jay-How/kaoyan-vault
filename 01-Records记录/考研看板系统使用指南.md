# 考研看板系统使用指南

> 基于四列结构的简单高效任务管理方法，与每日记录、月度计划、考研计划总览协同工作。

---

## 四列结构使用建议

| 列名 | 用途 | 任务特点 | 移动规则 |
|------|------|----------|----------|
| **Plan计划** | 长期目标和大型任务（1个月以上） | 不需要立即执行，但需要定期回顾 | 每月分解为具体任务到ToDo |
| **ToDo待办** | 本周或近期需要完成的任务（1-7天） | 已经明确可以开始，等待安排到具体时间 | 每天早上选择3-5个到Doing |
| **Doing进行中** | 今天正在做的任务（最多3-5个） | 当前焦点，需要集中精力完成 | 完成后立即移到Done |
| **Done已完成** | 已完成的任务（自动归档） | 用于成就感和进度回顾 | 每周清理，保留关键任务 |

### 列的使用原则

1. **Plan计划**：存放月度目标、学期目标、大型项目（如“完成高数基础学习”）
2. **ToDo待办**：存放本周需要完成的具体任务，每个任务都能在1-7天内完成
3. **Doing进行中**：严格控制在3-5个任务，确保专注力
4. **Done已完成**：及时清理，每周保留3-5个代表性任务供回顾

## 任务格式建议

### 基础格式
```
[科目] 任务描述 | 预计时间 | 优先级
```

### 增强格式（包含标签和截止日期）
```
[科目] 任务描述 | 预计时间 | 优先级 | #标签 @截止日期
```

### 示例任务

**Plan计划：**
- `[数学] 完成高数前四章基础学习（9月目标） | 24小时 | 高`
- `[英语] 六级词汇、听力、阅读同步推进（9月目标） | 32小时 | 高`
- `[专业课] 完成数据结构前四章学习（9月目标） | 24小时 | 高`

**ToDo待办：**
- `[数学] 高数第一章函数与极限学习 | 6小时 | 高 #本周`
- `[英语] 六级词汇每天50个 | 1小时/天 | 高 #今日`
- `[英语] 听力训练每天30分钟 | 0.5小时/天 | 中 #每日`

**Doing进行中：**
- `[规划] 制定本周详细学习计划 | 2小时 | 高 #今日`
- `[英语] 六级词汇Unit 1 | 1小时 | 高 #进行中`

**Done已完成：**
- `[x] [规划] 创建Kanban看板系统 | 1小时 | 高`
- `[x] [资源] 整理12篇经验帖PDF为Markdown | 3小时 | 中`

### 任务级标签（在任务描述中）
在任务描述中使用标签来分类和标记：

| 标签 | 含义 | 使用场景 | 示例 |
|------|------|----------|------|
| `#高` `#中` `#低` | 优先级 | 所有任务 | `[数学] 高数第一章学习 #高` |
| `#今日` `#本周` `#本月` | 时间范围 | Plan和ToDo列 | `[英语] 六级词汇 #本周` |
| `#数学` `#英语` `#专业课` | 科目分类 | 可选，用`[科目]`更简洁 | 可省略，用`[科目]`替代 |
| `#复习` `#新学` `#做题` | 任务类型 | 区分学习方式 | `[数学] 错题复习 #复习` |
| `#进行中` `#已完成` `#阻塞` | 状态标记 | Doing和Done列 | `[英语] 听力训练 #进行中` |
| `#重要` `#紧急` `#可延` | 紧急程度 | 优先级补充 | `[专业课] 真题研究 #重要` |

### 标签使用规则
1. **优先级标签**：每个任务必须包含一个优先级标签（`#高`、`#中`、`#低`）
2. **时间标签**：ToDo列的任务建议包含时间标签（`#今日`、`#本周`）
3. **状态标签**：Doing列的任务使用`#进行中`，Done列使用`#已完成`
4. **标签位置**：标签放在任务描述的末尾，用空格分隔

## 工作流程建议

### 1. 任务创建流程
```
每周日晚上 → 从月度计划提取本周任务 → 放入ToDo待办
每天早上   → 从ToDo待办选择3-5个任务 → 放入Doing进行中
任务完成   → 立即移到Done已完成
```

### 2. 每日工作流程
```
早上（8:00-8:15）：
1. 检查Doing进行中列，确认今日焦点
2. 从ToDo待办选择3-5个任务到Doing
3. 复制Doing中的任务到每日记录

晚上（21:30-21:45）：
1. 将完成的任务移到Done已完成
2. 更新任务描述，标记实际完成时间
3. 为明天准备ToDo待办任务
```

### 3. 每周工作流程
```
周日晚上（20:00-20:30）：
1. 回顾Done已完成列，总结本周成果
2. 清理Done列，保留3-5个代表性任务
3. 从月度计划提取下周任务到ToDo待办
4. 检查Plan计划，分解长期目标为具体任务
```

### 4. 每月工作流程
```
每月最后一天（19:00-19:30）：
1. 回顾本月Done已完成列，统计完成率
2. 清理Plan计划，将完成的目标移到Done
3. 从考研计划总览提取下月目标到Plan计划
4. 更新月度记录，标记完成情况
```

- **输出**：每月将完成情况反馈到考研计划总览的里程碑

## 使用规则

### 1. 任务创建规则
- 任务必须包含科目标签：`[数学]`、`[英语]`、`[专业课]`、`[规划]`、`[资源]`
- 任务必须包含预计时间和优先级
- Plan计划中的任务不需要精确时间，但需要大致估算

### 2. 任务移动规则
- 每天Doing进行中最多5个任务
- 任务完成后必须立即移动，不得拖延
- 未完成的任务需要重新评估优先级

### 3. 定期维护规则
- 每天清理Doing进行中列
- 每周清理Done已完成列，保留代表性任务
- 每月清理Plan计划，分解长期目标

### 4. 标签使用规则
- 优先级标签必须存在
- 时间标签建议使用，便于筛选
- 状态标签随任务移动自动更新

## 常见问题

### Q: 任务太多怎么办？
A: 使用优先级标签筛选，先做`#高`优先级的任务，`#低`优先级的任务可以移到Plan计划中。

### Q: 任务总是完不成怎么办？
A: 重新评估预计时间，将大任务分解为小任务，确保每个任务能在2-4小时内完成。

### Q: 如何平衡不同科目？
A: 在ToDo待办中保持科目平衡，每天至少包含数学、英语、专业课各一个任务。

### Q: 突发任务如何处理？
A: 创建新任务放入ToDo待办，评估优先级后决定是否替换Doing进行中中的任务。
