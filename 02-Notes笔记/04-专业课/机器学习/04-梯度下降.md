 梯度下降

> 本篇整理自课程听讲笔记。梯度下降是机器学习、深度学习、大模型训练的核心优化方法。

---

## 、为什么需要梯度下降？

损失函数（MSE）告诉我们模型预测得准不准，但没有告诉我们**如何调整参数**。

> [!question] 核心问题
> 参数应该调大还是调小？调多少？——这就是梯度下降要回答的。

类比：**蒙眼下山**

| 比喻 | 对应概念 |
|------|----------|
| 山的高度 | 损失函数值 $L$ |
| 当前位置 | 当前参数 $(w, b)$ |
| 感知坡度 | 计算偏导数（梯度） |
| 往下坡走 | 沿梯度反方向更新参数 |
| 每步迈多大 | 学习率 $\eta$ |
| 到达山底 | 损失最小，参数最优 |

---

## 、数学基础

### .1 导数

函数 $f(x)$ 在 $x_0$ 处的导数：

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

| 导数值 | 含义 |
|--------|------|
| $f'(x) > 0$ | $x$ 增大 → $f(x)$ 增大（上升趋势） |
| $f'(x) < 0$ | $x$ 增大 → $f(x)$ 减小（下降趋势） |
| $f'(x) = 0$ | 极值点（可能最优） |

### .2 偏导数

多变量函数中，只对其中一个变量求导，其余视为常量。

$$f(x, y) = x^2 + 3xy + y^2$$

$$\frac{\partial f}{\partial x} = 2x + 3y \quad \text{（将 } y \text{ 视为常量）}$$

$$\frac{\partial f}{\partial y} = 3x + 2y \quad \text{（将 } x \text{ 视为常量）}$$

### .3 梯度

所有偏导数组成的向量：

$$\nabla L = \left[\frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}, \ldots, \frac{\partial L}{\partial w_n}, \frac{\partial L}{\partial b}\right]$$

| 性质 | 说明 |
|------|------|
| 梯度方向 | 函数值**增长最快**的方向 |
| 梯度反方向 | 函数值**下降最快**的方向 |
| 梯度大小 | 变化率的大小（坡度陡峭程度） |

> [!info] 直觉理解
> 梯度就像一个箭头，指向"上坡最陡的方向"。我们要下山，就往箭头的反方向走。

---

## 、梯度下降算法

### .1 参数更新公式

$$w_{\text{new}} = w_{\text{old}} - \eta \cdot \frac{\partial L}{\partial w}$$

$$b_{\text{new}} = b_{\text{old}} - \eta \cdot \frac{\partial L}{\partial b}$$

其中 $\eta$ 为学习率（learning rate）。

> [!tip] 为什么要减？
> 梯度指向增长最快的方向，减去梯度 → 沿下降最快的方向移动。

### .2 学习率的影响

| 学习率 | 效果 | 现象 |
|--------|------|------|
| **太小** | 收敛极慢 | 参数几乎不变，训练耗时过长 |
| **合适** | 稳定收敛 | 参数逐步逼近最优值 |
| **太大** | 震荡 | 参数反复跳过最优解，来回震荡 |
| **过大** | 梯度爆炸 | 参数越来越大，完全发散 |

> [!warning] 学习率设置是关键挑战
> 设太小浪费算力，设太大无法收敛。实践中常用自适应优化器（如 Adam）自动调整。

### .3 训练终止条件

- 损失函数接近零（或不再明显下降）
- 达到预设的训练轮数（epoch）
- 参数变化量小于阈值

## 、线性回归的梯度推导

### .1 损失函数

$$L(w, b) = \frac{1}{n} \sum_{i=1}^{n} (wx_i + b - y_i)^2$$

### .2 对 $w$ 求偏导

$$\frac{\partial L}{\partial w} = \frac{2}{n} \sum_{i=1}^{n} (wx_i + b - y_i) \cdot x_i$$

### .3 对 $b$ 求偏导

$$\frac{\partial L}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (wx_i + b - y_i)$$

### .4 推导过程（链式法则）

令 $e_i = \hat{y}_i - y_i = wx_i + b - y_i$（第 $i$ 个样本的误差）

$$L = \frac{1}{n} \sum e_i^2$$

$$\frac{\partial L}{\partial w} = \frac{1}{n} \sum 2e_i \cdot \frac{\partial e_i}{\partial w} = \frac{2}{n} \sum e_i \cdot x_i$$

> [!info] 链式法则
> 对嵌套函数求导：$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial e} \cdot \frac{\partial e}{\partial w}$。这在深度学习的反向传播中同样核心。

## 、梯度下降的变体

| 变体 | 每次使用数据量 | 优点 | 缺点 | 收敛特点 |
|------|----------------|------|------|----------|
| **批量梯度下降（BGD）** | 全部 $n$ 条 | 梯度精确、稳定收敛 | 计算开销大，内存占用高 | 平滑收敛 |
| **随机梯度下降（SGD）** | 1 条 | 速度快，能跳出局部最优 | 噪声大、震荡剧烈 | 震荡收敛 |
| **小批量梯度下降（Mini-batch）** | $m$ 条（通常 32/64/128） | 兼顾精度与效率，可利用 GPU 并行 | 需选批量大小 | 较平滑 |

> [!tip] 实践中的 SGD
> 业界说的 SGD 通常指 **Mini-batch**（64/128 条），不是真正的单条。这是深度学习训练的主流选择。

### ini-batch 的优势

```python
# 代码：Mini-batch 梯度下降
for epoch in range(num_epochs):
    # 乱数据
    shuffle(X, y)
    
    # 批处理
    for i in range(0, n, batch_size):
        X_batch = X[i:i+batch_size]
        y_batch = y[i:i+batch_size]
        
        # 算这批数据的梯度
        gradient = compute_gradient(X_batch, y_batch, w, b)
        
        # 新参数
        w -= learning_rate * gradient[0]
        b -= learning_rate * gradient[1]
```

## 、优化器演进

### .1 SGD with Momentum（动量法）

**核心思想**：模拟物理学中的惯性，给梯度加上"速度"。

$$v_t = \beta \cdot v_{t-1} + \eta \cdot \nabla L$$
$$w = w - v_t$$

| 参数 | 含义 | 典型值 |
|------|------|--------|
| $\beta$ | 动量系数（摩擦力） | 0.9 |

**效果**：能冲出局部最优的"凹槽"，加速收敛。

### .2 AdaGrad

**核心思想**：为每个参数维护**独立的学习率**。

$$w = w - \frac{\eta}{\sqrt{G_t + \epsilon}} \cdot \nabla L$$

其中 $G_t$ 是历史梯度平方和。

**效果**：大参数用大更新，小参数用小更新。

**缺点**：学习率会单调递减，后期可能趋近于零。

### .3 RMSProp

**核心思想**：只关注**近期梯度**，防止学习率降为零。

$$s_t = \beta \cdot s_{t-1} + (1-\beta) \cdot (\nabla L)^2$$
$$w = w - \frac{\eta}{\sqrt{s_t + \epsilon}} \cdot \nabla L$$

**效果**：适合非平稳目标函数。

### .4 Adam（Adaptive Moment Estimation）

**核心思想**：Momentum + RMSProp 的结合。

$$m_t = \beta_1 \cdot m_{t-1} + (1-\beta_1) \cdot \nabla L \quad \text{（一阶矩：动量）}$$
$$v_t = \beta_2 \cdot v_{t-1} + (1-\beta_2) \cdot (\nabla L)^2 \quad \text{（二阶矩：自适应学习率）}$$
$$w = w - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t$$

| 参数 | 含义 | 典型值 |
|------|------|--------|
| $\beta_1$ | 一阶矩衰减率 | 0.9 |
| $\beta_2$ | 二阶矩衰减率 | 0.999 |
| $\eta$ | 学习率 | 0.001 |
| $\epsilon$ | 防止除零 | $10^{-8}$ |

> [!success] Adam 是当前默认选择
> 跑得快、跑得稳、对学习率不敏感。深度学习几乎默认使用 Adam。

### 化器对比总结

| 优化器 | 核心思想 | 学习率 | 适用场景 |
|--------|----------|--------|----------|
| SGD | 标准梯度下降 | 固定 | 简单问题 |
| SGD + Momentum | 惯性加速 | 固定 | 需要加速收敛 |
| AdaGrad | 每参数独立学习率 | 自适应（递减） | 稀疏数据 |
| RMSProp | 近期梯度加权 | 自适应 | 非平稳目标 |
| **Adam** | **Momentum + RMSProp** | **自适应** | **几乎万能** |

## 、梯度下降的两大问题

### .1 局部最优 vs 全局最优

```
损失   ╱╲
  │  ╱  ╲    ╱╲
  │ ╱    ╲  ╱  ╲
  │╱      ╲╱    ╲
  │  局部   全局
  └──────────────→ 参数
```

| 问题 | 说明 |
|------|------|
| **局部最优** | 梯度为零，但不是全局最小值 |
| **鞍点** | 某些方向是最小值，某些方向是最大值（高维常见） |

> [!info] 高维空间中的局部最优
> 在高维空间中，真正的局部最优其实很少见，更常见的是**鞍点**（saddle point）。鞍点处梯度为零，但不是所有方向都是最小值。

### .2 梯度消失与梯度爆炸

| 问题 | 现象 | 原因 | 解决方案 |
|------|------|------|----------|
| **梯度消失** | 梯度趋近于零，参数不再更新 | 深层网络中梯度连乘导致 | ReLU 激活函数、残差连接、BatchNorm |
| **梯度爆炸** | 梯度越来越大，参数发散 | 学习率过大或梯度累积 | 梯度裁剪、降低学习率、BatchNorm |

> [!warning] 深度学习中的关键问题
> 梯度消失和爆炸是深度网络训练的核心挑战。ResNet（残差网络）通过跳跃连接解决了梯度消失问题，使得训练数百层的网络成为可能。

## 、代码实现

### .1 手写梯度下降

```python
import numpy as np

# 成数据
np.random.seed(42)
X = np.random.uniform(0.9, 1.5, 100)  # 积（百平米）
y = 2.5 * X + 0.3 + np.random.normal(0, 0.1, 100)  # 价 + 噪声

# 参数
learning_rate = 0.01
epochs = 100000

# 始化参数
w, b = 0.0, 0.0
n = len(X)

for epoch in range(epochs):
    # 测
    y_pred = w * X + b
    
    # 算梯度
    dw = (2 / n) * np.sum((y_pred - y) * X)
    db = (2 / n) * np.sum(y_pred - y)
    
    # 新参数
    w -= learning_rate * dw
    b -= learning_rate * db
    
    # 印进度
    if epoch % 10000 == 0:
        loss = np.mean((y_pred - y) ** 2)
        print(f"Epoch {epoch}: w={w:.4f}, b={b:.4f}, loss={loss:.4f}")

print(f"\n最终结果: w = {w:.2f}, b = {b:.2f}")
# 期: w ≈ 2.50, b ≈ 0.30
```

### .2 使用 Adam 优化器

```python
import numpy as np

# 据同上
X = np.random.uniform(0.9, 1.5, 100)
y = 2.5 * X + 0.3 + np.random.normal(0, 0.1, 100)

# dam 超参数
learning_rate = 0.01
beta1, beta2, epsilon = 0.9, 0.999, 1e-8
epochs = 50000

# 始化
w, b = 0.0, 0.0
mw, mb, vw, vb = 0.0, 0.0, 0.0, 0.0
n = len(X)

for epoch in range(epochs):
    y_pred = w * X + b
    
    # 算梯度
    dw = (2 / n) * np.sum((y_pred - y) * X)
    db = (2 / n) * np.sum(y_pred - y)
    
    # 新一阶矩（动量）
    mw = beta1 * mw + (1 - beta1) * dw
    mb = beta1 * mb + (1 - beta1) * db
    
    # 新二阶矩（自适应学习率）
    vw = beta2 * vw + (1 - beta2) * dw ** 2
    vb = beta2 * vb + (1 - beta2) * db ** 2
    
    # 差修正
    mw_hat = mw / (1 - beta1 ** (epoch + 1))
    mb_hat = mb / (1 - beta1 ** (epoch + 1))
    vw_hat = vw / (1 - beta2 ** (epoch + 1))
    vb_hat = vb / (1 - beta2 ** (epoch + 1))
    
    # 新参数
    w -= learning_rate * mw_hat / (np.sqrt(vw_hat) + epsilon)
    b -= learning_rate * mb_hat / (np.sqrt(vb_hat) + epsilon)

print(f"Adam 结果: w = {w:.2f}, b = {b:.2f}")
# 万次就能达到 10万次 SGD 的效果
```

## 、梯度下降的核心地位

| 应用场景 | 说明 |
|----------|------|
| **机器学习** | 线性回归、逻辑回归的参数优化 |
| **深度学习** | 反向传播 + 梯度下降 = 训练核心 |
| **大语言模型** | GPT 等模型的训练依赖梯度下降（Adam 优化器） |

> [!quote] 核心结论
> 梯度下降 + 反向传播 = 深度学习训练的核心。理解了梯度下降，学习反向传播时只需再看链式法则即可。
