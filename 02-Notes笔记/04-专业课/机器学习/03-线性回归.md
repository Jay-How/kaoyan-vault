 线性回归

> 本篇整理自课程听讲笔记。线性回归是机器学习的理论基础，掌握它就理解了机器学习的工作原理。

---

## 、核心思想

线性回归通过构建**线性方程**来拟合数据的内在分布规律，从而实现对**连续数值**的预测。

### 键概念拆解

| 概念 | 含义 |
|------|------|
| **线性** | 对**参数**是线性的（不是对特征）。$f(ax) = a \cdot f(x)$，可加性 $f(x+y) = f(x) + f(y)$ |
| **回归** | 通过数据建模，找到变量间的映射关系，实现连续数值预测 |
| **拟合** | 为数据找一条规律曲线，使预测值尽可能接近真实值 |

> [!warning] 常见误解
> - 线性回归不一定画直线（多项式回归可画曲线）
> - "线性"指对**参数** $w$ 线性，不是对输入特征 $x$ 线性

---

## 、简单线性回归（单特征）

### .1 模型公式

$$\hat{y} = wx + b$$

| 符号 | 名称 | 含义 | 几何意义 |
|------|------|------|----------|
| $\hat{y}$ | 预测值 | 模型输出 | 直线上的点 |
| $x$ | 特征 | 输入数据 | 横坐标 |
| $w$ | 权重（weight） | 特征对结果的影响程度 | 直线斜率 |
| $b$ | 偏置（bias） | 特征为零时的理论基准值 | 截距 |

> [!tip] 参数的含义
> $w$ 表示：特征每变化 1 个单位，输出变化 $w$ 个单位。
> 例如：面积每增加 1 平米，房价变化 $w$ 万元。

### .2 直觉示例：房价预测

| 面积 ($x$) | 房价 ($y$) |
|------------|------------|
| 90 | 203 |
| 100 | 230 |
| 120 | 310 |
| 150 | 414 |

通过散点图观察，数据大致沿一条直线分布：
- 直线方程：$y \approx 2.2x + 10$
- 预测 100 平房价：$2.2 \times 100 + 10 = 230$ 万

## 、多元线性回归（多特征）

### .1 模型公式

$$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b$$

向量化表示：

$$\hat{y} = \mathbf{w}^T \mathbf{x} + b$$

其中 $\mathbf{w} = [w_1, w_2, \ldots, w_n]^T$，$\mathbf{x} = [x_1, x_2, \ldots, x_n]^T$

### .2 房价多特征示例

| 特征 | 权重 $w$ | 含义 |
|------|----------|------|
| 面积 | +2.42 | 正相关：面积越大越贵 |
| 楼层 | +1.30 | 正相关：高层更贵 |
| 距地铁距离 | -0.85 | 负相关：越远越便宜 |
| 房龄 | -0.32 | 负相关：越老越便宜 |
| 偏置 $b$ | +49.0 | 基准值 |

预测公式：$\hat{y} = 2.42 \times \text{面积} + 1.30 \times \text{楼层} - 0.85 \times \text{距离} - 0.32 \times \text{房龄} + 49$

> [!info] 无论一个特征还是 100 个特征，模型结构都是 $\hat{y} = \mathbf{w}^T \mathbf{x} + b$，只是维度不同。

## 、多项式回归

### .1 为什么需要？

现实数据不总是线性分布。房价可能随面积"先慢后快"增长，直线无法拟合。

### .2 模型公式

$$\hat{y} = w_1 x + w_2 x^2 + \cdots + w_d x^d + b$$

| 次数 $d$ | 拟合形状 | 说明 |
|----------|----------|------|
| $d = 1$ | 直线 | 普通线性回归 |
| $d = 2$ | 抛物线 | 可拟合非线性趋势 |
| $d > 2$ | 更复杂的曲线 | 灵活性更高 |

> [!warning] 多项式回归仍属于线性回归
> 因为"线性"是对**参数** $w$ 而言。$x^2$ 可以视为新特征 $z = x^2$，则 $\hat{y} = w_1 x + w_2 z + b$ 仍是线性形式。

## 、损失函数：均方误差（MSE）

### .1 定义

度量预测值与真实值之间的偏差：

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

其中 $n$ 为样本数量，$\hat{y}_i$ 为第 $i$ 个样本的预测值，$y_i$ 为真实值。

### .2 为什么用平方？

| 原因 | 说明 |
|------|------|
| **消除正负抵消** | 不用平方时，正负误差相加可能为零（误判为完美） |
| **放大误差** | 平方使大误差更显著，便于优化方向调整 |
| **数学性质好** | 处处可导，便于求梯度 |

### .3 MSE 的意义

| MSE 值 | 含义 |
|--------|------|
| MSE 大 | 预测不准，参数需要调整 |
| MSE 小 | 预测较准 |
| MSE = 0 | 完美拟合（通常达不到） |

> [!tip] 训练目标
> 找到一组参数 $(w, b)$，使 MSE 尽可能小。

### .4 其他常见损失函数

| 损失函数 | 公式 | 特点 |
|----------|------|------|
| **MSE（均方误差）** | $\frac{1}{n}\sum(\hat{y}_i - y_i)^2$ | 对异常值敏感（平方放大） |
| **MAE（平均绝对误差）** | $\frac{1}{n}\sum|\hat{y}_i - y_i|$ | 对异常值鲁棒 |
| **Huber Loss** | MSE 和 MAE 的结合 | 兼顾两者优点 |

## 、梯度下降优化

### .1 核心思想

通过计算损失函数对参数的**梯度**（偏导数），沿梯度反方向更新参数，使损失逐步减小。

### .2 参数更新公式

$$w_{\text{new}} = w_{\text{old}} - \eta \cdot \frac{\partial L}{\partial w}$$

$$b_{\text{new}} = b_{\text{old}} - \eta \cdot \frac{\partial L}{\partial b}$$

其中 $\eta$ 为学习率（learning rate）。

### .3 线性回归的梯度推导

对 MSE 损失函数分别求偏导：

$$\frac{\partial \text{MSE}}{\partial w} = \frac{2}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) \cdot x_i$$

$$\frac{\partial \text{MSE}}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)$$

> [!tip] 直觉理解
> - 对 $w$ 的偏导：误差 $(\hat{y}_i - y_i)$ 乘以对应的特征值 $x_i$ → 特征越大，对权重的影响越大
> - 对 $b$ 的偏导：直接是误差的平均值

详见 → [[04-梯度下降]]

## 、模型训练流程

```
输入数据 → 模型预测 → 计算损失(MSE) → 求梯度(偏导) → 更新参数 → 重新预测
     ↑                                                              │
     └──────────────────── 迭代循环 ←──────────────────────────────┘
```

## 、欠拟合与过拟合

| 问题 | 表现 | 原因 | 解决方法 |
|------|------|------|----------|
| **欠拟合（Underfitting）** | 训练集和测试集上表现都差 | 模型太简单（如用直线拟合曲线数据） | 增加特征、使用多项式回归 |
| **过拟合（Overfitting）** | 训练集表现好，测试集表现差 | 模型太复杂，记住了噪声 | 正则化、减少特征、增加数据 |

### 则化

在损失函数中加入参数大小的惩罚项，防止参数过大：

| 方法 | 惩罚项 | 效果 |
|------|--------|------|
| **L2 正则化（Ridge）** | $\lambda \sum w_i^2$ | 参数趋向于小值，平滑模型 |
| **L1 正则化（Lasso）** | $\lambda \sum |w_i|$ | 参数趋向于稀疏（部分为零），特征选择 |

## 、代码示例

### .1 使用 sklearn（最小二乘法）

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 备数据
X = np.array([[90], [100], [120], [150]])  # 积（特征）
y = np.array([203, 230, 310, 414])          # 价（标签）

# 练模型
model = LinearRegression()
model.fit(X, y)

# 看参数
print(f"权重 w = {model.coef_[0]:.2f}")    #  2.42
print(f"偏置 b = {model.intercept_:.2f}")   #  49.0

# 测
area = np.array([[100]])
predicted_price = model.predict(area)
print(f"100平房价预测: {predicted_price[0]:.2f} 万")
```

### .2 使用 SGDRegressor（梯度下降）

```python
from sklearn.linear_model import SGDRegressor
from sklearn.preprocessing import StandardScaler

# 征缩放（梯度下降对特征尺度敏感）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 练
model = SGDRegressor(learning_rate='constant', eta0=0.01, max_iter=100000)
model.fit(X_scaled, y)
```

### .3 多特征示例

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 特征：面积、楼层、距地铁距离、房龄
X = np.array([
    [90, 3, 500, 10],
    [100, 5, 200, 5],
    [120, 8, 100, 3],
    [150, 10, 50, 1]
])
y = np.array([203, 280, 380, 520])

model = LinearRegression()
model.fit(X, y)

print(f"权重: {model.coef_}")       # 2.42, 1.30, -0.85, -0.32]
print(f"偏置: {model.intercept_}")   # 9.0
```

## 、线性回归的重要地位

线性回归延伸出两个重要方向：

| 方向 | 说明 | 关系 |
|------|------|------|
| **逻辑回归** | 解决分类问题（加激活函数 $\sigma$） | 线性回归 + Sigmoid |
| **深度学习** | 多层逻辑回归叠加 | 每个隐藏层 ≈ 线性回归 + 激活函数 |

> [!quote] 核心理解
> - 线性回归 → 加 Sigmoid → 逻辑回归（分类）
> - 逻辑回归 × 多层叠加 → 深度神经网络
> - 深度神经网络 + 自注意力机制 → Transformer → 大语言模型
>
> 理解不了线性回归，深度学习肯定学不会。
