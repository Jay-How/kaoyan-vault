# 📒 模块五：设计理论

> 843专业课 - 创新设计类（约25分）

---

## 一、设计基础概念

### 1.1 设计的定义与本质

**设计的定义**：
设计是发现问题、定义问题、解决问题的系统工程，是将抽象需求转化为具体方案的过程。

**设计 ≠ 美化/造型**：
- 现代设计是"解决问题"的系统工程
- 包含：视觉设计、交互设计、服务设计、商业模式设计等
- 核心是"以人为本"

**设计的核心价值**：
- 发现用户痛点
- 利用技术手段提供解决方案
- 外观只是解决方案的载体之一

> [!tip] 真题考点
> - 2021年：辨析题考"设计就是美化"
> - 2024年：辨析题考"用户需求就是设计目标"

### 1.2 设计的分类

| 类型 | 关注点 | 示例 |
|------|--------|------|
| **产品设计** | 物理产品的形态和功能 | 手机、家具 |
| **交互设计** | 人与产品的交互方式 | App界面、手势操作 |
| **服务设计** | 服务流程和体验 | 医院就诊流程 |
| **体验设计** | 整体用户体验 | 苹果零售店 |

## 二、设计方法论

### 2.1 设计思维（Design Thinking）

**定义**：一套以人为本的创新方法论

**五个阶段**（斯坦福d.school）：
```
共情 → 定义 → 构思 → 原型 → 测试
(Empathize) (Define) (Ideate) (Prototype) (Test)
```

**双钻模型**（Double Diamond）：
```
发散 ──→ 收敛 ──→ 发散 ──→ 收敛
发现      定义      发展      交付
```

**核心要素**：
1. **同理心**：理解用户需求
2. **定义**：明确问题
3. **构思**：头脑风暴
4. **原型**：动手思考
5. **测试**：迭代验证

> [!warning] 易错点
> 设计思维 ≠ 发散思维！发散思维只是设计思维的一个工具。

> [!tip] 真题考点
> - 2023年：辨析题考"设计思维就是发散思维"
> - 2024年：辨析题考"用户需求就是设计目标"

### 2.2 用户中心设计（UCD）

**核心思想**：以用户需求为设计出发点

**用户研究方法**：

| 方法 | 说明 |
|------|------|
| 用户访谈 | 深入了解用户想法 |
| 问卷调查 | 大规模收集数据 |
| 用户观察 | 观察用户真实行为 |
| 可用性测试 | 测试产品易用性 |

**用户画像（Persona）**：
- 基于真实用户数据构建
- 包含：姓名、年龄、职业、目标、痛点
- 帮助团队聚焦目标用户

**用户需求分析**：

| 需求类型 | 说明 | 示例 |
|----------|------|------|
| **Needs（需求）** | 真实的、深层的需求 | 快速到达目的地 |
| **Wants（想要）** | 表面的、表达的需求 | 我想要一辆车 |

> [!warning] 易错点
> UCD的核心是理解用户，不是讨好用户！设计师需要透过现象看本质。

### 2.3 参与式设计（Participatory Design）

**定义**：让用户直接参与设计决策过程

**特点**：
- 利益相关者参与设计
- 确保产品满足真实需求
- 提高用户接受度

**利益相关者分析**：
- 政府、企业、NGO、用户
- 各方诉求可能冲突
- 需要平衡各方利益

> [!tip] 真题考点
> - 2023年：名词解释考参与式设计
> - 2025年：辨析题考社会创新设计中的利益相关者

## 三、互联网与设计

### 3.1 互联网思维

**核心要素**：

| 要素 | 说明 |
|------|------|
| **用户至上** | 以用户为中心 |
| **体验为王** | 极致用户体验 |
| **迭代创新** | 快速迭代，小步快跑 |
| **流量思维** | 用户量即价值 |
| **平台思维** | 连接多方 |
| **免费思维** | 低成本获取用户 |

**互联网思维的本质**：
- 不是技术，是方法论和价值观
- 基于互联网技术特征演化而来
- 不能将"思维"等同于"技术"

> [!tip] 真题考点
> - 2021年：辨析题考"互联网思维是技术"
> - 2022年：名词解释考互联网思维

### 3.2 "互联网+"与"+互联网"

| 概念 | 说明 | 示例 |
|------|------|------|
| **互联网+** | 互联网思维改造传统行业 | 网约车、移动支付 |
| **+互联网** | 传统行业使用互联网工具 | 开网店 |

**本质区别**：
- "互联网+"是深度融合，改变生产方式
- "+互联网"是简单叠加，工具使用

> [!tip] 真题考点
> - 2022年：辨析题考"互联网+"与"+互联网"

### 3.3 设计驱动式创新

**定义**：通过赋予产品新的意义和语言来创造竞争优势

**三种创新模式**：

| 模式 | 关注点 | 示例 |
|------|--------|------|
| 技术驱动 | 技术突破 | 芯片技术 |
| 市场驱动 | 用户需求 | 市场调研 |
| 设计驱动 | 意义重构 | iPhone |

**苹果iPhone的案例**：
- 不是技术突破（触摸屏已存在）
- 不是市场调研（用户不知道想要什么）
- 而是重新定义了"手机"的意义

> [!tip] 真题考点
> - 2021年：名词解释考设计驱动式创新

## 四、可持续设计

### 4.1 有计划的报废

**定义**：故意限制产品寿命或频繁更新外观，诱导消费者购买新产品

**双面性**：

| 视角 | 观点 |
|------|------|
| 经济 | 刺激消费，推动循环 |
| 环境 | 资源浪费，环境污染 |
| 伦理 | 增加消费者负担 |

**现代启示**：
- 这种思路已过时
- 应转向"可持续设计"
- 模块化、易维修、循环设计

> [!tip] 真题考点
> - 2024年：简答题考"有计划的报废"

### 4.2 社会创新设计

**定义**：通过设计解决社会问题

**特点**：
- 解决复杂系统性问题
- 需考虑所有利益相关者
- 可持续性是关键

**利益相关者分析**：
- 政府：监管要求
- 企业：盈利模式
- 用户：实际痛点

> [!tip] 真题考点
> - 2025年：辨析题考社会创新设计

## 五、通用设计

### 5.1 通用设计原则

| 原则 | 说明 |
|------|------|
| **公平使用** | 所有人都能使用 |
| **弹性使用** | 适应不同偏好 |
| **简单直觉** | 易于理解 |
| **容错设计** | 减少意外后果 |
| **省力设计** | 高效舒适 |
| **空间适当** | 提供足够空间 |

### 5.2 无障碍设计

**目标**：让残障人士也能使用

**示例**：
- 轮椅坡道
- 盲文标识
- 屏幕阅读器

> [!tip] 真题考点
> - 2025年：名词解释考通用设计

## 六、游戏化设计

### 6.1 游戏化思维

**定义**：将游戏元素应用于非游戏场景

**游戏元素**：

| 元素 | 说明 | 示例 |
|------|------|------|
| **点数（Points）** | 量化成就 | 积分 |
| **徽章（Badges）** | 可视化成就 | 成就徽章 |
| **排行榜（Leaderboards）** | 竞争排名 | 排行榜 |
| **挑战（Challenges）** | 任务目标 | 每日任务 |
| **奖励（Rewards）** | 完成奖励 | 奖品 |

**应用场景**：
- 教育：学习积分
- 健康：运动挑战
- 环保：碳积分

> [!tip] 真题考点
> - 2022年：名词解释考游戏化思维
> - 2023年：辨析题考游戏技术与教育

### 6.2 严肃游戏

**定义**：以非娱乐为主要目的的游戏

**应用领域**：

| 领域 | 示例 |
|------|------|
| 教育 | 教育游戏 |
| 医疗 | 康复训练 |
| 军事 | 模拟训练 |
| 企业 | 培训游戏 |

**参与式设计与严肃游戏**：
- 参与式设计关注设计过程
- 严肃游戏关注设计目的
- 两者常结合使用

> [!tip] 真题考点
> - 2023年：名词解释考严肃游戏
> - 2024年：辨析题考游戏数值设计

## 七、非物质设计

### 7.1 概念

**定义**：从有形的"物"转向无形的"服务"、"体验"、"流程"、"数据"

**特点**：
- 去物质化
- 关注"使用权"而非"所有权"
- 服务设计、体验设计

**示例**：
- 共享经济（Uber、Airbnb）
- 订阅服务（Netflix）
- 数字产品（App）

> [!tip] 真题考点
> - 2024年：名词解释考非物质设计
