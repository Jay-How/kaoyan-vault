## 一、概率论基础

### 1.1 随机事件与概率

#### 1.1.1 基本概念

| 术语 | 定义 | 示例 |
|------|------|------|
| **随机试验** | 可重复进行、结果不确定的试验 | 掷骰子、抽牌 |
| **样本空间** $\Omega$ | 随机试验所有可能结果的集合 | 掷骰子：$\{1,2,3,4,5,6\}$ |
| **随机事件** | 样本空间的子集 | 出现偶数：$\{2,4,6\}$ |
| **必然事件** | 一定会发生的事件 | 样本空间本身 $\Omega$ |
| **不可能事件** | 不可能发生的事件 | 空集 $\varnothing$ |

#### 1.1.2 事件的关系与运算

| 运算 | 符号 | 含义 |
|------|------|------|
| **包含** | $A \subset B$ | A发生则B必发生 |
| **相等** | $A = B$ | $A \subset B$ 且 $B \subset A$ |
| **和（并）** | $A \cup B$ | A与B至少一个发生 |
| **积（交）** | $A \cap B$ | A与B同时发生 |
| **差** | $A - B$ | A发生但B不发生 |
| **互斥** | $A \cap B = \varnothing$ | A与B不能同时发生 |
| **对立** | $A \cap \bar{A} = \varnothing$，$A \cup \bar{A} = \Omega$ | A与$\bar{A}$互为对立 |

**运算律**：
- 交换律：$A \cup B = B \cup A$，$A \cap B = B \cap A$
- 结合律：$(A \cup B) \cup C = A \cup (B \cup C)$
- 分配律：$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
- 德摩根律：$\overline{A \cup B} = \bar{A} \cap \bar{B}$，$\overline{A \cap B} = \bar{A} \cup \bar{B}$

#### 1.1.3 概率的定义

**古典概型**（等可能概型）：
$$P(A) = \frac{A包含的基本事件数}{基本事件总数} = \frac{k}{n}$$

**几何概型**：
$$P(A) = \frac{构成事件A的区域度量}{样本空间的区域度量}$$

**概率的公理化定义**：
1. 非负性：$P(A) \geq 0$
2. 规范性：$P(\Omega) = 1$
3. 可列可加性：$P(\bigcup_{i=1}^{\infty} A_i) = \sum_{i=1}^{\infty} P(A_i)$（$A_i$互斥）

#### 1.1.4 概率的性质

| 性质 | 公式 |
|------|------|
| 空集概率 | $P(\varnothing) = 0$ |
| 有限可加性 | $P(\bigcup_{i=1}^{n} A_i) = \sum_{i=1}^{n} P(A_i)$（互斥） |
| 对立事件 | $P(\bar{A}) = 1 - P(A)$ |
| 加法公式 | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| 单调性 | 若 $A \subset B$，则 $P(A) \leq P(B)$ |

#### 1.1.5 条件概率

**定义**：
$$P(A|B) = \frac{P(AB)}{P(B)}, \quad P(B) > 0$$

**乘法公式**：
$$P(AB) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)$$

**推广**：
$$P(A_1 A_2 \cdots A_n) = P(A_1) P(A_2|A_1) P(A_3|A_1 A_2) \cdots P(A_n|A_1 \cdots A_{n-1})$$

#### 1.1.6 全概率公式与贝叶斯公式

**全概率公式**：
设 $B_1, B_2, \ldots, B_n$ 为样本空间的一个划分，且 $P(B_i) > 0$，则：
$$P(A) = \sum_{i=1}^{n} P(A|B_i) P(B_i)$$

**贝叶斯公式**：
$$P(B_j|A) = \frac{P(A|B_j) P(B_j)}{\sum_{i=1}^{n} P(A|B_i) P(B_i)}$$

> - 2023年：填空题考全概率公式

#### 1.1.7 事件的独立性

**定义**：
若 $P(AB) = P(A) \cdot P(B)$，则称A与B相互独立。

**性质**：
- 若A与B独立，则 $A$ 与 $\bar{B}$、$\bar{A}$ 与 $B$、$\bar{A}$ 与 $\bar{B}$ 也独立
- 若A与B独立，则 $P(A|B) = P(A)$

**三事件独立**：
A、B、C相互独立 $\Leftrightarrow$ 两两独立 + $P(ABC) = P(A)P(B)P(C)$

### 1.2 随机变量及其分布

#### 1.2.1 随机变量的定义

设随机试验的样本空间为 $\Omega$，若对每个 $\omega \in \Omega$，都有唯一的实数 $X(\omega)$ 与之对应，则称 $X(\omega)$ 为随机变量。

#### 1.2.2 离散型随机变量

**分布律**：$P(X = x_k) = p_k$，$k = 1, 2, \ldots$

**常见离散分布**：

| 分布 | 记号 | 分布律 | 期望 | 方差 |
|------|------|--------|------|------|
| 两点分布 | $B(1, p)$ | $P(X=1)=p$，$P(X=0)=1-p$ | $p$ | $p(1-p)$ |
| 二项分布 | $B(n, p)$ | $P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| 泊松分布 | $P(\lambda)$ | $P(X=k)=\frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ |

#### 1.2.3 连续型随机变量

**概率密度函数** $f(x)$ 的性质：
1. $f(x) \geq 0$
2. $\int_{-\infty}^{+\infty} f(x) dx = 1$
3. $P(a < X \leq b) = \int_a^b f(x) dx$

**分布函数**：$F(x) = P(X \leq x) = \int_{-\infty}^x f(t) dt$

**常见连续分布**：

| 分布 | 记号 | 密度函数 | 期望 | 方差 |
|------|------|----------|------|------|
| 均匀分布 | $U(a, b)$ | $f(x) = \frac{1}{b-a}$，$a \leq x \leq b$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| 指数分布 | $E(\lambda)$ | $f(x) = \lambda e^{-\lambda x}$，$x > 0$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| 正态分布 | $N(\mu, \sigma^2)$ | $f(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

**标准正态分布**：$N(0, 1)$
- $\Phi(-x) = 1 - \Phi(x)$
- $P(a < X < b) = \Phi(b) - \Phi(a)$

### 1.3 多维随机变量

#### 1.3.1 联合分布

**联合分布函数**：
$$F(x, y) = P(X \leq x, Y \leq y)$$

**联合概率密度**：$f(x, y)$ 满足
1. $f(x, y) \geq 0$
2. $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$

#### 1.3.2 边缘分布

**边缘分布函数**：
$$F_X(x) = F(x, +\infty), \quad F_Y(y) = F(+\infty, y)$$

**边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy, \quad f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

#### 1.3.3 条件分布

**条件概率密度**：
$$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}, \quad f_Y(y) > 0$$

#### 1.3.4 独立性

X与Y相互独立 $\Leftrightarrow$ $F(x, y) = F_X(x) \cdot F_Y(y)$ $\Leftrightarrow$ $f(x, y) = f_X(x) \cdot f_Y(y)$

### 1.4 随机变量的数字特征

#### 1.4.1 数学期望

**定义**：
- 离散：$E(X) = \sum_{k} x_k p_k$
- 连续：$E(X) = \int_{-\infty}^{+\infty} x f(x) \, dx$

**性质**：
1. $E(C) = C$（常数）
2. $E(aX + bY) = aE(X) + bE(Y)$（线性性）
3. 若X、Y独立，则 $E(XY) = E(X) \cdot E(Y)$

#### 1.4.2 方差

**定义**：$D(X) = E[(X - E(X))^2] = E(X^2) - [E(X)]^2$

**性质**：
1. $D(C) = 0$
2. $D(aX + b) = a^2 D(X)$
3. $D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X, Y)$
4. 若X、Y独立，则 $D(X \pm Y) = D(X) + D(Y)$

#### 1.4.3 协方差与相关系数

**协方差**：
$$\text{Cov}(X, Y) = E(XY) - E(X)E(Y)$$

**相关系数**：
$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)} \cdot \sqrt{D(Y)}}$$

**性质**：
- $|\rho_{XY}| \leq 1$
- $\rho_{XY} = 0$ 称为不相关
- 独立 $\Rightarrow$ 不相关，但不相关 $\nRightarrow$ 独立（正态分布除外）

### 1.5 大数定律与中心极限定理

#### 1.5.1 切比雪夫不等式

$$P(|X - E(X)| \geq \varepsilon) \leq \frac{D(X)}{\varepsilon^2}$$

#### 1.5.2 大数定律

**切比雪夫大数定律**：若 $E(X_i) = \mu$，$D(X_i) \leq C$，则：
$$\frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{P} \mu$$

**辛钦大数定律**：若 $E(X_i) = \mu$，则：
$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{P} \mu$$

#### 1.5.3 中心极限定理

**列维-林德伯格定理**：若 $X_i$ 独立同分布，$E(X_i) = \mu$，$D(X_i) = \sigma^2$，则：
$$\frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{d} N(0, 1)$$

> [!warning] 易错点
> 中心极限定理要求 $X_i$ **独立同分布**，不仅仅是期望相同！

## 二、数理统计基础

### 2.1 基本概念

#### 2.1.1 总体与样本

- **总体**：研究对象的全体
- **样本**：从总体中抽取的部分个体
- **简单随机样本**：独立同分布的样本

#### 2.1.2 统计量

**定义**：样本的函数，不含未知参数

**常用统计量**：
- 样本均值：$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$
- 样本方差：$S^2 = \frac{1}{n-1}\sum_{i=1}^{n} (X_i - \bar{X})^2$
- 样本标准差：$S = \sqrt{S^2}$

#### 2.1.3 抽样分布

**三大抽样分布**：

| 分布 | 定义 | 性质 |
|------|------|------|
| $\chi^2$分布 | $\chi^2 = \sum_{i=1}^{n} X_i^2$，$X_i \sim N(0,1)$ | $E(\chi^2) = n$，$D(\chi^2) = 2n$ |
| $t$分布 | $t = \frac{X}{\sqrt{Y/n}}$，$X \sim N(0,1)$，$Y \sim \chi^2(n)$ | 关于0对称，$n$大时近似正态 |
| $F$分布 | $F = \frac{X/n_1}{Y/n_2}$，$X \sim \chi^2(n_1)$，$Y \sim \chi^2(n_2)$ | $F \sim F(n_1, n_2)$ |

**重要定理**：
- $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$
- $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
- $\bar{X}$ 与 $S^2$ 独立

### 2.2 参数估计

#### 2.2.1 点估计

**矩估计法**：
1. 计算总体的各阶矩
2. 用样本矩代替总体矩
3. 解方程得估计量

**最大似然估计法**：
1. 写出似然函数 $L(\theta) = \prod_{i=1}^{n} f(x_i; \theta)$
2. 取对数 $\ln L(\theta)$
3. 求导令其为0，解得 $\hat{\theta}$

#### 2.2.2 估计量的评价标准

| 标准 | 定义 | 判断方法 |
|------|------|----------|
| **无偏性** | $E(\hat{\theta}) = \theta$ | 计算期望 |
| **有效性** | 方差最小 | 比较方差 |
| **一致性** | $\hat{\theta} \xrightarrow{P} \theta$ | 大数定律 |

### 2.3 假设检验

#### 2.3.1 基本概念

- **原假设** $H_0$：待检验的假设
- **备择假设** $H_1$：与 $H_0$ 对立的假设
- **第一类错误**（弃真）：$H_0$ 为真，拒绝 $H_0$，概率为 $\alpha$
- **第二类错误**（取伪）：$H_0$ 为假，接受 $H_0$，概率为 $\beta$

#### 2.3.2 常用检验方法

| 检验方法 | 适用条件 | 检验统计量 |
|----------|----------|------------|
| $Z$检验 | 方差已知，检验均值 | $Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}}$ |
| $t$检验 | 方差未知，检验均值 | $t = \frac{\bar{X} - \mu_0}{S / \sqrt{n}}$ |
| $\chi^2$检验 | 检验方差 | $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$ |
| $F$检验 | 比较两总体方差 | $F = \frac{S_1^2}{S_2^2}$ |

> [!warning] 易错点
> - 同时降低 $\alpha$ 和 $\beta$ 的唯一方法是增大样本容量 $n$
> - $\alpha$ 和 $\beta$ 在 $n$ 固定时此消彼长

## 三、线性代数基础

### 3.1 行列式

#### 3.1.1 行列式的性质

1. 转置不变：$|A^T| = |A|$
2. 行列互换：交换两行（列），行列式变号
3. 数乘：某行（列）乘 $k$，行列式乘 $k$
4. 拆分：某行（列）可拆分为两行（列）之和
5. 倍加：某行（列）加另一行（列）的倍数，行列式不变

#### 3.1.2 行列式的计算

**常用方法**：
- 对角线法则（2阶、3阶）
- 按行（列）展开
- 化为上三角行列式

### 3.2 矩阵

#### 3.2.1 矩阵运算

| 运算 | 条件 | 结果 |
|------|------|------|
| 加法 | 同型矩阵 | 对应元素相加 |
| 数乘 | 任意矩阵 | 每个元素乘数 |
| 乘法 | $A_{m \times n} \cdot B_{n \times p} = C_{m \times p}$ | 行乘列 |
| 转置 | 任意矩阵 | 行变列，列变行 |

#### 3.2.2 逆矩阵

**定义**：若 $AB = BA = E$，则 $B = A^{-1}$

**求法**：
- 伴随矩阵法：$A^{-1} = \frac{1}{|A|} A^*$
- 初等变换法：$(A | E) \xrightarrow{行变换} (E | A^{-1})$

**性质**：
- $(A^{-1})^{-1} = A$
- $(AB)^{-1} = B^{-1}A^{-1}$
- $(A^T)^{-1} = (A^{-1})^T$

#### 3.2.3 矩阵的秩

**定义**：矩阵中非零子式的最高阶数

**性质**：
- $r(A) \leq \min(m, n)$
- $r(A) = r(A^T)$
- $r(AB) \leq \min(r(A), r(B))$

### 3.3 向量

#### 3.3.1 线性相关与线性无关

**定义**：若存在不全为0的 $k_1, k_2, \ldots, k_n$ 使得 $k_1\alpha_1 + k_2\alpha_2 + \cdots + k_n\alpha_n = 0$，则线性相关。

**判断方法**：
- 定义法
- 秩的方法：$r(\alpha_1, \alpha_2, \ldots, \alpha_n) < n$ 则相关

#### 3.3.2 向量组的秩

**定义**：极大线性无关组中向量的个数

### 3.4 线性方程组

#### 3.4.1 齐次方程组 $Ax = 0$

**解的情况**：
- 只有零解 $\Leftrightarrow$ $r(A) = n$
- 有非零解 $\Leftrightarrow$ $r(A) < n$

**基础解系**：$n - r(A)$ 个线性无关的解向量

#### 3.4.2 非齐次方程组 $Ax = b$

**解的情况**：
- 无解 $\Leftrightarrow$ $r(A) < r(A|b)$
- 唯一解 $\Leftrightarrow$ $r(A) = r(A|b) = n$
- 无穷多解 $\Leftrightarrow$ $r(A) = r(A|b) < n$

**解的结构**：通解 = 特解 + 齐次通解

> [!tip] 真题考点
> - 2021年：选择题考齐次方程组解的情况

### 3.5 特征值与特征向量

#### 3.5.1 定义

若 $Ax = \lambda x$，$x \neq 0$，则 $\lambda$ 为特征值，$x$ 为对应的特征向量。

#### 3.5.2 求法

1. 求特征方程 $|A - \lambda E| = 0$ 的根
2. 对每个 $\lambda$，求 $(A - \lambda E)x = 0$ 的基础解系

#### 3.5.3 性质

- $\sum \lambda_i = \sum a_{ii}$（迹）
- $\prod \lambda_i = |A|$
- 不同特征值对应的特征向量线性无关

#### 3.5.4 相似对角化

A可对角化 $\Leftrightarrow$ A有n个线性无关的特征向量

若A可对角化，则 $A = P\Lambda P^{-1}$，其中 $\Lambda = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$

### 3.6 二次型

#### 3.6.1 二次型的标准形

$f = x^TAx$，通过正交变换 $x = Py$ 化为标准形 $f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2$

#### 3.6.2 正定性

**正定的充要条件**：
- 所有特征值 > 0
- 所有顺序主子式 > 0
