## 、数据结构基本概念

### .1 基本术语

| 术语 | 定义 |
|------|------|
| **数据** | 信息的载体，能被计算机识别、存储和处理 |
| **数据元素** | 数据的基本单位 |
| **数据项** | 数据元素中不可分割的最小单位 |
| **数据对象** | 性质相同的数据元素的集合 |
| **数据结构** | 相互之间存在特定关系的数据元素的集合 |

### .2 数据结构三要素

| 要素 | 说明 | 分类 |
|------|------|------|
| **逻辑结构** | 数据元素之间的逻辑关系 | 集合、线性、树形、图形 |
| **存储结构** | 数据在内存中的表示 | 顺序、链式、索引、散列 |
| **数据运算** | 对数据的操作 | 增、删、改、查 |

### .3 算法与算法分析

#### .3.1 算法的特性

| 特性 | 说明 |
|------|------|
| **有穷性** | 有限步骤内终止 |
| **确定性** | 每步含义明确，无歧义 |
| **可行性** | 每步都能执行 |
| **输入** | 0个或多个输入 |
| **输出** | 1个或多个输出 |

#### .3.2 时间复杂度

**定义**：算法中基本操作的执行次数与问题规模 $n$ 的关系

**常见时间复杂度**（从小到大）：
$$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$

**常见算法的时间复杂度**：

| 算法 | 最好 | 平均 | 最坏 |
|------|------|------|------|
| 冒泡排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ |
| 快速排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ |
| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ |
| 顺序查找 | $O(1)$ | $O(n)$ | $O(n)$ |
| 折半查找 | $O(1)$ | $O(\log n)$ | $O(\log n)$ |

#### .3.3 空间复杂度

**定义**：算法执行过程中所需的额外存储空间与问题规模 $n$ 的关系

## 、线性结构

### .1 线性表

#### .1.1 线性表的定义

线性表是具有相同数据类型的 $n$ 个数据元素的有限序列。

**特点**：
- 有且仅有一个"第一个"元素（首元素）
- 有且仅有一个"最后一个"元素（尾元素）
- 除首元素外，每个元素有且仅有一个前驱
- 除尾元素外，每个元素有且仅有一个后继

#### .1.2 顺序存储（顺序表）

**定义**：用一段地址连续的存储单元依次存储线性表的数据元素

**实现**（C语言）：
```c
#define MaxSize 100
typedef struct {
    int data[MaxSize];
    int length;
} SqList;
```

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 随机访问 $O(1)$ | 插入删除需移动元素 $O(n)$ |
| 存储密度高 | 需预分配空间 |

**基本操作时间复杂度**：

| 操作 | 时间复杂度 |
|------|------------|
| 按位查找 | $O(1)$ |
| 按值查找 | $O(n)$ |
| 插入 | $O(n)$ |
| 删除 | $O(n)$ |

#### .1.3 链式存储（链表）

**单链表**：
```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

**双向链表**：
```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

**循环链表**：尾节点的next指向头节点

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 插入删除 $O(1)$（已知位置） | 不支持随机访问 |
| 动态分配，无溢出 | 存储密度低（指针开销） |

### .2 栈

#### .2.1 栈的定义

**后进先出**（LIFO）的线性表

**基本操作**：
- `Push`：入栈
- `Pop`：出栈
- `GetTop`：取栈顶

#### .2.2 顺序栈

```c
#define MaxSize 100
typedef struct {
    int data[MaxSize];
    int top;
} SqStack;
```

#### .2.3 链栈

```c
typedef struct StackNode {
    int data;
    struct StackNode *next;
} StackNode, *LinkStack;
```

#### .2.4 栈的应用

1. **表达式求值**：中缀转后缀，后缀表达式计算
2. **括号匹配**：检查括号是否配对
3. **递归转非递归**：用栈模拟递归调用

### .3 队列

#### .3.1 队列的定义

**先进先出**（FIFO）的线性表

**基本操作**：
- `EnQueue`：入队
- `DeQueue`：出队
- `GetHead`：取队头

#### .3.2 循环队列

```c
#define MaxSize 100
typedef struct {
    int data[MaxSize];
    int front, rear;
} SqQueue;
```

**判空/判满条件**：
- 空：`front == rear`
- 满：`(rear + 1) % MaxSize == front`
- 元素个数：`(rear - front + MaxSize) % MaxSize`

#### .3.3 队列的应用

1. **BFS**：广度优先搜索
2. **操作系统**：进程调度、打印队列
3. **缓冲区**：数据缓冲

### .4 数组与矩阵

#### .4.1 数组的存储

**行优先存储**（C语言）：
$$\text{LOC}(a_{i,j}) = \text{LOC}(a_{0,0}) + (i \times n + j) \times L$$

**列优先存储**：
$$\text{LOC}(a_{i,j}) = \text{LOC}(a_{0,0}) + (j \times m + i) \times L$$

#### .4.2 特殊矩阵的压缩存储

**对称矩阵**：只存下三角（或上三角）
$$k = \frac{i(i+1)}{2} + j \quad (i \geq j)$$

**三角矩阵**：类似对称矩阵

**稀疏矩阵**：三元组表
```c
typedef struct {
    int row, col;
    int value;
} Triple;
```

## 、非线性结构

### .1 树

#### .1.1 基本术语

| 术语 | 定义 |
|------|------|
| **度** | 节点的子树个数 |
| **叶子节点** | 度为0的节点 |
| **深度** | 根到该节点的路径长度 |
| **高度** | 该节点到最远叶子的路径长度 |
| **有序树** | 子树有左右之分 |

#### .1.2 树的存储结构

1. **双亲表示法**：每个节点存储其父节点位置
2. **孩子表示法**：每个节点存储其所有孩子
3. **孩子兄弟表示法**：左孩子右兄弟

### .2 二叉树

#### .2.1 二叉树的定义

每个节点至多有两棵子树，且子树有左右之分。

**特殊二叉树**：
- **满二叉树**：每层节点数都达到最大
- **完全二叉树**：除最后一层外都满，最后一层从左到右连续

#### .2.2 二叉树的性质

1. 第 $i$ 层最多有 $2^{i-1}$ 个节点
2. 深度为 $h$ 的二叉树最多有 $2^h - 1$ 个节点
3. $n_0 = n_2 + 1$（叶子节点数 = 度为2的节点数 + 1）
4. 完全二叉树中，$n$ 个节点的深度为 $\lfloor \log_2 n \rfloor + 1$
5. 完全二叉树中，节点 $i$ 的父节点为 $\lfloor i/2 \rfloor$，左孩子为 $2i$，右孩子为 $2i+1$

#### .2.3 二叉树的遍历

**递归遍历**：
```c
// 先序遍历
void PreOrder(BiTree T) {
    if (T == NULL) return;
    visit(T);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

// 中序遍历
void InOrder(BiTree T) {
    if (T == NULL) return;
    InOrder(T->lchild);
    visit(T);
    InOrder(T->rchild);
}

// 后序遍历
void PostOrder(BiTree T) {
    if (T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    visit(T);
}
```

**层次遍历**：使用队列

**由遍历序列构造二叉树**：
- 先序 + 中序 → 唯一二叉树
- 后序 + 中序 → 唯一二叉树
- 先序 + 后序 → 不唯一

#### .2.4 线索二叉树

**定义**：利用空指针存储前驱和后继信息

**结构**：
```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // 0: 指向孩子, 1: 指向前驱/后继
} ThreadNode, *ThreadTree;
```

> [!tip] 真题考点
> - 2020年：名词解释考树与二叉树
> - 2023年：证明题考二叉树性质
> - 2025年：算法题考线索二叉树插入

#### .2.5 二叉排序树（BST）

**定义**：
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点
- 左右子树也分别是二叉排序树

**中序遍历**：得到递增序列

**查找**：平均 $O(\log n)$，最坏 $O(n)$

#### .2.6 平衡二叉树（AVL）

**定义**：任意节点的左右子树高度差不超过1

**平衡因子**：左子树高度 - 右子树高度

**旋转操作**：
- LL旋转（右旋）
- RR旋转（左旋）
- LR旋转（先左后右）
- RL旋转（先右后左）

#### .2.7 哈夫曼树

**定义**：带权路径长度（WPL）最小的二叉树

**构造方法**（哈夫曼算法）：
1. 将 $n$ 个节点作为 $n$ 棵只有根的树
2. 选取权值最小的两棵树合并
3. 重复步骤2，直到只剩一棵树

**哈夫曼编码**：左分支为0，右分支为1

**性质**：
- 没有度为1的节点
- $n$ 个叶子节点，共 $2n-1$ 个节点

> [!tip] 真题考点
> - 2022年：填空题考哈夫曼树叶子节点数和空指针数

### .3 图

#### .3.1 基本术语

| 术语 | 定义 |
|------|------|
| **顶点** | 图中的节点 |
| **边** | 顶点之间的连接 |
| **度** | 与顶点相连的边数 |
| **路径** | 顶点序列 |
| **连通图** | 任意两点间有路径 |
| **强连通图** | 有向图中任意两点互相可达 |

#### .3.2 图的存储结构

**邻接矩阵**：
```c
typedef struct {
    int vexs[MAXVEX];
    int arc[MAXVEX][MAXVEX];
    int vexNum, arcNum;
} MGraph;
```

**邻接表**：
```c
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *next;
} ArcNode;

typedef struct {
    int data;
    ArcNode *first;
} VNode, AdjList[MAXVEX];
```

**选择**：
- 稠密图 → 邻接矩阵
- 稀疏图 → 邻接表

#### .3.3 图的遍历

**深度优先搜索（DFS）**：
```c
void DFS(Graph G, int v) {
    visited[v] = 1;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
        if (!visited[w]) {
            DFS(G, w);
        }
    }
}
```

**广度优先搜索（BFS）**：
```c
void BFS(Graph G, int v) {
    Queue Q;
    InitQueue(&Q);
    visited[v] = 1;
    EnQueue(&Q, v);
    while (!isEmpty(Q)) {
        DeQueue(&Q, &v);
        for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
            if (!visited[w]) {
                visited[w] = 1;
                EnQueue(&Q, w);
            }
        }
    }
}
```

#### .3.4 最小生成树

**Prim算法**（适合稠密图）：
1. 从任意顶点开始
2. 选择权值最小的边连接新顶点
3. 重复直到所有顶点加入

**Kruskal算法**（适合稀疏图）：
1. 将边按权值排序
2. 依次选择不形成回路的边
3. 重复直到 $n-1$ 条边

#### .3.5 最短路径

**Dijkstra算法**（单源最短路径）：
- 时间复杂度：$O(n^2)$
- 不适用于负权边

**Floyd算法**（所有顶点对最短路径）：
- 时间复杂度：$O(n^3)$
- 可处理负权边（但不能有负权回路）

#### .3.6 拓扑排序

**定义**：将有向无环图（DAG）的所有顶点排成一个线性序列

**算法**：
1. 选择入度为0的顶点
2. 删除该顶点及其出边
3. 重复直到所有顶点输出（成功）或找不到入度为0的顶点（有环）

#### .3.7 关键路径

**定义**：从源点到汇点的最长路径

**相关概念**：
- 事件最早发生时间 $ve$
- 事件最迟发生时间 $vl$
- 活动最早开始时间 $e$
- 活动最迟开始时间 $l$
- 关键活动：$e = l$ 的活动

## 、查找算法

### .1 顺序查找

**基本思想**：从头到尾逐个比较

**平均查找长度**：
$$ASL = \frac{n+1}{2}$$

### .2 折半查找（二分查找）

**条件**：有序表

**算法**：
```c
int BinarySearch(int A[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (A[mid] == key) return mid;
        else if (A[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

**判定树**：$\lfloor \log_2 n \rfloor + 1$ 层

**平均查找长度**：$O(\log n)$

### .3 散列表

**散列函数构造**：
- 除留余数法：$H(key) = key \% p$
- 直接定址法：$H(key) = a \times key + b$

**冲突处理**：

| 方法 | 说明 |
|------|------|
| **线性探测** | 逐个向后探测 |
| **二次探测** | $\pm 1^2, \pm 2^2, \ldots$ |
| **链地址法** | 同义词用链表存储 |

**装填因子**：$\alpha = \frac{n}{m}$（$n$为元素个数，$m$为表长）

## 、排序算法

### .1 插入排序

**直接插入排序**：
```c
void InsertSort(int A[], int n) {
    for (int i = 1; i < n; i++) {
        int key = A[i];
        int j = i - 1;
        while (j >= 0 && A[j] > key) {
            A[j+1] = A[j];
            j--;
        }
        A[j+1] = key;
    }
}
```
- 时间：$O(n^2)$
- 空间：$O(1)$
- 稳定

**希尔排序**：
- 时间：$O(n^{1.3})$
- 不稳定

### .2 交换排序

**冒泡排序**：
- 时间：$O(n^2)$
- 空间：$O(1)$
- 稳定

**快速排序**：
```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivot = Partition(A, low, high);
        QuickSort(A, low, pivot - 1);
        QuickSort(A, pivot + 1, high);
    }
}
```
- 平均：$O(n \log n)$
- 最坏：$O(n^2)$
- 空间：$O(\log n)$（平均），$O(n)$（最坏）
- 不稳定

### .3 选择排序

**简单选择排序**：
- 时间：$O(n^2)$
- 空间：$O(1)$
- 不稳定

**堆排序**：
```c
void HeapAdjust(int A[], int k, int n) {
    int temp = A[k];
    for (int i = 2*k+1; i < n; i = 2*i+1) {
        if (i+1 < n && A[i] < A[i+1]) i++;
        if (temp >= A[i]) break;
        A[k] = A[i];
        k = i;
    }
    A[k] = temp;
}

void HeapSort(int A[], int n) {
    // 建堆
    for (int i = n/2-1; i >= 0; i--) {
        HeapAdjust(A, i, n);
    }
    // 排序
    for (int i = n-1; i > 0; i--) {
        swap(A[0], A[i]);
        HeapAdjust(A, 0, i);
    }
}
```
- 时间：$O(n \log n)$
- 空间：$O(1)$
- 不稳定

### .4 归并排序

**二路归并**：
- 时间：$O(n \log n)$
- 空间：$O(n)$
- 稳定

### .5 排序算法比较

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|----------|----------|------|--------|
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ |  |
| 插入排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ |  |
| 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ |  |
| 希尔排序 | $O(n^{1.3})$ | $O(n^2)$ | $O(1)$ |  |
| 快速排序 | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ |  |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ |  |
| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ |  |

## 、其他数据结构

### .1 串（String）

#### .1.1 基本概念

**定义**：由零个或多个字符组成的有限序列

**术语**：
- 串长：串中字符个数
- 空串：零个字符的串
- 子串：串中任意个连续字符组成的子序列
- 主串：包含子串的串
- 位置：字符在串中的序号

#### .1.2 存储结构

| 方式 | 说明 | 优缺点 |
|------|------|--------|
| 定长顺序存储 | 固定长度数组 | 简单，可能浪费空间 |
| 堆分配存储 | 动态分配 | 灵活，需要管理内存 |
| 链式存储 | 链表存储 | 插入删除方便，存储密度低 |

#### .1.3 模式匹配

**朴素模式匹配**（BF算法）：
- 时间复杂度：$O(m \times n)$
- 思想：逐个字符比较，失配时回溯

**KMP算法**：
- 时间复杂度：$O(m + n)$
- 思想：利用next数组，失配时不回溯
- next数组：记录模式串中每个位置的最长相等前后缀长度

### .2 广义表

#### .2.1 定义

广义表是 $n$ 个元素的有限序列，其中每个元素可以是原子或广义表。

**示例**：
- $A = ()$：空表
- $B = (a, b, c)$：三个原子
- $C = (a, (b, c))$：原子和子表
- $D = (A, B, C)$：表中表

#### .2.2 基本操作

| 操作 | 说明 |
|------|------|
| `head(L)` | 取表头（第一个元素） |
| `tail(L)` | 取表尾（除第一个外的元素） |
| `length(L)` | 求表长度 |
| `depth(L)` | 求表深度 |

### .3 分块查找

#### .3.1 基本思想

将表分为若干块，块间有序，块内无序。

**步骤**：
1. 在索引表中确定目标所在的块
2. 在块内顺序查找

#### .3.2 性能分析

**平均查找长度**：
$$ASL = \frac{b+1}{2} + \frac{s+1}{2}$$
其中 $b$ 为块数，$s$ 为每块元素数。

**最优块大小**：$s = \sqrt{n}
此时 $ASL_{min} = \sqrt{n} + 1$

### .4 B树

#### .4.1 定义

B树是一种平衡的多路查找树。

**m阶B树性质**：
1. 每个节点最多有 $m$ 棵子树
2. 除根节点外，每个节点至少有 $\lceil m/2 \rceil$ 棵子树
3. 根节点至少有 2 棵子树（除非是叶子）
4. 所有叶子节点在同一层
5. 有 $k$ 棵子树的节点有 $k-1$ 个关键字

#### .4.2 查找操作

从根节点开始，在节点内顺序或折半查找，找到则成功，否则沿指针向下继续查找。

**时间复杂度**：$O(\log n)$

#### .4.3 插入操作

1. 找到插入位置
2. 若节点未满，直接插入
3. 若节点满，分裂节点

#### .4.4 删除操作

1. 找到关键字
2. 若在叶子节点，直接删除
3. 若在内部节点，用前驱或后继替换
4. 若删除后节点关键字不足，需要合并或借位

### .5 B+树

#### .5.1 与B树的区别

| 特性 | B树 | B+树 |
|------|-----|------|
| 关键字 | 每个节点都有 | 只在叶子节点 |
| 叶子链表 | 无 | 有 |
| 查找 | 不稳定 | 稳定 |
| 范围查询 | 不方便 | 方便 |

#### .5.2 应用

- 数据库索引（MySQL InnoDB）
- 文件系统

## 、资源管理技术（操作系统基础）

> 考纲明确要求掌握“资源管理技术”，这是操作系统的核心内容。

### .1 操作系统概述

#### .1.1 操作系统的定义

操作系统是管理计算机硬件与软件资源的系统软件，是用户与计算机之间的接口。

#### .1.2 操作系统的功能

| 功能 | 说明 |
|------|------|
| **进程管理** | 进程调度、同步、通信 |
| **内存管理** | 内存分配、回收、虚拟内存 |
| **设备管理** | I/O设备分配、控制 |
| **文件管理** | 文件存储、检索、保护 |

### .2 进程与线程

#### .2.1 进程

**定义**：程序的一次执行，是系统资源分配的基本单位。

**进程控制块（PCB）**：
| 信息 | 说明 |
|------|------|
| 进程标识符 | PID |
| 进程状态 | 就绪、运行、阻塞 |
| 程序计数器 | 下一条指令地址 |
| 寄存器 | CPU寄存器内容 |
| 内存信息 | 页表、段表 |
| I/O状态 | 打开的文件、设备 |

**进程状态转换**：
```
        ┌─────────┐
        │  创建   │
        └────┬────┘
             ↓
        ┌─────────┐
    ┌──→│  就绪   │←──┐
    │   └────┬────┘   │
    │        ↓        │
    │   ┌─────────┐   │
    │   │  运行   │   │
    │   └────┬────┘   │
    │        ↓        │
    │   ┌─────────┐   │
    └───│  阻塞   │───┘
        └────┬────┘
             ↓
        ┌─────────┐
        │  终止   │
        └─────────┘
```

**转换条件**：
- 就绪 → 运行：被调度程序选中
- 运行 → 就绪：时间片用完
- 运行 → 阻塞：等待I/O或事件
- 阻塞 → 就绪：I/O完成或事件发生

#### .2.2 线程

**定义**：轻量级进程，是CPU调度的基本单位。

**进程 vs 线程**：

| 对比项 | 进程 | 线程 |
|--------|------|------|
| 资源分配 | 基本单位 | 不分配 |
| CPU调度 | 不直接调度 | 基本单位 |
| 地址空间 | 独立 | 共享进程的 |
| 开销 | 大 | 小 |
| 通信 | IPC | 直接共享内存 |

**线程的实现方式**：
- 用户级线程：用户空间实现，切换不需内核
- 内核级线程：内核实现，切换需要内核

### .3 进程调度

#### .3.1 调度层次

| 层次 | 频率 | 功能 |
|------|------|------|
| 高级调度 | 低 | 作业调度 |
| 中级调度 | 中 | 内存调度 |
| 低级调度 | 高 | CPU调度 |

#### .3.2 调度算法

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| FCFS（先来先服务） | 简单，不利于短作业 | 批处理 |
| SJF（短作业优先） | 平均等待时间短 | 批处理 |
| 优先级调度 | 灵活，可能饥饿 | 实时系统 |
| 时间片轮转 | 公平，适合交互 | 分时系统 |
| 多级反馈队列 | 综合优点 | 通用系统 |

### .4 进程同步与互斥

#### .4.1 基本概念

| 概念 | 说明 |
|------|------|
| **临界资源** | 一次只允许一个进程使用的资源 |
| **临界区** | 访问临界资源的代码段 |
| **互斥** | 不能同时进入临界区 |
| **同步** | 按一定顺序执行 |

#### .4.2 实现方法

**软件方法**：
- Peterson算法
- Dekker算法

**硬件方法**：
- 关中断
- TestAndSet指令
- Swap指令

**信号量机制**：
```c
// P操作（申请资源）
wait(S) {
    S--;
    if (S < 0) {
        阻塞当前进程;
    }
}

// V操作（释放资源）
signal(S) {
    S++;
    if (S <= 0) {
        唤醒一个阻塞进程;
    }
}
```

**经典问题**：
- 生产者-消费者问题
- 读者-写者问题
- 哲学家就餐问题

### .5 内存管理

#### .5.1 内存分配方式

| 方式 | 说明 | 优缺点 |
|------|------|--------|
| **连续分配** | 进程占用连续内存 | 简单，有碎片 |
| **分页存储** | 内存分为固定大小的页 | 无外部碎片 |
| **分段存储** | 按逻辑分段 | 便于共享 |
| **段页式** | 先分段再分页 | 综合优点 |

#### .5.2 虚拟内存

**定义**：将主存和外存统一管理，程序使用虚拟地址。

**实现原理**：
- 局部性原理（时间局部性、空间局部性）
- 请求调页：需要时才调入内存
- 页面置换：内存满时换出页面

**页面置换算法**：

| 算法 | 说明 | 特点 |
|------|------|------|
| OPT | 最佳置换，选择最长时间不用的页 | 理论最优，无法实现 |
| FIFO | 先进先出 | 简单，可能Belady异常 |
| LRU | 最近最少使用 | 性能好，实现复杂 |
| Clock | 改进的FIFO | 近似LRU，开销小 |

#### .5.3 地址转换

**虚拟地址 = 页号 + 页内偏移**

**地址转换过程**：
1. 从虚拟地址提取页号
2. 查页表得到物理页号
3. 物理地址 = 物理页号 × 页大小 + 页内偏移

### .6 设备管理

#### .6.1 I/O控制方式

| 方式 | 特点 | CPU参与程度 |
|------|------|-------------|
| 程序查询 | 忙等待 | 高 |
| 中断驱动 | 事件驱动 | 中 |
| DMA | 直接内存访问 | 低 |
| 通道 | 专用处理器 | 最低 |

#### .6.2 缓冲技术

**目的**：解决CPU与I/O设备速度不匹配问题

**缓冲类型**：
- 单缓冲
- 双缓冲
- 循环缓冲
- 缓冲池

### .7 文件管理

#### .7.1 文件目录

| 结构 | 说明 |
|------|------|
| 单级目录 | 所有文件在同一目录 |
| 两级目录 | 主文件目录 + 用户目录 |
| 树形目录 | 层次结构，便于组织 |

#### .7.2 磁盘调度

**磁盘访问时间**：
- 寻道时间：磁头移动到目标磁道
- 旋转延迟：等待目标扇区转到磁头下
- 传输时间：数据读写时间

**磁盘调度算法**：

| 算法 | 说明 | 特点 |
|------|------|------|
| FCFS | 先来先服务 | 公平，移动距离大 |
| SSTF | 最短寻道时间优先 | 移动距离小，可能饥饿 |
| SCAN | 电梯算法 | 不会饥饿，移动距离适中 |
| C-SCAN | 循环扫描 | 更加公平 |

| 3NF | 满足2NF，消除传递依赖 | 消除传递函数依赖 |
| BCNF | 每个决定因素都是候选键 | 更强的规范化 |
