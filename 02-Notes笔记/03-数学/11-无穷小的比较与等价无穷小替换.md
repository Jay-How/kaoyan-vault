# 11 无穷小的比较与等价无穷小替换

> [!summary] 摘要
> 无穷小的比较就是**比趋于零的速度谁快谁慢**；结尾的**等价无穷小替换**是求极限计算题的必用技巧（高数偏重计算，证明题相对少）。
>
> - **五种比较**：高阶 $\beta = o(\alpha)$、低阶、同阶、等价 $\beta \sim \alpha$、$k$ 阶，都由 $\lim \dfrac{\beta}{\alpha}$（或 $\dfrac{\beta}{\alpha^k}$）的值决定，**必须指明变化过程**。
> - **等价替换**：$\alpha \sim \alpha'$、$\beta \sim \beta'$ 且 $\lim \dfrac{\beta'}{\alpha'}$ 存在时，$\lim \dfrac{\beta}{\alpha} = \lim \dfrac{\beta'}{\alpha'}$；公式里的 $x$ 可以**整体替换**为任何趋于 0 的式子。
> - **替换的规矩**：相乘（相除）的因式可以单独替换、也可以只换一半；**相加减一般不能替换**。

## 一、无穷小的比较：比趋于零的速度

### 1. 三个引例

无穷小即极限为 $0$ 的量。比较两个无穷小，就是比较它们**趋于零的速度谁快谁慢**。

- **引例 1**：$x \to 0$ 时，$x^2$ 与 $3x$ 都是无穷小。约掉一个 $x$：
  $$
  \lim_{x \to 0} \frac{x^2}{3x} = \lim_{x \to 0} \frac{x}{3} = 0
  $$
  说明 $x^2$ 比 $3x$ 趋于零的速度**快**。
- **引例 2**：$x \to 0$ 时，
  $$
  \lim_{x \to 0} \frac{x^3}{x} = \lim_{x \to 0} x^2 = 0
  $$
  说明 $x^3$ 比 $x$ 趋于零的速度**快**。取 $x = 0.1$ 验证：$x^3 = 0.001$，确实比 $0.1$ 小得多。
- **引例 3**：$x \to 0$ 时，由第一重要极限 $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ 可得
  $$
  \lim_{x \to 0} \frac{\sin x}{3x} = \frac13
  $$
  比值是个非零常数，说明 $\sin x$ 与 $3x$ 趋于零的速度**差不多**。

> [!tip] 一句话
> 无穷小的比较＝比较趋于零的速度：比值极限是 $0$ 说明分子快，是 $\infty$ 说明分子慢，是非零常数说明"差不多快"。

## 二、无穷小比较的五种定义

以下 $\alpha$、$\beta$ 都是同一变化过程中的无穷小（$x \to x_0$、$x \to \infty$、$n \to \infty$ 等，看具体题目），$\lim$ 均指这个变化过程。

### 1. 高阶无穷小

若
$$
\lim \frac{\beta}{\alpha} = 0
$$
则称 $\beta$ 是比 $\alpha$ **高阶**的无穷小，记作
$$
\beta = o(\alpha)
$$

理解：比值趋于 $0$，说明 $\beta$ 比 $\alpha$ 趋于零的速度**快**。从次数上看，$x^3$ 比 $x$ 的"阶数"高，所以叫高阶。

> [!warning] 记号 $o(\alpha)$ 不是"$0$ 乘以 $\alpha$"
> $\beta = o(\alpha)$ 只是"$\beta$ 是比 $\alpha$ 高阶的无穷小"的**记号**。其中 $o$ 是小写的斜体字母（不是数字 $0$，手写时写得比 $0$ 稍小一点），$o(\alpha)$ 泛指所有比 $\alpha$ 高阶的无穷小，不代表某个确定的式子。

### 2. 低阶无穷小

若
$$
\lim \frac{\beta}{\alpha} = \infty
$$
则称 $\beta$ 是比 $\alpha$ **低阶**的无穷小（$\beta$ 趋于零更慢）。

### 3. 同阶无穷小

若
$$
\lim \frac{\beta}{\alpha} = c \ne 0
$$
（$c$ 是非零常数），则称 $\beta$ 与 $\alpha$ 是**同阶**无穷小。

> [!tip] 不在乎是几倍，在乎阶数
> 极限是 $\dfrac13$ 还是 $2$ 都无所谓——比较的是趋于零的**速度**（阶数），常数倍数不影响"快慢"。$x \to 0$ 时 $x^3$ 与 $x$ 的差别是阶数；$\sin x$ 与 $3x$ 只是倍数上的差别。

### 4. 等价无穷小

若
$$
\lim \frac{\beta}{\alpha} = 1
$$
则称 $\beta$ 与 $\alpha$ 是**等价无穷小**，记作
$$
\beta \sim \alpha
$$

等价无穷小是同阶无穷小中 $c = 1$ 的**特殊情况**。由于做题时用得特别多，单独列为一种定义。

### 5. $k$ 阶无穷小

若
$$
\lim \frac{\beta}{\alpha^k} = c \ne 0 \qquad (k > 0)
$$
则称 $\beta$ 是关于 $\alpha$ 的 **$k$ 阶**无穷小。

> [!tip] 做题怎么用
> 题目说"证 $\beta$ 是 $\alpha$ 的二阶无穷小"，就取 $k = 2$，证 $\displaystyle \lim \frac{\beta}{\alpha^2} = c \ne 0$ 即可；说几阶就把 $k$ 取成几。

## 三、定义的常见例子

### 1. 例 1：$3x^2 = o(x)$（$x \to 0$）

$$
\lim_{x \to 0} \frac{3x^2}{x} = \lim_{x \to 0} 3x = 0
$$

所以 $x \to 0$ 时 $3x^2$ 是比 $x$ 高阶的无穷小，记作 $3x^2 = o(x)$。

> [!warning] 说"谁是谁的无穷小"必须指出变化过程
> 同一个式子换个过程结论就变。"$3x^2$ 是 $x$ 的高阶无穷小"必须说成"**$x \to 0$ 时**，$3x^2$ 是比 $x$ 高阶的无穷小"。

### 2. 例 2：$\dfrac1n$ 是比 $\dfrac{1}{n^2}$ 低阶的无穷小（$n \to \infty$）

$$
\lim_{n \to \infty} \frac{1/n}{1/n^2} = \lim_{n \to \infty} n = \infty
$$

分子趋于零更慢，是低阶的。

> [!tip] 记号说明
> 数列情形写 $n \to \infty$，含义就是 $n \to +\infty$（$n$ 只取正整数）。

### 3. 例 3：$x \to 3$ 时 $x^2 - 9$ 与 $x - 3$ 同阶

$x \to 3$ 时两者都趋于 $0$。分子用平方差公式分解：

$$
\lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} \frac{(x+3)(x-3)}{x-3} = \lim_{x \to 3} (x+3) = 6
$$

极限是 $6 \ne 0$，所以两者同阶。

> [!warning] 约分合法：趋于零 ≠ 等于零
> $x \to 3$ 时 $x$ 永远到不了 $3$，故 $x - 3$ 趋于 $0$ 但**不等于 0**，分子分母中的 $x - 3$ 可以约掉。

### 4. 例 4：$x \to 0$ 时 $1 - \cos x$ 是 $x$ 的二阶无穷小

由 [[10-极限存在准则与两个重要极限]] 的例 2：

$$
\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac12
$$

取 $k = 2$ 时极限是非零常数，故 $1 - \cos x$ 是 $x$ 的**二阶**无穷小，且 $1 - \cos x \sim \dfrac{x^2}{2}$。

> [!tip] 换个说法也对
> "$1 - \cos x$ 与 $x^2$ 是同阶无穷小"同样成立（比值极限是 $\dfrac12 \ne 0$）。

### 5. 例 5：$\sin x \sim x$（$x \to 0$）

由第一重要极限 $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ 直接得到，这是最常用的等价无穷小。

## 四、常用公式：$\sqrt[n]{1+x} - 1 \sim \dfrac{x}{n}$

课本例题：$x \to 0$ 时，$\sqrt[n]{1+x} - 1$ 与 $\dfrac{x}{n}$ 是等价无穷小（证明较繁琐，从略）。

做题中 $n$ 次根式很少见，最常用的是这两个特例：

$$
\sqrt{1+x} - 1 \sim \frac{x}{2}, \qquad \sqrt[3]{1+x} - 1 \sim \frac{x}{3} \qquad (x \to 0)
$$

**务必单独记住**：开平方对应 $\dfrac12 x$，开立方对应 $\dfrac13 x$。

## 五、定理：$\beta \sim \alpha \iff \beta = \alpha + o(\alpha)$

> [!important] 等价无穷小的刻画
> $$
> \beta \sim \alpha \quad\Longleftrightarrow\quad \beta = \alpha + o(\alpha)
> $$
> 其中 $o(\alpha)$ 表示比 $\alpha$ 高阶的无穷小，各处极限取同一个变化过程。

理解：$\beta \sim \alpha$ 说明两者"差不多"，$\alpha$ 是 $\beta$ 的主要部分，$o(\alpha)$ 就是那个无限小的"误差"。

### 1. 必要性（$\beta \sim \alpha \Rightarrow \beta = \alpha + o(\alpha)$）

由 $\beta \sim \alpha$ 得 $\lim \dfrac{\beta}{\alpha} = 1$，于是

$$
\lim \frac{\beta - \alpha}{\alpha} = \lim\left(\frac{\beta}{\alpha} - 1\right) = 1 - 1 = 0
$$

即 $\dfrac{\beta - \alpha}{\alpha}$ 的极限为 $0$，按高阶无穷小的定义，$\beta - \alpha$ 是比 $\alpha$ 高阶的无穷小，记作 $\beta - \alpha = o(\alpha)$。移项即

$$
\beta = \alpha + o(\alpha)
$$

### 2. 充分性（$\beta = \alpha + o(\alpha) \Rightarrow \beta \sim \alpha$）

把 $\beta = \alpha + o(\alpha)$ 代入：

$$
\lim \frac{\beta}{\alpha} = \lim \frac{\alpha + o(\alpha)}{\alpha} = \lim\left(1 + \frac{o(\alpha)}{\alpha}\right) = 1 + 0 = 1
$$

其中 $\dfrac{o(\alpha)}{\alpha} \to 0$ 正是高阶无穷小定义的**反向使用**。故 $\beta \sim \alpha$。

## 六、常见等价无穷小公式总结（$x \to 0$）

课本后面也会陆续给这些公式，但零散不成体系，这里一次总结到位，做题时直接查表替换。

| 等价无穷小（$x \to 0$） | 说明 |
| --- | --- |
| $\sin x \sim x$ | 第一重要极限 |
| $\tan x \sim x$ | |
| $\arcsin x \sim x$ | |
| $\arctan x \sim x$ | |
| $1 - \cos x \sim \dfrac12 x^2$ | 二阶无穷小 |
| $\cos x - 1 \sim -\dfrac12 x^2$ | 上一行取相反数 |
| $\sqrt{1+x} - 1 \sim \dfrac{x}{2}$ | |
| $\sqrt[3]{1+x} - 1 \sim \dfrac{x}{3}$ | |
| $1 - \sqrt{1+x} \sim -\dfrac{x}{2}$ | |
| $1 - \sqrt[3]{1+x} \sim -\dfrac{x}{3}$ | |
| $\ln(1+x) \sim x$ | |
| $e^x - 1 \sim x$ | |
| $1 - e^x \sim -x$ | |
| $a^x - 1 \sim x \ln a$ | $a > 0$ 且 $a \ne 1$ |
| $1 - a^x \sim -x \ln a$ | 同上 |

### 1. 从图形理解

大部分公式课本都给了证明，这里用图形建立直觉：

- $\sin x$、$\tan x$、$\arcsin x$、$\arctan x$ 的图像在 $x = 0$ 附近都与 $y = x$ 几乎重合（前两讲已画过）
- $\ln(1+x)$：由 $y = \ln x$ **左加右减**，左移 $1$ 个单位，在原点附近与 $y = x$ 几乎重合
- $e^x - 1$：由 $y = e^x$ **下移** $1$ 个单位，在原点附近与 $y = x$ 几乎重合
- $1 - \cos x$：把 $y = \cos x$ 取反再上移 $1$ 个单位，得到开口向上的小"碗"，所以它是**二阶**无穷小（$\sim \dfrac{x^2}{2}$），不是一阶

### 2. 正负号怎么记

出题时 $1 - \cos x$、$\cos x - 1$、$e^x - 1$、$1 - e^x$ 都可能出现，符号容易记混。判断依据是**被减数一定更大**：

- $\cos x \le 1$，所以 $1 - \cos x \ge 0$（正），$\cos x - 1 \le 0$（带负号）
- $x > 0$ 时 $e^x > 1$，所以 $e^x - 1 > 0$（正），$1 - e^x < 0$（带负号）

> [!tip] 正负两式成对记牢
> 把 $\alpha - \beta$ 与 $\beta - \alpha$ 一起记：后者就是前者加个负号。带负号的公式千万别漏符号，否则整题做反。

## 七、等价无穷小替换定理

### 1. 定理

> [!important] 等价无穷小替换
> 设 $\alpha \sim \alpha'$、$\beta \sim \beta'$，且 $\lim \dfrac{\beta'}{\alpha'}$ **存在**，则
> $$
> \lim \frac{\beta}{\alpha} = \lim \frac{\beta'}{\alpha'}
> $$

含义：求 $\dfrac{\beta}{\alpha}$ 的极限时，可以直接把分子换成 $\beta'$、分母换成 $\alpha'$（书上把 $\alpha'$、$\beta'$ 读作"阿尔法撇""贝塔撇"）。

### 2. 证明

给分子分母各配一个因子、拆成三个极限（各极限都存在，可用四则运算法则）：

$$
\lim \frac{\beta}{\alpha}
= \lim\left(\frac{\beta}{\beta'} \cdot \frac{\beta'}{\alpha'} \cdot \frac{\alpha'}{\alpha}\right)
= \underbrace{\lim \frac{\beta}{\beta'}}_{= 1} \cdot \lim \frac{\beta'}{\alpha'} \cdot \underbrace{\lim \frac{\alpha'}{\alpha}}_{= 1}
= \lim \frac{\beta'}{\alpha'}
$$

其中 $\beta \sim \beta'$、$\alpha \sim \alpha'$ 保证了前后两个极限都是 $1$。

### 3. 与第一重要极限的关系

有了等价替换，第一重要极限在计算中就很少直接用了：

$$
\lim_{x \to 0} \frac{\sin 2x}{\sin 3x}
= \lim_{x \to 0} \frac{2x}{3x}
= \frac23
$$

对比第 10 讲的解法（分子分母各凑 $\dfrac{\sin \square}{\square}$、再补系数）要绕两三步；用等价替换一步到位。

## 八、整体替换

### 1. 原理

公式里的 $x$ 可以换成**任何趋于 0 的整体** $\square$（里外、上下都换同一个）：

$$
\square \to 0 \text{ 时}, \qquad \sin\square \sim \square,\quad \tan\square \sim \square,\quad \ln(1 + \square) \sim \square,\ \cdots
$$

- $x \to 0$ 时：$\sin 3x \sim 3x$（$\square = 3x$）
- $x \to 1$ 时：$\sin(1-x) \sim 1-x$（$\square = 1-x$，它趋于 $0$）
- $\sin(1-x^2)$ 这类形式，整体就是 $1 - x^2$；$\tan$、根式、对数里的整体都照此办理

> [!tip] 做题几乎都是整体替换
> 原始公式里的形式往往不直接出现，一般都得先认出"整体"再替换。

### 2. 例 1：$\displaystyle \lim_{x \to 0} \frac{\tan 2x}{\sin 5x} = \frac25$

整体替换 $\tan 2x \sim 2x$、$\sin 5x \sim 5x$：

$$
\lim_{x \to 0} \frac{\tan 2x}{\sin 5x} = \lim_{x \to 0} \frac{2x}{5x} = \frac25
$$

### 3. 例 2：$\displaystyle \lim_{x \to 0} \frac{\sin x}{x^2 + 3x} = \frac13$

$\sin x$ 处于相乘（分子整体）的因式位置，可单独替换为 $x$；分母提出 $x$：

$$
\lim_{x \to 0} \frac{\sin x}{x^2 + 3x} = \lim_{x \to 0} \frac{x}{x(x+3)} = \lim_{x \to 0} \frac{1}{x+3} = \frac13
$$

### 4. 例 3：$\displaystyle \lim_{x \to 0} \frac{\sqrt[3]{1+x^2}-1}{\cos x - 1} = -\frac23$

- 分子：$\sqrt[3]{1 + \square} - 1 \sim \dfrac{\square}{3}$，此处 $\square = x^2$，故 $\sqrt[3]{1+x^2} - 1 \sim \dfrac{x^2}{3}$
- 分母：$\cos x - 1 \sim -\dfrac{x^2}{2}$

于是

$$
\lim_{x \to 0} \frac{\sqrt[3]{1+x^2}-1}{\cos x - 1} = \lim_{x \to 0} \frac{x^2/3}{-x^2/2} = \frac{1/3}{-1/2} = -\frac23
$$

## 九、替换的注意事项

### 1. 相乘（相除）的因式可以单独替换

定理里看着是分子分母"整个换掉"，实际做题时**只换分子或只换分母也行**，甚至只换某一个因式。

**例 1**：

$$
\lim_{x \to 0} \frac{x \sin x}{x^2} = \lim_{x \to 0} \frac{x \cdot x}{x^2} = 1
$$

只把 $\sin x$ 换成 $x$，分母 $x^2$ 一动没动。

**例 2**：

$$
\lim_{x \to 0} \frac{x \tan x (e^x - 1)}{\arcsin x \,(1 - \cos x)}
$$

四个因式替换、$x$ 不替换，$\tan x \to x$、$e^x - 1 \to x$、$\arcsin x \to x$、$1 - \cos x \to \dfrac{x^2}{2}$：

$$
\lim_{x \to 0} \frac{x \cdot x \cdot x}{x \cdot \dfrac{x^2}{2}} = \lim_{x \to 0} \frac{x^3}{x^3/2} = 2
$$

### 2. 相加减一般不能替换

**反例**：求 $\displaystyle \lim_{x \to 0} \frac{\tan x - \sin x}{x^3}$。

若把两个加减项都替换（$\tan x \to x$、$\sin x \to x$），分子变成 $x - x = 0$，会得出极限为 $0$——**这是错的**。相减时两个无穷小的"一阶部分"正好抵消，剩下更高阶的部分才决定结果，直接替换等于把它丢掉了。

正确做法：先提公因式（利用 $\sin x = \tan x \cos x$）化成相乘，再替换：

$$
\tan x - \sin x = \tan x(1 - \cos x)
$$

$$
\lim_{x \to 0} \frac{\tan x - \sin x}{x^3}
= \lim_{x \to 0} \frac{\tan x (1 - \cos x)}{x^3}
= \lim_{x \to 0} \frac{x \cdot \dfrac12 x^2}{x^3}
= \frac12
$$

真实答案是 $\dfrac12$，不是 $0$。

### 3. 预告：相加减何时能替换

> [!tip] 相加减满足一定条件时其实可以替换
> 相加减的替换需要验证附加条件，不满足就会像上面的反例一样"翻车"。初学阶段不要在加减项里直接替换——先化成相乘（提公因式、通分、有理化）再替换，永远稳妥。加减项替换的条件留待后续补充。

## 十、考点与易错点

> [!warning] 本节高频易错点
> - **必须指明变化过程**："$3x^2$ 是 $x$ 的高阶无穷小"要写成"**$x \to 0$ 时**……"，换个过程结论可能完全不同
> - **$o(\alpha)$ 是记号不是运算**：$\beta = o(\alpha)$ 不是"$0$ 乘 $\alpha$ 等于 $0$"，$o$ 是小写斜体字母
> - **等价是同阶的特例**：$\beta \sim \alpha$ 能推出同阶；同阶（$c \ne 1$）推不出等价
> - **替换只用于相乘（相除）的因式**：可以只换分子、只换分母，也可以只换其中一个因式
> - **相加减一般不能替换**：$\tan x - \sin x$ 的反例说明强行替换会得到 $0$ 而非 $\dfrac12$
> - **整体替换要求整体趋于 0**：$x \to 1$ 时用 $\square = 1 - x$，$\sin(1-x) \sim 1-x$，别死盯"$x \to 0$"
> - **替换定理要求 $\lim \dfrac{\beta'}{\alpha'}$ 存在**：换完极限不存在的，说明替换用错了地方
> - **带负号的公式别漏符号**：$\cos x - 1 \sim -\dfrac12 x^2$、$1 - e^x \sim -x$，与"正向"公式成对记

> 7. $x \to 1$ 时能把 $\sin(1-x)$ 替换成 $1 - x$ 吗？为什么？

> [!success]- 参考答案
> **1.** 同一变化过程下（$\lim$ 均指该过程）：
> $$\text{高阶：}\ \lim \frac{\beta}{\alpha} = 0,\ \text{记}\ \beta = o(\alpha) \qquad \text{低阶：}\ \lim \frac{\beta}{\alpha} = \infty$$
> $$\text{同阶：}\ \lim \frac{\beta}{\alpha} = c \ne 0 \qquad \text{等价：}\ \lim \frac{\beta}{\alpha} = 1,\ \text{记}\ \beta \sim \alpha$$
> $$\text{k 阶：}\ \lim \frac{\beta}{\alpha^k} = c \ne 0 \ (k > 0)$$
>
> **2.** 意思是"$x \to 0$ 时 $3x^2$ 是比 $x$ 高阶的无穷小"，即 $\lim\limits_{x \to 0} \dfrac{3x^2}{x} = 0$，$3x^2$ 趋于零更快。$o(x)$ **不是** $0$ 乘 $x$：$o$ 是小写斜体字母，$o(x)$ 是"比 $x$ 高阶的无穷小"这一类的记号，本身不是确定的式子。
>
> **3.** $\dfrac25$。整体替换 $\tan 3x \sim 3x$、$\sin 5x \sim 5x$，原式 $= \lim\limits_{x \to 0} \dfrac{3x}{5x} = \dfrac25$。
>
> **4.** $-\dfrac23$。分子 $\sqrt[3]{1+x^2}-1 \sim \dfrac{x^2}{3}$（整体是 $x^2$），分母 $\cos x - 1 \sim -\dfrac{x^2}{2}$，原式 $= \dfrac{x^2/3}{-x^2/2} = -\dfrac23$。
>
> **5.** 二阶：$\lim\limits_{x \to 0} \dfrac{1 - \cos x}{x^2} = \dfrac12 \ne 0$，取 $k = 2$ 即可；它与 $\dfrac{x^2}{2}$ 等价（$1 - \cos x \sim \dfrac12 x^2$）。
>
> **6.** 因为 $\tan x - \sin x$ 是**相减**：两个被减数都是一阶无穷小，一阶部分相减恰好抵消，剩下的高阶部分才决定极限。若强行替换，分子被替换成 $0$，把真实结果丢了。正确做法是先提公因式 $\tan x$（$\sin x = \tan x \cos x$）：
> $$\tan x - \sin x = \tan x(1 - \cos x) \sim x \cdot \frac{x^2}{2} = \frac{x^3}{2}$$
> 故极限为 $\dfrac12$。
>
> **7.** 可以。$x \to 1$ 时整体 $\square = 1 - x \to 0$，由 $\sin\square \sim \square$ 得 $\sin(1-x) \sim 1-x$。整体替换只要求**整体趋于 0**，不要求非得是 $x \to 0$。
