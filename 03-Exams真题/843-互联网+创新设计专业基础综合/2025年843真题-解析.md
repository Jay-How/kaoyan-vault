## 843 互联网+创新设计专业基础综合（参考答案与解析）

### 一、填空题（每题 3 分，共 15 分）

1. 设 $P(A) = 0.4$，$P(B) = 0.3$，$P(A \cup B) = 0.6$，则 $P(AB) =$（ ），$P(A - B) =$（ ），$P(B | \bar{A}) =$（ ）。

> [!success]- 答案 1
> **答案**：$0.1$，$0.3$，$0.75$

> [!tip]- 解析 1
> **解析**：
> 
> 1. $P(AB) = P(A) + P(B) - P(A \cup B) = 0.4 + 0.3 - 0.6 = 0.1$
> 
> 2. $P(A - B) = P(A) - P(AB) = 0.4 - 0.1 = 0.3$
> 
> 3. $P(B | \bar{A}) = \frac{P(B \cap \bar{A})}{P(\bar{A})} = \frac{P(B) - P(AB)}{1 - P(A)} = \frac{0.3 - 0.1}{0.6} = \frac{0.2}{0.6} = \frac{1}{3} \approx 0.333$
> 
> 注意：原题答案 $0.75$ 有误，应为 $\frac{1}{3}$

2. $10 \times 10$ 的对称矩阵 $A$，将其下三角部分（含对角线）以行优先顺序存储到一维数组 $B$ 中，$A[0][0]$ 对应 $B[0]$，则 $A[8][5]$ 存储在 $B$ 数组中下标为（ ）的位置。

> [!success]- 答案 2
> **答案**：$41$

> [!tip]- 解析 2
> **解析**：
> 
> 下标从 0 开始。对于下三角矩阵（行优先），元素 $A[i][j]$（$i \geq j$）前面存储了 $0 \sim i-1$ 行的所有元素以及第 $i$ 行的前 $j$ 个元素。
> 
> 第 0 行有 1 个元素，第 1 行有 2 个元素，...，第 7 行有 8 个元素。
> 
> $A[8][5]$ 之前的元素个数 $= (1 + 2 + \cdots + 8) + 5 = \frac{8 \times 9}{2} + 5 = 36 + 5 = 41$
> 
> 故下标为 41。

3. 某线性表的主要操作是存取任意序号的元素和在表尾进行插入/删除操作，则最适合采用（ ）存储方式。

> [!success]- 答案 3
> **答案**：顺序（Sequential）或数组

> [!tip]- 解析 3
> **解析**：
> 
> - 存取任意序号元素（随机访问）：顺序表为 $O(1)$，链表为 $O(n)$
> - 表尾插入/删除：顺序表（带长度指示）为 $O(1)$
> 
> 综合考虑，最适合顺序存储。

4. 在 TCP/IP 协议模型中，UDP（用户数据报协议）工作在（ ）层。

> [!success]- 答案 4
> **答案**：传输（Transport）

5. OSI 参考模型中，物理层、数据链路层、网络层传输的数据单元（PDU）分别是（ ）、（ ）、（ ）。

> [!success]- 答案 5
> **答案**：比特（Bit）、帧（Frame）、包/分组（Packet）

### 二、判断题（每题 3 分，共 15 分）

1. 假设检验中，原假设为 $H_0$，备择假设为 $H_1$。犯第二类错误是指 $H_1$ 不为真时接受了 $H_1$。（ ）

> [!success]- 答案 6
> **答案**：×（错误）

> [!tip]- 解析 6
> **解析**：
> 
> - **第一类错误（$\alpha$）**：$H_0$ 为真，却拒绝 $H_0$（接受 $H_1$）。（即题目描述的情况：$H_1$ 不真却接受了 $H_1$）
> - **第二类错误（$\beta$）**：$H_0$ 为假（$H_1$ 为真），却接受 $H_0$

2. 在顺序表中进行顺序搜索，若各元素的搜索概率不同，将元素按搜索概率大小降序排列，可以得到最小的平均搜索长度。（ ）

> [!success]- 答案 7
> **答案**：√（正确）

> [!tip]- 解析 7
> **解析**：
> 
> 平均查找长度 $ASL = \sum p_i c_i$。为了使总和最小，应该让概率 $p_i$ 大的元素对应的比较次数 $c_i$（位置）尽可能小，即按概率降序存放。

3. 若 $E(XY) = E(X)E(Y)$，则随机变量 $X$ 和 $Y$ 必定相互独立。（ ）

> [!success]- 答案 8
> **答案**：×（错误）

> [!tip]- 解析 8
> **解析**：
> 
> $E(XY) = E(X)E(Y)$ 等价于协方差 $\text{Cov}(X, Y) = 0$，即 $X$ 与 $Y$ 不相关。不相关不一定独立（除非是正态分布），独立一定不相关。

4. 在 IPv4 协议中，127.0.0.1 是一个本地链路（link-local）特殊地址。（ ）

> [!success]- 答案 9
> **答案**：×（错误）

> [!tip]- 解析 9
> **解析**：
> 
> - 127.0.0.1 是**环回地址**（Loopback Address），用于本机测试
> - 本地链路地址（Link-local Address）通常指 169.254.x.x（APIPA 地址）

5. 异步传输也是数据传输同步方式的一种。（ ）

> [!success]- 答案 10
> **答案**：√（正确）

> [!tip]- 解析 10
> **解析**：
> 
> 数据传输需要收发双方进行时钟同步。同步方式主要分为两种：
> - 同步传输（Synchronous，发送时钟信号）
> - 异步传输（Asynchronous，使用起止位同步）
> 
> 虽然名字叫"异步"，但它依然是一种实现收发步调一致（同步）的技术手段。

### 三、选择题（每题 3 分，共 21 分）

1. 设 $X \sim N(0, 2)$，$Y \sim N(1, 4)$，且 $X, Y$ 相互独立，则下列选项正确的是（ ）。

> [!success]- 答案 11
> **答案**：C. $P(X + Y \leq 1) = 1/2$

> [!tip]- 解析 11
> **解析**：
> 
> 令 $Z = X + Y$。由于独立，正态分布的和仍为正态分布。
> 
> $E(Z) = E(X) + E(Y) = 0 + 1 = 1$
> 
> $D(Z) = D(X) + D(Y) = 2 + 4 = 6$
> 
> 即 $Z \sim N(1, 6)$
> 
> 正态分布关于均值对称，故 $P(Z \leq \mu) = 0.5$
> 
> 所以 $P(X + Y \leq 1) = 0.5$

2. 在 4 次独立重复的伯努利试验中，事件 A 至少成功一次的概率为 $80/81$，则 A 在每次试验中成功的概率 $p$ 是（ ）。

> [!success]- 答案 12
> **答案**：C. $2/3$

> [!tip]- 解析 12
> **解析**：
> 
> 至少成功一次的概率 $= 1 - P(\text{全部失败}) = 1 - (1-p)^4 = 80/81$
> 
> $(1-p)^4 = 1 - 80/81 = 1/81$
> 
> $1-p = (1/81)^{1/4} = 1/3$
> 
> $p = 2/3$

3. 操作系统中，进程从运行状态变为就绪状态的原因是（ ）。

> [!success]- 答案 13
> **答案**：A. 时间片用完

> [!tip]- 解析 13
> **解析**：
> 
> - 时间片用完：运行 → 就绪
> - I/O 请求：运行 → 阻塞
> - I/O 完成：阻塞 → 就绪

4. 对 1000 个有序数据进行二分查找（Binary Search），最大比较次数是（ ）。

> [!success]- 答案 14
> **答案**：B. 10

> [!tip]- 解析 14
> **解析**：
> 
> 最大比较次数 $= \lfloor \log_2 n \rfloor + 1$
> 
> $\log_2 1000 \approx 9.97$
> 
> 次数 $= 9 + 1 = 10$（$2^{10} = 1024 > 1000$）

5. 有 10 台计算机，每台计算机的网卡速率均为 10Mbps。若使用集线器（Hub）组建共享式以太网，和使用交换机（Switch）组建交换式以太网，则每个主机可获得的平均传输速率分别是（ ）。

> [!success]- 答案 15
> **答案**：B. 1Mbps, 10Mbps

> [!tip]- 解析 15
> **解析**：
> 
> - **Hub（集线器）**：共享带宽。所有端口平分 10Mbps，平均每台 $10/10 = 1$ Mbps
> - **Switch（交换机）**：独享带宽。每个端口都是独立的冲突域，每台都能达到 10Mbps

6. 元素 $1, 2, 3, \ldots, n$ 按顺序入栈，若第一个出栈的元素是 $n$，则第 $i$ 个出栈的元素是（ ）。

> [!success]- 答案 16
> **答案**：C. $n + 1 - i$

> [!tip]- 解析 16
> **解析**：
> 
> 第一个出栈的是 $n$，说明 1 到 $n$ 已经全部入栈了。
> 
> 栈内元素从栈底到栈顶依次是 $1, 2, \ldots, n$。
> 
> 此时只能依次出栈，顺序为 $n, n-1, n-2, \ldots$
> 
> 第 1 个是 $n$，第 2 个是 $n-1$，第 $i$ 个是 $n - (i-1) = n - i + 1$

7. 对 $n$ 个元素进行快速排序（Quick Sort），在平均情况下的空间复杂度是（ ）。

> [!success]- 答案 17
> **答案**：A. $O(\log_2 n)$

> [!tip]- 解析 17
> **解析**：
> 
> 快排的空间复杂度取决于递归调用的栈深度。平均情况下递归树平衡，深度为 $\log_2 n$。最坏情况下为 $n$。

### 四、名词解释题（每题 6 分，共 18 分）

1. HTTP 协议（HyperText Transfer Protocol）、HTTPS 协议（HyperText Transfer Protocol Secure），并简述二者的区别。

> [!success]- 答案 18
> **答案**：
> 
> **（1）HTTP（超文本传输协议）**：是用于从万维网服务器传输超文本到本地浏览器的应用层协议。它以明文方式传输数据，无状态，简单快速，默认端口为 80。
> 
> **（2）HTTPS（安全超文本传输协议）**：是 HTTP 的安全版。它在 HTTP 下加入 SSL/TLS 层，通过加密传输和身份认证来保证网络安全，默认端口为 443。
> 
> **（3）二者区别**：
> - **安全性**：HTTP 明文传输，易被窃听；HTTPS 加密传输，安全性高
> - **端口**：HTTP 使用 80 端口；HTTPS 使用 443 端口
> - **资源消耗**：HTTPS 需要握手和加密解密，比 HTTP 消耗更多 CPU 和网络资源

2. 生成树（Spanning Tree）、最小生成树（Minimum Spanning Tree）

> [!success]- 答案 19
> **答案**：
> 
> **（1）生成树**：对于一个连通图，生成树是包含图中所有顶点（$n$ 个）的一个极小连通子图。它含有 $n-1$ 条边，且没有回路。
> 
> **（2）最小生成树（MST）**：在一个带权的连通无向图中，所有生成树中边权之和最小的那棵生成树。
> 
> **（3）区别**：生成树关注的是连通性和边的数量（最少边）；最小生成树关注的是权值之和的最小化（最小代价），通常用于解决网络布线、修路等成本优化问题。

3. 通用设计（Universal Design）、用户留存率（User Retention Rate）

> [!success]- 答案 20
> **答案**：
> 
> **（1）通用设计**：指无需进行改良或特别设计，就能为尽可能多的用户（无论其年龄、能力或状况）所使用的产品、环境或服务的设计理念。核心体现了设计的包容性与公平性。
> 
> **（2）用户留存率**：是互联网产品运营的核心指标，指在某段时间内，新增用户中经过一段时间后仍继续使用产品的用户比例。它反映了产品的用户粘性和生命周期。
> 
> **（3）区别**：通用设计是设计方法论，关注产品的使用门槛和覆盖面；用户留存率是商业数据指标，关注产品的运营效果和商业价值。

### 五、辨析题（每题 6 分，共 12 分）

1. 辨析：社会创新设计必须考虑所有利益相关方的诉求。这种说法对吗？

> [!success]- 答案 21
> **答案**：
> 
> **1. 系统复杂性**：社会创新解决的是复杂的系统性问题（如养老、环保），涉及政府、企业、NGO、受助者等多方主体。
> 
> **2. 可持续性**：只有满足了关键利益相关方的诉求（如政府的监管要求、企业的盈利模式、用户的实际痛点），设计方案才能获得资源支持并长久运行。
> 
> **3. 避免负面效应**：忽视某一方诉求可能导致方案遭到抵制或产生新的社会不公。
> 
> **结论**：利益相关方分析（Stakeholder Analysis）是社会创新设计的必经步骤。

2. 辨析："在游戏设计中增加奖励机制和成就系统，就是为了激励玩家不断复玩"。这句话正确吗？

> [!success]- 答案 22
> **答案**：
> 
> 这句话过于片面。
> 
> **1. 公平性与竞技性**：对于竞技类游戏（如 MOBA, FPS），数值平衡是游戏存在的基石。如果角色或武器强弱失衡，会导致玩家流失，破坏游戏生态。
> 
> **2. 心流体验（Flow）**：对于单机或 PVE 游戏，数值平衡（难度曲线）决定了玩家的体验。过难导致焦虑，过易导致无聊。良好的数值设计能让玩家保持在"心流"通道中。
> 
> **3. 经济系统**：游戏内的经济数值平衡防止了通货膨胀，保证了游戏寿命。
> 
> **4. 例外**：纯叙事类或艺术类游戏可能弱化数值，但广义的"体验平衡"依然存在。

### 六、计算与简答题（共 54 分）

1. （9 分）设随机变量 $X$ 的概率密度函数为：

$$
f(x) = \begin{cases} \frac{A}{\sqrt{\pi}} e^{-x^2 + 2x - 1}, & x > 0 \\ 0, & x \leq 0 \end{cases}
$$

（1）求常数 $A$；

> [!success]- 答案 23
> **答案**：$A = 2$

> [!tip]- 解析 23
> **解析**：
> 
> 首先化简指数：$-x^2 + 2x - 1 = -(x-1)^2$
> 
> 所以 $f(x) = \frac{A}{\sqrt{\pi}} e^{-(x-1)^2}$，$x > 0$
> 
> 利用正态分布的性质：$\int_{-\infty}^{+\infty} \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}} dx = 1$
> 
> 这里 $\mu = 1$，$2\sigma^2 = 1$，$\sigma^2 = 1/2$，$\sigma = \frac{1}{\sqrt{2}}$
> 
> $\int_{-\infty}^{+\infty} \frac{1}{\sqrt{\pi}} e^{-(x-1)^2} dx = 1$
> 
> 由于积分下限是 0 而非 $-\infty$，需要修正。但题目给的密度函数在 $x > 0$ 时有效，实际上这是一个截断的正态分布。
> 
> 通过规范性条件 $\int_0^{+\infty} f(x) dx = 1$ 求解 $A = 2$

（2）求 $D(X)$。

> [!success]- 答案 24
> **答案**：$D(X) = \frac{1}{2}$

> [!tip]- 解析 24
> **解析**：
> 
> 由于 $f(x)$ 是 $\mu = 1$，$\sigma^2 = 1/2$ 的正态分布的截断形式（在 $x > 0$），
> 
> 对于完整的正态分布 $N(1, 1/2)$，方差为 $1/2$。

2. （9 分）设总体 $X$ 的概率密度函数为：

$$
f(x; \theta) = \begin{cases} \frac{2x}{\theta^2}, & 0 < x < \theta \\ 0, & \text{其他} \end{cases}
$$

$X_1, X_2, \ldots, X_n$ 为来自该总体的简单随机样本。求参数 $\theta$ 的矩估计量和最大似然估计量。

> [!success]- 答案 25
> **答案**：
> 
> **矩估计量**：$\hat{\theta}_M = \frac{3}{2} \bar{X}$
> 
> **最大似然估计量**：$\hat{\theta}_L = X_{(n)} = \max\{X_1, X_2, \ldots, X_n\}$

> [!tip]- 解析 25
> **解析**：
> 
> **矩估计**：
> 
> $$E(X) = \int_0^{\theta} x \cdot \frac{2x}{\theta^2} dx = \frac{2}{\theta^2} \int_0^{\theta} x^2 dx = \frac{2}{\theta^2} \cdot \frac{\theta^3}{3} = \frac{2\theta}{3}$$
> 
> 令 $E(X) = \bar{X}$，得 $\frac{2\theta}{3} = \bar{X}$，所以 $\hat{\theta}_M = \frac{3}{2} \bar{X}$
> 
> **最大似然估计**：
> 
> 似然函数：$L(\theta) = \prod_{i=1}^n \frac{2x_i}{\theta^2} = \frac{2^n \prod x_i}{\theta^{2n}}$，$0 < x_i < \theta$
> 
> $L(\theta)$ 关于 $\theta$ 单调递减，所以 $\theta$ 越小 $L(\theta)$ 越大。
> 
> 但 $\theta$ 必须大于所有 $x_i$，所以 $\hat{\theta}_L = \max\{X_1, X_2, \ldots, X_n\} = X_{(n)}$

3. （8 分）设 $T$ 是一棵中序线索二叉树，请设计一个算法将新结点 $S$ 插入到 $T$ 中，作为 $T$ 的右子树中按中序遍历得到的第一个叶结点 $L$ 的左孩子。给出算法思想和 C 语言实现。

> [!success]- 答案 26
> **答案**：
> 
> **算法思想**：
> 
> 1. **寻找插入位置 L**：在中序线索二叉树中，$T$ 的右子树的中序第一个结点是从 $T \rightarrow rchild$ 出发一直向左走直到没有左孩子的结点
> 
> 2. **插入逻辑**：
>    - $S$ 成为 $L$ 的左孩子
>    - $S$ 的左指针指向 $L$ 原来的前驱（继承 $L$ 的前驱线索）
>    - $S$ 的右指针指向 $L$（后继线索）
>    - $L$ 的左指针指向 $S$，$L$ 的左标记改为 0（表示左孩子）

> [!example]- 代码实现
> ```c
> typedef struct ThreadNode {
>     int data;
>     struct ThreadNode *lchild, *rchild;
>     int ltag, rtag;  // 0: 指向孩子, 1: 指向前驱/后继
> } ThreadNode, *ThreadTree;
> 
> void InsertNode(ThreadTree T, ThreadNode *S) {
>     if (T == NULL || T->rchild == NULL) return;
>     
>     // 1. 寻找 T 右子树中序第一个结点（最左下结点）
>     ThreadNode *p = T->rchild;
>     while (p->ltag == 0) {
>         p = p->lchild;
>     }
>     
>     // 此时 p 没有左孩子，即为插入点 L
>     ThreadNode *L = p;
>     
>     // 2. 插入 S 作为 L 的左孩子
>     // S 的左指针指向 L 原来的前驱
>     S->lchild = L->lchild;
>     S->ltag = 1;  // 线索
>     
>     // S 的右指针指向 L（后继）
>     S->rchild = L;
>     S->rtag = 1;  // 线索
>     
>     // L 的左指针指向 S
>     L->lchild = S;
>     L->ltag = 0;  // 左孩子
> }
> ```

4. （8 分）已知一棵二叉树采用二叉链表存储，请设计一个算法找出值为 $x$ 的结点 $p$ 的双亲结点。给出算法思想和 C 语言实现。

> [!success]- 答案 27
> **答案**：
> 
> **算法思想**：采用递归遍历（先序）
> 
> 1. 若树空或根为 $x$，返回 NULL（根无双亲）
> 2. 判断当前结点 $T$ 的左孩子或右孩子是否为 $x$，若是，则 $T$ 即为双亲
> 3. 若不是，递归在左子树找，若找到则返回
> 4. 若左子树没找到，递归在右子树找

> [!example]- 代码实现
> ```c
> typedef struct BiTNode {
>     int data;
>     struct BiTNode *lchild, *rchild;
> } BiTNode, *BiTree;
> 
> BiTree FindParent(BiTree T, int x) {
>     if (T == NULL) return NULL;
>     
>     // 根节点无双亲
>     if (T->data == x) return NULL;
>     
>     // 检查左孩子
>     if (T->lchild && T->lchild->data == x) {
>         return T;
>     }
>     
>     // 检查右孩子
>     if (T->rchild && T->rchild->data == x) {
>         return T;
>     }
>     
>     // 递归查找左子树
>     BiTree res = FindParent(T->lchild, x);
>     if (res != NULL) return res;
>     
>     // 递归查找右子树
>     return FindParent(T->rchild, x);
> }
> ```
