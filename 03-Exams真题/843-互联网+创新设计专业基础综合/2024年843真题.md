# 清华大学深圳国际研究生院 2024 年硕士研究生入学考试

## 843 互联网+创新设计专业基础综合

### 一、填空题（每题 3 分，共 15 分）

1. 设 $A, B$ 两个事件相互独立，已知 $P(A) = 0.7$，$P(A \cup B) = 0.88$，则 $P(A - B) =$（ ）。

2. 散列表长度 $m = 14$，哈希函数为 $H(key) = key \% 11$。现有数据 $\{15, 38, 61, 84\}$ 已按其哈希地址 4, 5, 6, 7 存入表中。若采用线性探测法解决冲突，现在插入关键字 49，应存放的地址是（ ）。

3. OSI 参考模型中，负责在两个相邻节点之间（点对点）提供流量控制功能的层次是（ ）。

4. 一个 B 类 IP 地址网络，若采用的子网掩码是 255.255.240.0，则该网络中每个子网最多能容纳的主机个数为（ ）。

5. 对 50TB 的海量数据文件进行排序，应主要采用（ ）排序方法。

### 二、判断题（每题 3 分，共 15 分）

1. 若要实现一个链式队列，采用带有头指针和尾指针的循环单链表是最好的结构选择。（ ）

2. 为了让数字信号在信道上传递得更远，可以在传输路径上使用放大器。（ ）

3. 在假设检验（显著性检验）中，若要同时降低犯第一类错误和第二类错误的概率，唯一的方法是扩大样本容量。（ ）

4. 在计算机中，浮点数的"下溢"（Underflow）指的是浮点数的值小于所能表示的负数最小值。（ ）

5. 根据列维—林德伯格中心极限定理，若 $S_n = X_1 + X_2 + \cdots + X_n$ 服从正态分布，则 $X_i$ 只需要满足具有相同的数学期望即可。（ ）

### 三、选择题（每题 3 分，共 21 分）

1. 设随机变量 $X \sim N(0, 1)$，$\Phi(x)$ 为其标准正态分布函数，则 $P(|X| > 2)$ 为（ ）。

2. 设 $X$ 和 $Y$ 为两个相互独立的随机变量，其分布函数分别为 $F_X(x)$ 和 $F_Y(y)$。令 $Z = \max\{X, Y\}$，则 $Z$ 的分布函数 $F_Z(z)$ 为（ ）。

3. 邻接矩阵（Adjacency Matrix）存储结构最适用于以下哪种图？（ ）

4. 在一个已按升序排列的单链表中，插入一个新元素并保持其有序性的时间复杂度为（ ）。

5. 防火墙（Firewall）无法实现的网络功能是（ ）。

6. 某计算机地址总线为 32 位，Cache 容量为 32KB，块大小为 32B，采用直接映射和回写法（Write-back），则 Cache 每行（Cache Line）的总位数至少是（ ）。

7. 在一个含有 $n$ 个元素的有序线性表中进行折半查找（二分查找），最多需要比较的次数是（ ）。

### 六、计算与简答题（共 54 分）

1. （6 分）设工厂售出一台设备的寿命 $X$（年）服从参数为 $\lambda = 0.25$ 的指数分布。若设备在一年内发生故障，工厂亏损 300 元；若设备在一年内不发生故障，工厂盈利 100 元。求工厂售出一台设备所获利润的数学期望。

2. （9 分）设二维随机变量 $(X, Y)$ 在区域 $D = \{(x, y) | x \geq 0, y \geq 0, x + y \leq 1\}$ 上服从均匀分布。

（1）求 $X$ 的边缘概率密度函数 $f_X(x)$；

（2）设 $Z = X + Y$，求 $Z$ 的分布函数 $F_Z(z)$ 和概率密度函数 $f_Z(z)$。

3. （8 分）已知两个有序（递增）单链表 $LA$ 和 $LB$，请设计一个算法将它们合并为一个新的有序（递增）单链表 $LC$。给出算法思想、时间复杂度分析及 C 语言实现。

4. （8 分）设计一个算法，在一个包含 $n$ 个不同元素的线性表中，同时找出最大值和最小值。要求比较次数最坏不超过 $\frac{3n}{2} - 2$ 次。给出算法思想和 C 语言实现。

5. （6 分）计算机组成原理计算题：I/O 查询 vs DMA。

（1）设备 A 使用 I/O 查询方式，数据率为 2MB/s，缓冲区大小为 32 位。CPU 时钟频率为 500MHz，每次查询需要执行 10 条指令，每条指令平均需要 4 个时钟周期。求 CPU 用于设备 A 的时间百分比。

（2）设备 B 使用 DMA 方式，数据率为 40MB/s，每次 DMA 传输块大小为 1000B。DMA 初始化和后处理共需 500 个时钟周期。CPU 时钟频率为 500MHz。求 CPU 用于设备 B 的时间百分比。

6. （9 分）乐高（LEGO）玩具宣称 4 岁以上的儿童不用看说明书就能拼搭。请从产品设计的角度，分析乐高玩具是如何提升其产品的"易用性"的。

7. （8 分）汽车设计史上曾有过一段时间盛行"有计划的报废"（Planned Obsolescence）。请谈谈你如何看待这种产品设计思路。

要求：
