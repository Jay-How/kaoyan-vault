# 清华大学深圳国际研究生院 2021 年硕士研究生入学考试

## 843 互联网+创新设计专业基础综合（参考答案与解析）

### 一、填空题（每题 3 分，共 15 分）

1. 设 $A, B$ 为两个相互独立的随机事件，已知 $P(A) = 0.4$，$P(B) = 0.4$，则 $P(A \cup B) =$（ ）。

> [!success]- 答案 1
> **答案**：$0.64$

> [!tip]- 解析 1
> **解析**：
> 
> 根据概率加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
> 
> 由于 $A, B$ 相互独立，故 $P(AB) = P(A)P(B) = 0.4 \times 0.4 = 0.16$
> 
> 所以，$P(A \cup B) = 0.4 + 0.4 - 0.16 = 0.64$

2. 假设一棵完全二叉树的高度为 $h$（根节点在第 1 层），则该树的最少节点数为（ ），最多节点数为（ ）。

> [!success]- 答案 2
> **答案**：$2^{h-1}$，$2^h - 1$

> [!tip]- 解析 2
> **解析**：
> 
> **最少情况**：第 $h$ 层只有一个节点，即前 $h-1$ 层是满的。
> 
> 节点数 $= 2^{h-1} - 1 + 1 = 2^{h-1}$
> 
> **最多情况**：是一棵满二叉树。
> 
> 节点数 $= 2^0 + 2^1 + \cdots + 2^{h-1} = 2^h - 1$

3. 在计算机系统中，决定 CPU 字长（Word Length）的总线类型是（ ）总线。

> [!success]- 答案 3
> **答案**：数据（Data）

> [!tip]- 解析 3
> **解析**：
> 
> CPU 的字长是指 CPU 一次能处理的二进制数据的位数，它通常与 CPU 内部寄存器、运算器（ALU）的位数以及数据总线的宽度一致。数据总线的宽度决定了 CPU 与外界交换数据的能力。

4. 计算机中表示信息（数据）的最小单位是（ ）。

> [!success]- 答案 4
> **答案**：位（bit）

> [!tip]- 解析 4
> **解析**：
> 
> "位"（bit）是最小单位；"字节"（Byte）是最基本的存储/计量单位。注意审题，问的是"最小单位"。

5. 广域网（WAN）和互联网的核心部分通常采用（ ）拓扑结构。

> [!success]- 答案 5
> **答案**：网状（Mesh）

> [!tip]- 解析 5
> **解析**：
> 
> 广域网和互联网核心路由器之间需要高可靠性和多条路径，因此通常采用不规则的网状结构，而非局域网常见的星型或总线型。

### 二、判断题（每题 3 分，共 15 分）

1. 已知 $A_1, A_2, A$ 为三个随机事件，若事件 $A_1$ 与 $A_2$ 同时发生时，事件 $A$ 必然发生，则 $P(A) \geq P(A_1) + P(A_2) - 1$。（ ）

> [!success]- 答案 6
> **答案**：√（正确）

> [!tip]- 解析 6
> **解析**：
> 
> 题目条件意味着 $A_1 \cap A_2 \subseteq A$，因此 $P(A) \geq P(A_1 \cap A_2)$。
> 
> 根据加法公式：$P(A_1 \cup A_2) = P(A_1) + P(A_2) - P(A_1 \cap A_2)$
> 
> 移项得：$P(A_1 \cap A_2) = P(A_1) + P(A_2) - P(A_1 \cup A_2)$
> 
> 因为 $P(A_1 \cup A_2) \leq 1$，所以 $P(A_1 \cap A_2) \geq P(A_1) + P(A_2) - 1$
> 
> 综上，$P(A) \geq P(A_1) + P(A_2) - 1$

2. 操作系统进行磁盘空间分配的基本单位是簇（Cluster）。（ ）

> [!success]- 答案 7
> **答案**：√（正确）

> [!tip]- 解析 7
> **解析**：
> 
> 扇区（Sector）是磁盘读写的物理最小单位，但操作系统为了提高效率，将多个相邻扇区组合成"簇"（Cluster）作为文件分配的基本单位。

3. TCP/IP 是一套网络协议簇（Protocol Suite），是构成互联网的基础。（ ）

> [!success]- 答案 8
> **答案**：√（正确）

> [!tip]- 解析 8
> **解析**：

> TCP/IP 不仅仅指 TCP 和 IP 两个协议，而是指包含 UDP、ICMP、HTTP 等在内的一整套协议集合。

4. 递归算法编写简单、方便，且运行效率高。（ ）

> [!success]- 答案 9
> **答案**：×（错误）

> [!tip]- 解析 9
> **解析**：
> 
> 递归算法通常逻辑清晰、代码简洁，但由于频繁的函数调用、入栈出栈操作，其时间效率和空间效率（栈空间）通常较低，且容易导致栈溢出。

5. 对于同一数据类型，顺序存储结构在存取速度上一定优于链式存储结构。（ ）

> [!success]- 答案 10
> **答案**：×（错误）

> [!tip]- 解析 10
> **解析**：
> 
> - **存取（Access）**：如果是指"随机访问第 $i$ 个元素"，顺序表 $O(1)$ 确实优于链表 $O(n)$
> - **操作（Operation）**：链表在插入/删除时的指针操作速度快（无需移动元素）
> 
> 严格来说，题干若指"读取任意元素"，顺序表确实优；但若指广义的"存取使用"，链表在动态性上更优。"一定"这个词通常暗示错误。

### 三、选择题（每题 3 分，共 21 分）

1. 假设 $X, Y$ 两个随机变量相互独立且均服从 $(0, 1)$ 上的均匀分布，则 $P(X + Y \leq 1/2)$ 的概率为（ ）。

> [!success]- 答案 11
> **答案**：C. $1/8$

> [!tip]- 解析 11
> **解析**：
> 
> $(X, Y)$ 的联合概率密度在单位正方形区域 $D = \{(x, y) | 0 \leq x \leq 1, 0 \leq y \leq 1\}$ 内均匀分布，面积为 1。
> 
> 事件 $X + Y \leq 1/2$ 对应的区域是直线 $x + y = 1/2$ 与坐标轴围成的三角形。
> 
> 该三角形的三个顶点为 $(0, 0), (0.5, 0), (0, 0.5)$
> 
> 面积 $S = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$

2. 设 $X_1, \ldots, X_m$ 和 $Y_1, \ldots, Y_n$ 分别来自两个独立的服从正态分布 $N(\mu_1, \sigma_1^2)$ 和 $N(\mu_2, \sigma_2^2)$ 的样本，检验 $\sigma_1^2 = \sigma_2^2$ 时，使用的统计分布是（ ）。

> [!success]- 答案 12
> **答案**：B. $F$ 分布

> [!tip]- 解析 12
> **解析**：
> 
> - 检验均值 $\mu$（方差已知）：$Z$ 检验（正态分布）
> - 检验均值 $\mu$（方差未知）：$t$ 检验（$t$ 分布）
> - 检验方差 $\sigma^2$（单个总体）：$\chi^2$ 检验（卡方分布）
> - 检验两总体方差比 $\sigma_1^2 / \sigma_2^2$：$F$ 检验（$F$ 分布）

3. 在 OSI（开放系统互连）参考模型中，负责处理原始比特流（bit stream）传输的层次是（ ）。

> [!success]- 答案 13
> **答案**：A. 物理层（Physical Layer）

> [!tip]- 解析 13
> **解析**：
> 
> 物理层负责传输比特流；数据链路层传输帧；网络层传输包/分组；传输层传输段/报文。

4. 对一棵二叉排序树（Binary Search Tree）进行（ ）遍历，可以得到一个递增的节点序列。

> [!success]- 答案 14
> **答案**：B. 中序（In-order）

> [!tip]- 解析 14
> **解析**：
> 
> 二叉排序树的定义就是：左子树 < 根 < 右子树。中序遍历（左-根-右）正好顺应了这个顺序。

5. 下列排序算法中，哪一种是不稳定的排序算法？（ ）

> [!success]- 答案 15
> **答案**：B. 堆排序（Heap Sort）

> [!tip]- 解析 15
> **解析**：
> 
> - **稳定**：冒泡、插入、归并、基数
> - **不稳定**：快速、希尔、选择、堆排序
> 
> 记忆口诀："快(快排)些(希尔)选(选择)一堆(堆排)心情不稳定"

6. 设 $A$ 为一个 $3 \times 4$ 矩阵，齐次线性方程组 $Ax = 0$ 必定（ ）。

> [!success]- 答案 16
> **答案**：B. 必有非零解

> [!tip]- 解析 16
> **解析**：
> 
> $A$ 是 $3 \times 4$ 矩阵，方程组有 4 个未知数，3 个方程。秩 $r(A) \leq 3 < 4$（未知数个数）。
> 
> 自由变量个数 $= 4 - r(A) \geq 1$。因此必有无穷多解（包含非零解）。

7. 8 位补码的表示范围是（ ）。

> [!success]- 答案 17
> **答案**：B. $-128 \sim +127$

> [!tip]- 解析 17
> **解析**：
> 
> $n$ 位补码的范围是 $[-2^{n-1}, 2^{n-1}-1]$。对于 8 位，即 $[-2^7, 2^7-1] = [-128, 127]$。

### 四、名词解释题（每题 6 分，共 18 分）

1. 连通图（Connected Graph）与最小生成树（Minimum Spanning Tree）

> [!success]- 答案 18
> **答案**：
> 
> **（1）连通图**：在无向图中，如果从顶点 $v_i$ 到顶点 $v_j$ 有路径，则称 $v_i$ 和 $v_j$ 是连通的。如果图中任意两个顶点都是连通的，则称该图为连通图。
> 
> **（2）最小生成树**：是在一个带权连通无向图中，包含图中所有顶点（$n$ 个），且边的数量最少（$n-1$ 条）并保持图连通的子图（即一棵树），且这棵树的所有边的权值之和最小。
> 
> **（3）辨析**：连通图是图的一种性质状态，而最小生成树是基于带权连通图构造出的一种特殊的极小连通子图（优化结构）。

2. 接口（Interface）、接口电路（Interface Circuit）、端口（Port）

> [!success]- 答案 19
> **答案**：
> 
> **（1）接口**：是计算机系统中两个独立的子系统（如 CPU 与外设）之间进行数据、控制和状态信息交换的交接点或连接标准。
> 
> **（2）接口电路**：是实现接口功能的硬件电路。它通常包含数据寄存器、控制逻辑和状态寄存器，用于解决 CPU 与外设在速度、电平、时序等方面的不匹配问题。
> 
> **（3）端口**：是指接口电路中可以被 CPU 直接访问（读写）的寄存器。例如数据端口、状态端口和控制端口。CPU 通过地址总线寻址这些端口来进行 I/O 操作。

3. 设计驱动式创新（Design-Driven Innovation）、互联网思维（Internet Thinking）

> [!success]- 答案 20
> **答案**：
> 
> **（1）设计驱动式创新**：是一种通过赋予产品新的意义（Meaning）和语言来创造竞争优势的创新模式。它区别于"技术驱动"和"市场驱动"，侧重于挖掘用户深层次的、未被表达的情感和文化需求（例如苹果 iPhone 对手机定义的重构）。
> 
> **（2）互联网思维**：是指在（移动）互联网+、大数据、云计算等科技不断发展的背景下，对市场、用户、产品、企业价值链乃至整个商业生态进行重新审视的思考方式。其核心包括用户至上、体验为王、迭代创新、流量思维等。
> 
> **（3）辨析**：设计驱动式创新侧重于"意义的重构"；互联网思维侧重于"利用数字技术重构商业模式和效率"。

### 五、辨析题（每题 6 分，共 12 分）

1. 有人说，设计就是"美化"或"造型"。请谈谈你的理解。

> [!success]- 答案 21
> **答案**：
> 
> **1. 定义误区**：将设计等同于"美化"或"造型"是工业设计早期的狭隘理解。
> 
> **2. 现代设计内涵**：现代设计（特别是"互联网+"背景下的设计）已经从单纯的"造物"演变为"解决问题"的系统工程。它不仅包含视觉/形态设计（外观），还包含交互设计（易用性）、服务设计（流程体验）、商业模式设计等。
> 
> **3. 核心价值**：设计的核心是"以人为本"，即发现用户的痛点，并利用技术手段提供解决方案，而外观只是解决方案的载体之一。例如，一个外观普通的 App 如果能高效解决挂号难的问题，它依然是优秀的设计。

2. 有人说，"互联网思维"本质上是一种技术。这种说法对吗？请说明理由。

> [!success]- 答案 22
> **答案**：
> 
> **1. 技术基础**：互联网思维确实是建立在互联网技术（连接、大数据、云计算）高度发展的基础之上的。没有技术作为底层支撑，这种思维无法落地。
> 
> **2. 本质界定**：但严格来说，"互联网思维"本身不是技术，而是一种方法论和价值观。它是指像互联网产品一样思考：如何低成本获取用户（免费思维）、如何快速响应变化（迭代思维）、如何连接一切（平台思维）。
> 
> **3. 结论**：因此，更准确的说法是：互联网思维是基于互联网技术特征而演化出的一种全新的商业与设计思维方式。不能将"思维"直接等同于"技术"。

### 六、简答与计算题（共 54 分）

1. （6 分）设随机变量 $X$ 和 $Y$ 的数学期望分别为 $E(X) = -2$，$E(Y) = 2$；方差分别为 $D(X) = 1$，$D(Y) = 4$；$X$ 与 $Y$ 的相关系数为 $\rho_{XY} = -0.5$。求 $E(2X - Y)$ 与 $D(2X - Y)$。

> [!success]- 答案 23
> **答案**：$E(2X - Y) = -6$，$D(2X - Y) = 12$

> [!tip]- 解析 23
> **解析**：
> 
> **（1）求均值**：根据期望的线性性质：
> 
> $$E(2X - Y) = 2E(X) - E(Y) = 2 \times (-2) - 2 = -4 - 2 = -6$$
> 
> **（2）求方差**：根据方差的性质 $D(aX + bY) = a^2D(X) + b^2D(Y) + 2ab\text{Cov}(X, Y)$
> 
> 首先计算协方差 $\text{Cov}(X, Y)$：
> 
> $$\text{Cov}(X, Y) = \rho_{XY} \cdot \sqrt{D(X)} \cdot \sqrt{D(Y)} = -0.5 \times \sqrt{1} \times \sqrt{4} = -0.5 \times 1 \times 2 = -1$$
> 
> 计算 $D(2X - Y)$：
> 
> $$D(2X - Y) = 2^2 D(X) + (-1)^2 D(Y) + 2 \cdot 2 \cdot (-1) \cdot \text{Cov}(X, Y)$$
> $$= 4D(X) + 1D(Y) - 4\text{Cov}(X, Y)$$
> $$= 4 \times 1 + 1 \times 4 - 4 \times (-1) = 4 + 4 + 4 = 12$$

2. （9 分）设二维随机变量 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = \begin{cases} 12e^{-4x-3y}, & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}
$$

（1）计算 $P(0 \leq X \leq 1, 0 \leq Y \leq 2)$；

> [!success]- 答案 24
> **答案**：$(1 - e^{-4})(1 - e^{-6})$

> [!tip]- 解析 24
> **解析**：
> 
> $$P(0 \leq X \leq 1, 0 \leq Y \leq 2) = \int_0^1 \int_0^2 12e^{-4x-3y} \, dy \, dx$$
> 
> 注意到函数可分离变量：$12e^{-4x-3y} = (4e^{-4x}) \cdot (3e^{-3y})$
> 
> 积分可拆分为：
> 
> $$= \left(\int_0^1 4e^{-4x} \, dx\right) \cdot \left(\int_0^2 3e^{-3y} \, dy\right)$$
> $$= [-e^{-4x}]_0^1 \cdot [-e^{-3y}]_0^2$$
> $$= (1 - e^{-4}) \cdot (1 - e^{-6})$$

（2）求 $X$ 的边缘概率密度函数 $f_X(x)$。

> [!success]- 答案 25
> **答案**：
> 
> $$f_X(x) = \begin{cases} 4e^{-4x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

> [!tip]- 解析 25
> **解析**：
> 
> 当 $x > 0$ 时：
> 
> $$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_0^{+\infty} 12e^{-4x-3y} \, dy$$
> $$= 4e^{-4x} \int_0^{+\infty} 3e^{-3y} \, dy$$
> $$= 4e^{-4x} \cdot [-e^{-3y}]_0^{+\infty}$$
> $$= 4e^{-4x} \cdot (0 - (-1)) = 4e^{-4x}$$
> 
> 当 $x \leq 0$ 时，$f_X(x) = 0$。

3. （6 分）简述科技创新与设计创新的关系。

> [!success]- 答案 26
> **答案**：
> 
> 相辅相成，螺旋上升：
> 
> **1. 科技创新是基础（驱动力）**：科技进步为设计提供了新的材料、工艺和功能实现的可能性。没有技术突破，设计往往只能停留在概念层面（例如智能手机的设计依赖于触摸屏和芯片技术的成熟）。
> 
> **2. 设计创新是导向（转化力）**：设计将冰冷的技术转化为用户易用、喜爱的产品。设计创新赋予技术以商业价值和社会意义，并往往对技术提出新的需求，反向推动技术的迭代（例如追求极致轻薄的设计推动了电池技术的革新）。
> 
> **3. 融合趋势**：在"互联网+"时代，两者边界日益模糊，如交互设计（IxD）既需要技术逻辑，也需要艺术感知。

4. （6 分）简述科技创新与人文创新的本质区别，并各举一例说明。

> [!success]- 答案 27
> **答案**：
> 
> **本质区别**：
> 
> **科技创新**：关注"真"与"效"。它解决的是物理世界的问题，追求更高的效率、更快的速度、更强的功能。本质是处理人与物的关系。
> 
> **人文创新**：关注"善"与"美"。它解决的是精神世界和社会关系的问题，追求价值观的重塑、文化的传承和伦理的关怀。本质是处理人与人的关系。
> 
> **举例**：
>

6. （9 分）简述影响 CPU 性能的主要技术指标，并说明高速缓存（Cache）在计算机系统中的主要作用。

> [!success]- 答案 29
> **答案**：
> 
> **CPU 主要性能指标**：
> 
> 1. **主频（Clock Speed）**：CPU 的时钟频率，单位 Hz，通常越高越快
> 2. **字长（Word Length）**：CPU 一次能处理的数据位数（如 32 位、64 位），影响精度和寻址范围
> 3. **核心数（Core Count）**：物理核心的数量，影响多任务处理能力
> 4. **CPI（Cycles Per Instruction）**：执行每条指令所需的平均时钟周期数
> 5. **总线速度**：数据传输带宽
> 
> **Cache 的作用**：
> 
> **缓解速度差异**：主要用于解决 CPU 极高的运算速度与主存（RAM）相对较慢的读写速度之间的矛盾。
> 
> **原理**：利用程序的局部性原理（Locality），将 CPU 近期可能用到的数据和指令预先从主存复制到速度更快的 Cache 中。CPU 访问数据时优先查找 Cache，从而减少访问主存的次数，显著提高系统整体性能。

7. （9 分）已知集合 $A$ 和 $B$ 分别用链表存储，链表中的元素无序。请设计一个算法求 $A$ 与 $B$ 的交集 $C$，要求 $C$ 也用链表存储。给出算法思想、时间复杂度分析及 C 语言实现。

> [!success]- 答案 30
> **答案**：
> 
> **算法思想**：
> 
> 1. 初始化一个空链表 $C$ 作为结果集
> 2. 遍历链表 $A$ 中的每一个节点（设指针为 $p$）
> 3. 对于 $p$ 指向的每一个元素，遍历链表 $B$（设指针为 $q$）进行查找
> 4. 若在 $B$ 中找到了与 $p\rightarrow data$ 相等的元素，说明该元素属于交集
> 5. 将该元素插入到链表 $C$ 中
> 
> **时间复杂度**：$O(|A| \times |B|)$

> [!example]- 代码实现
> ```c
> typedef struct Node {
>     int data;
>     struct Node *next;
> } Node, *LinkedList;
> 
> // 函数：求交集
> // 参数：La, Lb 为集合 A, B 的头指针
> // 返回：交集 C 的头指针
> LinkedList Intersect(LinkedList La, LinkedList Lb) {
>     // 初始化结果链表 C（带头结点）
>     LinkedList Lc = (Node*)malloc(sizeof(Node));
>     Lc->next = NULL;
>     Node *pc = Lc;  // pc 指向 C 的尾部
>     
>     // 遍历链表 A
>     Node *pa = La->next;
>     while (pa != NULL) {
>         // 在 B 中查找 pa->data
>         Node *pb = Lb->next;
>         int foundInB = 0;
>         while (pb != NULL) {
>             if (pb->data == pa->data) {
>                 foundInB = 1;
>                 break;
>             }
>             pb = pb->next;
>         }
>         
>         // 如果在 B 中找到了
>         if (foundInB) {
>             Node *newNode = (Node*)malloc(sizeof(Node));
>             newNode->data = pa->data;
>             newNode->next = NULL;
>             // 尾插法
>             pc->next = newNode;
>             pc = newNode;
>         }
>         
>         pa = pa->next;
>     }
>     
>     return Lc;
> }
> ```
