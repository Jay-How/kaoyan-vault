### 一、选择题（每题 3 分，共 18 分）

1. 设 $X$ 服从参数为 $p$ 的两点分布 $B(1, p)$，即 $P(X = 1) = p$，$P(X = 0) = 1 - p$，则 $X$ 的均值和方差分别为（ ）。

> [!success]- 答案 1
> **答案**：A. $p$ 和 $p(1-p)$

> [!tip]- 解析 1
> **解析**：
> 
> 均值：$E(X) = 1 \times p + 0 \times (1-p) = p$
> 
> 方差：$D(X) = E(X^2) - [E(X)]^2 = (1^2 \times p + 0^2 \times (1-p)) - p^2 = p - p^2 = p(1-p)$

2. 设 $X_1, \ldots, X_n$ 为来自正态总体 $N(\mu, \sigma^2)$ 的简单随机样本，$\bar{X}$ 为样本均值，$S^2$ 为样本方差。则统计量 $\frac{(n-1)S^2}{\sigma^2}$ 服从（ ）。

> [!success]- 答案 2
> **答案**：C. $\chi^2(n-1)$（卡方）分布

> [!tip]- 解析 2
> **解析**：
> 
> 这是数理统计中的三大抽样分布定理之一。样本方差 $S^2$ 归一化后服从自由度为 $n-1$ 的卡方分布。
> - A 是 $t$ 分布（用于未知方差时检验均值）
> - B 是 $F$ 分布（用于比较两个方差）

3. 在 TCP/IP 协议簇中，主要负责报告错误信息和网络诊断的网络层协议是（ ）。

> [!success]- 答案 3
> **答案**：D. ICMP

> [!tip]- 解析 3
> **解析**：
> 
> - HTTP 是应用层协议
> - SMTP 是邮件传输协议（应用层）
> - TCP 是传输层协议
> - ICMP（Internet Control Message Protocol）是网络层协议，专门用于在 IP 主机、路由器之间传递控制消息（如网络通不通、主机是否可达），ping 命令就是基于此

4. 下列排序算法中，（最坏情况下）空间复杂度最大的是（ ）。

> [!success]- 答案 4
> **答案**：B. 归并排序（Merge Sort）

> [!tip]- 解析 4
> **解析**：
> 
> - 堆排序：空间 $O(1)$
> - 归并排序：需要一个与原数组等长的辅助数组来合并元素，空间 $O(n)$
> - 冒泡排序：空间 $O(1)$
> - 插入排序：空间 $O(1)$
> - 快速排序最坏空间是 $O(n)$（递归栈），但平均是 $O(\log n)$
> 
> 题目中通常对比显性辅助空间，归并排序的 $O(n)$ 是必需的，通常被认为空间消耗最大。

### 二、判断题（每题 3 分，共 6 分）

1. 已知 $P(A) > 0$，$P(B) > 0$，若 $P(A|B) > P(A)$，则 $P(B|A) < P(B)$。（ ）

> [!success]- 答案 7
> **答案**：×（错误）

> [!tip]- 解析 7
> **解析**：
> 
> $P(A|B) > P(A) \Leftrightarrow \frac{P(AB)}{P(B)} > P(A) \Leftrightarrow P(AB) > P(A)P(B)$
> 
> 这说明 $A$ 和 $B$ 是正相关的（相互促进）。
> 
> 同理，看 $P(B|A)$：
> 
> $$P(B|A) = \frac{P(AB)}{P(A)} > \frac{P(A)P(B)}{P(A)} = P(B)$$
> 
> 所以，$P(B|A)$ 应该也大于 $P(B)$，而非小于。

2. 对于一个数据类型，顺序存储结构在所有方面都优于链式存储结构。（ ）

> [!success]- 答案 8
> **答案**：×（错误）

> [!tip]- 解析 8
> **解析**：
> 
> 过于绝对。
> - **顺序存储优点**：存储密度高（无指针），支持随机访问
> - **链式存储优点**：插入/删除方便（无需移动元素），内存分配灵活（不要求连续空间），无"溢出"问题（针对动态链表）
> 
> 在频繁插入删除的场景下，链式优于顺序。

### 三、填空题（每题 3 分，共 15 分）

1. 设 $P(A) = 0.7$，$P(\bar{A} \cap B) = 0.3$。若 $A, B$ 两个事件相互独立，则 $P(\bar{A} \cup \bar{B}) =$（ ）。

> [!success]- 答案 9
> **答案**：$0.3$

> [!tip]- 解析 9
> **解析**：
> 
> 1. 因为 $A, B$ 独立，所以 $\bar{A}$ 与 $B$ 也独立。
> 
> 2. $P(\bar{A} \cap B) = P(\bar{A}) \cdot P(B) = (1 - P(A)) \cdot P(B) = 0.3 \cdot P(B)$
> 
> 3. 题目给 $P(\bar{A} \cap B) = 0.3$，所以 $0.3 \cdot P(B) = 0.3 \Rightarrow P(B) = 1$
> 
> 4. $P(\bar{A} \cup \bar{B}) = P(\overline{A \cap B}) = 1 - P(A \cap B)$
> 
> 5. 因独立，$P(A \cap B) = P(A)P(B) = 0.7 \times 1 = 0.7$
> 
> 6. 结果 $= 1 - 0.7 = 0.3$

5. 一棵具有 99 个总节点的哈夫曼树（Huffman Tree），其叶子结点个数为（ ）。若该树采用二叉链表存储，则空指针域的总个数为（ ）。

> [!success]- 答案 13
> **答案**：50、100

> [!tip]- 解析 13
> **解析**：
> 
> 1. 哈夫曼树中没有度为 1 的结点，只有度为 0 和 2 的结点
> 2. 设叶子数为 $n_0$，总节点 $n = 2n_0 - 1$
> 3. $99 = 2n_0 - 1 \Rightarrow 2n_0 = 100 \Rightarrow n_0 = 50$
> 4. 在任意 $n$ 个结点的二叉链表中，空指针数 $= n + 1$
> 5. $99 + 1 = 100$

### 四、名词解释题（每题 6 分，共 18 分）

1. 循环链表（Circular Linked List）与双向链表（Doubly Linked List）

> [!success]- 答案 14
> **答案**：
> 
> **（1）循环链表**：是一种首尾相接的链表。其特点是表中最后一个结点的指针域不为空，而是指向头结点（或第一个结点），从而使整个链表形成一个环。由此可以从表中任一结点出发访问到表中其他所有结点。
> 
> **（2）双向链表**：每个结点包含两个指针域，一个指向直接后继（next），另一个指向直接前驱（prior）。其特点是能双向遍历，克服了单链表只能单向查找的缺点。
> 
> **（3）区别**：循环链表强调路径的闭合（环状），主要用于处理具有循环特性的数据（如约瑟夫环）；双向链表强调访问的双向性，主要用于提高在已知结点附近插入、删除和查找前驱的效率（以空间换时间）。

2. 计算机体系结构（Computer Architecture）

> [!success]- 答案 15
> **答案**：
> 
> **定义**：指程序员所看到的计算机系统的属性，即计算机系统的概念性结构和功能特性。
> 
> **内涵**：它主要研究软硬件功能的分配和界限，包括指令集结构（ISA）、数据表示、寻址方式、寄存器组织、中断机制等。
> 
> **区别**：它不同于"计算机组成"（Organization），后者关注具体的硬件实现（如数据通路宽度、缓存策略）。体系结构决定了计算机"能做什么"，组成决定了"怎么做"。

3. 互动媒体（Interactive Media）与游戏化思维（Gamification）

> [!success]- 答案 16
> **答案**：
> 
> **（1）互动媒体**：指利用数字技术，使用户能够通过输入（点击、触摸、语音等）主动参与内容并获得即时反馈的媒体形式。其核心是双向传播和用户参与（如交互网页、VR 体验）。
> 
> **（2）游戏化思维**：是一种将游戏的设计元素（如点数、徽章、排行榜）和心理机制（如挑战、竞争、成就感）应用于非游戏场景（如教育、管理、环保）的方法。
> 
> **（3）联系与区别**：互动媒体是技术载体或表现形式；游戏化思维是设计策略或方法论。互动媒体不一定包含游戏机制（如 ATM 机），但游戏化思维通常需要依托互动媒体来实现。

### 五、辨析题（每题 8 分，共 16 分）

1. 辨析"互联网+"与"+互联网"的区别。

> [!success]- 答案 17
> **答案**：
> 
> **1. 不是简单的物理叠加**："互联网+"不仅仅是把互联网作为工具加到传统行业上（如开个网店），而是利用信息通信技术和互联网平台，让互联网与传统行业进行深度融合。
> 
> **2. 化学反应与重构**：它的本质是要素重组和模式创新。它改变了传统行业的生产方式、组织结构和商业模式（如"互联网+交通"诞生了网约车，"互联网+金融"诞生了移动支付）。
> 
> **3. 创新驱动**："互联网+"更强调以互联网思维（用户至上、极致体验）去改造传统产业，创造新的发展生态。

2. 辨析题：有人说，中国互联网企业和传统制造业已经没有边界了。这种说法对吗？请说明理由。

> [!success]- 答案 18
> **答案**：
> 
> **1. 边界模糊（正确的一面）**：随着工业互联网（Industrial Internet）和智能制造的发展，互联网企业（如小米、华为）开始涉足造车、造硬件，深度介入制造环节；传统制造业（如美的、海尔）也在通过物联网和大数据转型为数据驱动的服务商。两者的业务链条确实在深度交叉。
> 
> **2. 核心能力差异（不正确的一面）**：尽管融合加深，但两者的核心基因仍有区别。互联网企业更擅长软件、算法、用户运营和快速迭代；传统制造业更擅长精密加工、供应链管理和硬件品控。
> 
> **3. 结论**：说"完全没有边界"过于绝对，更准确的说法是两者正在相互渗透、跨界融合，形成了"数实融合"的新产业形态。

### 六、简答与计算题（共 62 分）

1. （9 分）某空调厂商售出一台空调可盈利 100 元。若该空调在一年内发生故障，厂商承诺免费更换，此时厂商将转为亏损 300 元。假设一台空调一年内发生故障的寿命 $X$（年）服从参数为 $\lambda = 1/4$ 的指数分布。求厂商售出一台空调的平均盈利期望。

> [!success]- 答案 19
> **答案**：$E(Y) = 400e^{-0.25} - 300 \approx 11.52$ 元

> [!tip]- 解析 19
> **解析**：
> 
> **（1）建立模型**：设厂商的盈利为随机变量 $Y$
> - 若空调一年内不故障（$X > 1$），则 $Y = 100$
> - 若空调一年内故障（$X \leq 1$），则 $Y = -300$
> 
> **（2）计算概率**：寿命 $X \sim E(0.25)$，其概率密度 $f(x) = 0.25e^{-0.25x}$（$x > 0$）
> 
> 故障概率：$P(X \leq 1) = 1 - e^{-0.25}$
> 
> 不故障概率：$P(X > 1) = e^{-0.25}$
> 
> **（3）计算期望**：
> 
> $$E(Y) = 100 \times P(X > 1) + (-300) \times P(X \leq 1)$$
> $$= 100 \cdot e^{-0.25} - 300 \cdot (1 - e^{-0.25})$$
> $$= 100e^{-0.25} - 300 + 300e^{-0.25}$$
> $$= 400e^{-0.25} - 300$$
> 
> 数值解：$e^{-0.25} \approx 0.7788$，则 $E(Y) \approx 400(0.7788) - 300 = 311.52 - 300 = 11.52$ 元

2. （9 分）设二维随机变量 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = \begin{cases} ke^{-3x-4y}, & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}
$$

（1）求常数 $k$；

> [!success]- 答案 20
> **答案**：$k = 12$

> [!tip]- 解析 20
> **解析**：
> 
> 利用规范性：
> 
> $$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$$
> 
> $$\int_0^{+\infty} \int_0^{+\infty} ke^{-3x-4y} \, dx \, dy = 1$$
> 
> $$k \left(\int_0^{+\infty} e^{-3x} \, dx\right) \left(\int_0^{+\infty} e^{-4y} \, dy\right) = 1$$
> 
> $$k \cdot \left[-\frac{1}{3}e^{-3x}\right]_0^{+\infty} \cdot \left[-\frac{1}{4}e^{-4y}\right]_0^{+\infty} = 1$$
> 
> $$k \cdot \frac{1}{3} \cdot \frac{1}{4} = 1 \Rightarrow \frac{k}{12} = 1 \Rightarrow k = 12$$

（2）求 $X$ 和 $Y$ 的联合分布函数 $F(x, y)$；

> [!success]- 答案 21
> **答案**：
> 
> $$F(x, y) = \begin{cases} (1 - e^{-3x})(1 - e^{-4y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$$

> [!tip]- 解析 21
> **解析**：
> 
> 当 $x > 0, y > 0$ 时：
> 
> $$F(x, y) = \int_0^x \int_0^y 12e^{-3u-4v} \, du \, dv$$
> $$= 12 \left(\int_0^x e^{-3u} \, du\right) \left(\int_0^y e^{-4v} \, dv\right)$$
> $$= 12 \cdot \frac{1}{3}(1 - e^{-3x}) \cdot \frac{1}{4}(1 - e^{-4y})$$
> $$= (1 - e^{-3x})(1 - e^{-4y})$$

（3）计算 $P(0 < X < 1, 0 < Y < 2)$。

> [!success]- 答案 22
> **答案**：$(1 - e^{-3})(1 - e^{-8})$

> [!tip]- 解析 22
> **解析**：
> 
> $$P(0 < X < 1, 0 < Y < 2) = F(1, 2) - F(0, 2) - F(1, 0) + F(0, 0)$$
> 
> 由于 $F(0, \cdot) = 0$，实际上就是 $F(1, 2)$
> 
> $$= (1 - e^{-3 \times 1})(1 - e^{-4 \times 2}) = (1 - e^{-3})(1 - e^{-8})$$

3. （6 分）简述计算机系统中"接口（Interface）"、"接口电路（Interface Circuit）"和"端口（Port）"三个概念的区别与联系。

> [!success]- 答案 23
> **答案**：
> 
> **区别**：
> 
> - **接口**：是标准/规范（如 USB 协议），定义了连接的物理特性和逻辑规则
> - **接口电路**：是硬件实现（如 USB 控制器芯片），是连接 CPU 和外设的桥梁
> - **端口**：是接口电路中可被 CPU 寻址的寄存器（如数据端口、状态端口），是软件操作的直接对象
> 
> **联系**：CPU 通过接口电路中的端口，遵循接口规范，实现与外设的数据交换。

6. （8 分）已知两棵二叉树 $T_1$ 和 $T_2$，请设计一个算法判断它们是否完全相同。给出算法思想、时间复杂度分析及 C 语言实现。

> [!success]- 答案 26
> **答案**：
> 
> **算法思想**：采用递归策略。两棵树相同当且仅当：
> 1. 根节点都为空（相同）
> 2. 根节点一个空一个不空（不相同）
> 3. 根节点都不空，但值不同（不相同）
> 4. 根节点值相同，且左子树相同且右子树相同
> 
> **时间复杂度**：$O(n)$，其中 $n$ 为两棵树中节点数的较小值

> [!example]- 代码实现
> ```c
> typedef struct BiTNode {
>     int data;
>     struct BiTNode *lchild, *rchild;
> } BiTNode, *BiTree;
> 
> int IsIdentical(BiTree T1, BiTree T2) {
>     // 1. 均为空，相同
>     if (T1 == NULL && T2 == NULL)
>         return 1;
>     
>     // 2. 一个空一个不空，不同
>     if (T1 == NULL || T2 == NULL)
>         return 0;
>     
>     // 3. 值不同，不同
>     if (T1->data != T2->data)
>         return 0;
>     
>     // 4. 递归判断左右子树
>     return IsIdentical(T1->lchild, T2->lchild) &&
>            IsIdentical(T1->rchild, T2->rchild);
> }
> ```

7. （8 分）已知两个有序（递增）单链表 $LA$ 和 $LB$，请设计一个算法将它们合并为一个新的有序（递增）单链表 $LC$。给出算法思想、时间复杂度分析及 C 语言实现。

> [!success]- 答案 27
> **答案**：
> 
> **算法思想**：使用"尾插法"。维护三个指针：pa 指向 $LA$ 当前节点，pb 指向 $LB$ 当前节点，pc 指向 $LC$ 尾部（初始指向头结点）。
> 
> 循环比较 pa->data 和 pb->data：
> - 若 pa 小，将 pa 接到 pc 后面，pa 后移
> - 若 pb 小，将 pb 接到 pc 后面，pb 后移
> - 直到一表为空，将另一表剩余部分直接接到 pc 后面
> 
> **时间复杂度**：$O(m + n)$，其中 $m, n$ 分别为两个链表的长度

> [!example]- 代码实现
> ```c
> typedef struct Node {
>     int data;
>     struct Node *next;
> } Node, *LinkList;
> 
> void MergeList(LinkList *La, LinkList *Lb, LinkList *Lc) {
>     // 使用 La 的头结点作为 Lc 的头结点
>     *Lc = *La;
>     Node *pc = *Lc;  // pc 指向 Lc 的尾部
>     
>     Node *pa = (*La)->next;  // pa 指向首元结点
>     Node *pb = (*Lb)->next;  // pb 指向首元结点
>     
>     while (pa && pb) {
>         if (pa->data <= pb->data) {
>             pc->next = pa;  // 摘取 pa
>             pc = pa;        // 更新尾指针
>             pa = pa->next;
>         } else {
>             pc->next = pb;  // 摘取 pb
>             pc = pb;
>             pb = pb->next;
>         }
>     }
>     
>     // 插入剩余段
>     pc->next = (pa != NULL) ? pa : pb;
>     
>     // 释放 Lb 的头结点
>     free(*Lb);
> }
> ```
