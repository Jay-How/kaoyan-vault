# 清华大学深圳国际研究生院 2020 年硕士研究生入学考试

## 843 互联网+创新设计专业基础综合

### 一、填空题（每小题 3 分，共 15 分）

1. 十六进制数 $(2B.8)_H$ 转换为八进制数是（ ）。

2. 计算机的总线按其功能和传输信息的不同，可分为（ ）、（ ）和（ ）三种。

3. 数据结构的三要素是数据的（ ）、（ ）和（ ）。

4. 线性表若采用链式存储结构，其优点是便于插入和删除操作，但其缺点是不能进行（ ）存取。

5. 栈（Stack）和队列（Queue）都是操作受限的线性表。其中，栈的操作特性是（ ），队列的操作特性是（ ）。

### 二、判断题（每小题 3 分，共 15 分）

1. MIPS（Millions of Instructions Per Second）是衡量 CPU 性能的唯一标准，MIPS 值越高，代表计算机的实际运算能力越强。（ ）

2. DMA（Direct Memory Access）方式在进行数据传输时，完全不需要 CPU 的干预，数据传输过程完全由 DMA 控制器（DMAC）控制。（ ）

3. ARP（Address Resolution Protocol）协议的功能是已知目标设备的 IP 地址，查询其对应的 MAC 地址。（ ）

4. ICMP（Internet Control Message Protocol）协议是 TCP/IP 协议簇的组成部分，它封装在 IP 数据报中传输，用于报告差错情况和提供网络诊断信息。（ ）

5. 稀疏图（Sparse Graph）适合采用邻接矩阵存储，而稠密图（Dense Graph）适合采用邻接表存储。（ ）

### 三、选择题（每小题 3 分，共 21 分）

1. 在参数估计中，用样本矩来代替相应的总体矩，从而得到参数估计量的方法称为（ ）。

2. 堆排序在最坏情况下的时间复杂度和平均空间复杂度分别是（ ）。

3. 某 C 类网络地址为 192.168.10.0，现需要将其划分为至少 5 个子网，则应选用的子网掩码是（ ）。

4. 在计算机系统总线中，以下哪种不属于按数据传输方式分类的总线类型（ ）。

5. 下列排序算法中，哪一种是不稳定的排序方法（ ）。

6. 在 TCP/IP 协议簇中，负责在两个应用进程之间提供端到端的、不可靠的数据报服务的协议是（ ）。

7. 计算机中表示带符号整数最常用的编码方式是（ ）。

### 四、名词解释题（每小题 6 分，共 24 分）

1. 树（Tree）与二叉树（Binary Tree）

2. ROM（Read-Only Memory）与 RAM（Random-Access Memory）

3. HTTP（HyperText Transfer Protocol）与 FTP（File Transfer Protocol）

4. 新媒体艺术（New Media Art）

### 五、简答题（共 39 分）

1. （15 分）请写出 OSI（Open Systems Interconnection）七层参考模型的全部名称（从低到高），并简述每一层的主要功能及其传输的数据单元（PDU）名称。

2. （12 分）结合你所了解的具体艺术作品或设计案例，谈谈你对"新媒体艺术"的理解及其社会价值。

3. （12 分）你认为互动媒体设计（Interactive Media Design）与传统艺术（如绘画、雕塑）最核心的区别是什么？请举例说明。

### 六、计算题（共 16 分）

设二维随机变量 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = \begin{cases} k(x + y), & 0 \leq x \leq 1, 0 \leq y \leq 1 \\ 0, & \text{其他} \end{cases}
$$

（1）求常数 $k$ 的值。（6 分）

（2）求边缘概率密度 $f_X(x)$ 和 $f_Y(y)$。（6 分）

（3）判断 $X$ 和 $Y$ 是否相互独立，并说明理由。（4 分）

### 七、设计手绘题（20 分）

题目：信息时代的哪吒

请以"信息时代的哪吒"为主题，设计一个 20cm×20cm 的混合功能地图，要求：

1. 绘制一个科技感的哪吒形象
2. 将哪吒的法宝（混天绫、乾坤圈、风火轮、三头六臂）与现代科技概念进行映射
3. 采用信息图表（Infographic）风格布局
4. 附 100 字以内的设计说明
