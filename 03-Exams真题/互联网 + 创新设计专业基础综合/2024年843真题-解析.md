## 843 互联网+创新设计专业基础综合（参考答案与解析）

### 一、填空题（每题 3 分，共 15 分）

1. 设 $A, B$ 两个事件相互独立，已知 $P(A) = 0.7$，$P(A \cup B) = 0.88$，则 $P(A - B) =$（ ）。

> [!success]- 答案 1
> **答案**：$0.28$

> [!tip]- 解析 1
> **解析**：
> 
> 1. $P(A \cup B) = P(A) + P(B) - P(AB)$。因独立，$P(AB) = P(A)P(B) = 0.7P(B)$
> 
> 2. $0.88 = 0.7 + P(B) - 0.7P(B) \Rightarrow 0.18 = 0.3P(B) \Rightarrow P(B) = 0.6$
> 
> 3. $P(A - B) = P(A) - P(AB) = P(A) - P(A)P(B) = 0.7 - 0.7 \times 0.6 = 0.7 - 0.42 = 0.28$

2. 散列表长度 $m = 14$，哈希函数为 $H(key) = key \% 11$。现有数据 $\{15, 38, 61, 84\}$ 已按其哈希地址 4, 5, 6, 7 存入表中。若采用线性探测法解决冲突，现在插入关键字 49，应存放的地址是（ ）。

> [!success]- 答案 2
> **答案**：$8$

> [!tip]- 解析 2
> **解析**：
> 
> 1. 计算哈希值：$H(49) = 49 \% 11 = 5$
> 2. 探测地址 5：已被 38 占用（冲突）
> 3. 探测地址 6：已被 61 占用（冲突）
> 4. 探测地址 7：已被 84 占用（冲突）
> 5. 探测地址 8：空闲，存入

3. OSI 参考模型中，负责在两个相邻节点之间（点对点）提供流量控制功能的层次是（ ）。

> [!success]- 答案 3
> **答案**：数据链路层（Data Link Layer）

> [!tip]- 解析 3
> **解析**：
> 
> 数据链路层负责在相邻节点（Node-to-Node）之间传输帧，并提供流量控制和差错控制。网络层负责端到端（Host-to-Host）的控制。

4. 一个 B 类 IP 地址网络，若采用的子网掩码是 255.255.240.0，则该网络中每个子网最多能容纳的主机个数为（ ）。

> [!success]- 答案 4
> **答案**：$4094$

> [!tip]- 解析 4
> **解析**：
> 
> 1. 掩码 255.255.240.0 对应二进制前 20 位为 1（/20）
> 2. 主机位长度 $= 32 - 20 = 12$ 位
> 3. 最大主机数 $= 2^{12} - 2$（减去全 0 网络地址和全 1 广播地址）$= 4096 - 2 = 4094$

5. 对 50TB 的海量数据文件进行排序，应主要采用（ ）排序方法。

> [!success]- 答案 5
> **答案**：外部（External）或归并（Merge）

> [!tip]- 解析 5

### 二、判断题（每题 3 分，共 15 分）

1. 若要实现一个链式队列，采用带有头指针和尾指针的循环单链表是最好的结构选择。（ ）

> [!success]- 答案 6
> **答案**：✗（错误）

> [!tip]- 解析 6
> **解析**：
> 
> 对于循环单链表，若只设置一个尾指针（rear），访问尾节点是 $O(1)$，访问头节点（rear->next）也是 $O(1)$。这是最节省且高效的结构。若带头指针和尾指针，虽然也能实现，但不如"仅设尾指针"简洁高效（多维护一个变量）。

2. 为了让数字信号在信道上传递得更远，可以在传输路径上使用放大器。（ ）

> [!success]- 答案 7
> **答案**：✗（错误）

> [!tip]- 解析 7
> **解析**：
> 
> 模拟信号使用放大器（Amplifier），它在放大信号的同时也放大了噪声。
> 
> 数字信号应使用中继器（Repeater）或再生器，它能将衰减、变形的信号整形再生，消除噪声积累。

3. 在假设检验（显著性检验）中，若要同时降低犯第一类错误和第二类错误的概率，唯一的方法是扩大样本容量。（ ）

> [!success]- 答案 8
> **答案**：✓（正确）

> [!tip]- 解析 8
> **解析**：
> 
> 第一类错误概率 $\alpha$ 和第二类错误概率 $\beta$ 在样本量 $n$ 固定时是此消彼长的。要同时减小它们，必须增加信息量，即增大样本容量 $n$。

4. 在计算机中，浮点数的"下溢"（Underflow）指的是浮点数的值小于所能表示的负数最小值。（ ）

> [!success]- 答案 9
> **答案**：✗（错误）

> [!tip]- 解析 9
> **解析**：
> 
> - **下溢（Underflow）**：指绝对值太小，接近于 0，低于机器所能表示的最小正数（即在 0 到最小正规格化数之间）。通常处理为 0
> - **上溢（Overflow）**：指绝对值太大，超过了机器所能表示的最大数
> 
> "小于负数最小值"实际上是绝对值过大（负无穷方向），属于上溢。

5. 根据列维—林德伯格中心极限定理，若 $S_n = X_1 + X_2 + \cdots + X_n$ 服从正态分布，则 $X_i$ 只需要满足具有相同的数学期望即可。（ ）

> [!success]- 答案 10
> **答案**：✗（错误）

> [!tip]- 解析 10
> **解析**：
> 
> 列维-林德伯格中心极限定理要求 $X_i$ 必须是独立且同分布（i.i.d）的，即不仅期望相同，方差和分布形式也必须相同，且方差有限。

### 三、选择题（每题 3 分，共 21 分）

1. 设随机变量 $X \sim N(0, 1)$，$\Phi(x)$ 为其标准正态分布函数，则 $P(|X| > 2)$ 为（ ）。

> [!success]- 答案 11
> **答案**：A. $2(1 - \Phi(2))$

> [!tip]- 解析 11
> **解析**：
> 
> $$P(|X| > 2) = 1 - P(|X| \leq 2) = 1 - P(-2 \leq X \leq 2) = 1 - [\Phi(2) - \Phi(-2)]$$
> 
> 利用对称性 $\Phi(-2) = 1 - \Phi(2)$：
> 
> $$= 1 - [\Phi(2) - (1 - \Phi(2))] = 1 - [2\Phi(2) - 1] = 2 - 2\Phi(2) = 2[1 - \Phi(2)]$$

2. 设 $X$ 和 $Y$ 为两个相互独立的随机变量，其分布函数分别为 $F_X(x)$ 和 $F_Y(y)$。令 $Z = \max\{X, Y\}$，则 $Z$ 的分布函数 $F_Z(z)$ 为（ ）。

> [!success]- 答案 12
> **答案**：D. $F_Z(z) = 1 - [1 - F_X(z)][1 - F_Y(z)]$

> [!tip]- 解析 12
> **解析**：
> 
> $$F_Z(z) = P(Z \leq z) = 1 - P(Z > z)$$
> 
> $Z > z \Leftrightarrow \max\{X, Y\} > z \Leftrightarrow X > z$ 或 $Y > z$
> 
> 由于独立：
> 
> $$P(X > z, Y > z) = P(X > z)P(Y > z) = [1 - F_X(z)][1 - F_Y(z)]$$
> 
> 所以 $F_Z(z) = 1 - [1 - F_X(z)][1 - F_Y(z)]$

3. 邻接矩阵（Adjacency Matrix）存储结构最适用于以下哪种图？（ ）

> [!success]- 答案 13
> **答案**：C. 稠密图（Dense Graph）

4. 在一个已按升序排列的单链表中，插入一个新元素并保持其有序性的时间复杂度为（ ）。

> [!success]- 答案 14
> **答案**：C. $O(n)$

> [!tip]- 解析 14

5. 防火墙（Firewall）无法实现的网络功能是（ ）。

> [!success]- 答案 15
> **答案**：C. 终端准入控制（Terminal Access Control）

> [!tip]- 解析 15
> **解析**：
> 
> - VPN、NAT、访问控制 ACL 都是现代防火墙的标准功能
> - 终端准入控制（NAC）通常涉及对终端设备进行安全检查（如是否安装杀毒软件、补丁是否最新），这通常需要专门的 NAC 设备或软件客户端配合，纯网络边界防火墙难以深入终端内部进行检查

6. 某计算机地址总线为 32 位，Cache 容量为 32KB，块大小为 32B，采用直接映射和回写法（Write-back），则 Cache 每行（Cache Line）的总位数至少是（ ）。

> [!success]- 答案 16
> **答案**：A. 275

> [!tip]- 解析 16
> **解析**：
> 
> 1. Cache 容量 $= 32\text{KB} = 2^{15}\text{B}$
> 2. 块大小 $= 32\text{B} = 2^5\text{B}$，数据位 $= 32 \times 8 = 256$ bit
> 3. 行数 $= 2^{15} / 2^5 = 2^{10}$ 行
> 4. 地址结构：
>    - 块内偏移（Offset）：5 位
>    - 行索引（Index）：10 位
>    - 标记（Tag）：$32 - 10 - 5 = 17$ 位
> 5. 控制位：
>    - 有效位（Valid）：1 位
>    - 脏位/修改位（Dirty）：1 位（因为采用回写法）
> 6. 总位数 $= 256 + 17 + 1 + 1 = 275$ 位

7. 在一个含有 $n$ 个元素的有序线性表中进行折半查找（二分查找），最多需要比较的次数是（ ）。

> [!success]- 答案 17
> **答案**：A. $\lfloor \log_2 n \rfloor + 1$

> [!tip]- 解析 17
> **解析**：
> 
> 二分查找判定树的高度即为最大比较次数，即 $\lfloor \log_2 n \rfloor + 1$。

### 四、名词解释题（每题 6 分，共 18 分）

1. RAM（Random Access Memory）、CPU（Central Processing Unit）、GPU（Graphics Processing Unit）

> [!success]- 答案 18
> **答案**：
> 
> **（1）RAM（随机存取存储器）**：计算机的主存储器。具有易失性（断电数据丢失）和随机存取（读写速度与位置无关）的特性，用于暂时存放 CPU 中的运算数据及与硬盘等外部存储器交换的数据。
> 
> **（2）CPU（中央处理器）**：计算机系统的运算和控制核心。主要由运算器（ALU）和控制器（CU）组成，负责解释计算机指令以及处理计算机软件中的数据。
> 
> **（3）GPU（图形处理器）**：专门用于处理图像和图形运算的微处理器。与 CPU 相比，GPU 拥有大量的计算核心，擅长大规模并行计算，如今广泛应用于游戏渲染、深度学习和科学计算。

2. 堆（Heap）、堆排序（Heap Sort）

> [!success]- 答案 19
> **答案**：
> 
> **（1）堆**：是一种特殊的完全二叉树结构。满足所有父节点的值都大于等于（或小于等于）其子节点的值。前者称为大顶堆，后者称为小顶堆。它通常用数组来实现。
> 
> **（2）堆排序**：是一种基于堆结构的选择排序算法。其基本思想是将待排序序列构造成一个大顶堆，此时整个序列的最大值就是堆顶的根节点。将其与末尾元素交换，然后将剩余 $n-1$ 个元素重新调整为堆，如此反复。其时间复杂度稳定为 $O(n \log n)$，空间复杂度为 $O(1)$。

3. 非物质设计（Immaterial Design）、网站转化率（Website Conversion Rate）

> [!success]- 答案 20
> **答案**：
> 
> **（1）非物质设计**：随着信息社会的发展，设计对象从有形的"物"转向了无形的"服务"、"体验"、"流程"和"数据"。它强调以非物质的形式满足人的需求，如交互设计、服务设计。其核心在于"去物质化"和关注"使用权"而非"所有权"。
> 
> **（2）网站转化率**：是衡量网站运营效果的核心商业指标。指完成特定目标行为（如购买商品、注册账号、下载文件）的访客人数占网站总访问人数的比例。
> 
> 公式：转化率 = (转化次数 / 总访问量) × 100%

### 五、辨析题（每题 6 分，共 12 分）

1. 辨析：用户的需求就是设计的目标。这种说法对吗？

> [!success]- 答案 21
> **答案**：
> 
> **1. 需求辨析（Needs vs Wants）**：用户口头表达的往往是表面的"想要"（Wants），而非深层的真实"需要"（Needs）。设计师需要透过现象看本质，而不是盲目满足表面诉求。
> 
> **2. 可行性与限制**：设计受限于技术可行性、商业成本、法律道德以及产品定位。满足"所有"需求会导致产品功能臃肿（Feature Creep），失去核心竞争力。
> 
> **3. 用户冲突**：不同用户群体的需求可能是冲突的。设计需要进行取舍，服务于核心目标用户。
> 
> **4. 结论**：UCD（User-Centered Design）的核心是理解用户，而非讨好用户。

2. 辨析：在游戏设计中增加奖励机制和成就系统，就是为了激励玩家不断复玩。这句话正确吗？

> [!success]- 答案 22
> **答案**：
> 
> **1. 公平性与竞技性**：对于竞技类游戏（如 MOBA, FPS），数值平衡是游戏存在的基石。如果角色或武器强弱失衡，会导致玩家流失，破坏游戏生态。
> 
> **2. 心流体验（Flow）**：对于单机或 PVE 游戏，数值平衡（难度曲线）决定了玩家的体验。过难导致焦虑，过易导致无聊。良好的数值设计能让玩家保持在"心流"通道中。
> 
> **3. 经济系统**：游戏内的经济数值平衡防止了通货膨胀，保证了游戏寿命。
> 
> **4. 例外**：纯叙事类或艺术类游戏可能弱化数值，但广义的"体验平衡"依然存在。

### 六、计算与简答题（共 54 分）

1. （6 分）设工厂售出一台设备的寿命 $X$（年）服从参数为 $\lambda = 0.25$ 的指数分布。若设备在一年内发生故障，工厂亏损 300 元；若设备在一年内不发生故障，工厂盈利 100 元。求工厂售出一台设备所获利润的数学期望。

> [!success]- 答案 23
> **答案**：$E(Y) = 400e^{-0.25} - 300 \approx 11.52$ 元

> [!tip]- 解析 23
> **解析**：
> 
> 设利润为 $Y$。寿命 $X \sim E(0.25)$。
> 
> 故障概率：$P(\text{故障}) = P(X \leq 1) = 1 - e^{-0.25}$
> 
> 不故障概率：$P(\text{ok}) = e^{-0.25}$
> 
> $Y$ 的分布律：
> - $Y = 100$，概率 $e^{-0.25}$
> - $Y = -300$，概率 $1 - e^{-0.25}$
> 
> $$E(Y) = 100 \times e^{-0.25} + (-300) \times (1 - e^{-0.25})$$
> $$= 100e^{-0.25} - 300 + 300e^{-0.25} = 400e^{-0.25} - 300$$
> 
> 数值解：$e^{-0.25} \approx 0.7788$，结果约为 $11.52$ 元

2. （9 分）设二维随机变量 $(X, Y)$ 在区域 $D = \{(x, y) | x \geq 0, y \geq 0, x + y \leq 1\}$ 上服从均匀分布。

（1）求 $X$ 的边缘概率密度函数 $f_X(x)$；

> [!success]- 答案 24
> **答案**：
> 
> $$f_X(x) = \begin{cases} 2(1 - x), & 0 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$$

> [!tip]- 解析 24
> **解析**：
> 
> 区域 $D$ 的面积 $S = \frac{1}{2} \times 1 \times 1 = 0.5$
> 
> 联合密度 $f(x, y) = \frac{1}{S} = 2$，当 $(x, y) \in D$
> 
> $X$ 的取值范围 $[0, 1]$
> 
> $$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_0^{1-x} 2 \, dy = 2(1 - x), \quad 0 \leq x \leq 1$$

（2）设 $Z = X + Y$，求 $Z$ 的分布函数 $F_Z(z)$ 和概率密度函数 $f_Z(z)$。

> [!success]- 答案 25
> **答案**：
> 
> $$F_Z(z) = \begin{cases} 0, & z < 0 \\ z^2, & 0 \leq z \leq 1 \\ 1, & z > 1 \end{cases}$$
> 
> $$f_Z(z) = \begin{cases} 2z, & 0 \leq z \leq 1 \\ 0, & \text{其他} \end{cases}$$

> [!tip]- 解析 25
> **解析**：
> 
> 由区域 $D$ 可知，$X + Y$ 的取值范围是 $[0, 1]$
> 
> 当 $0 \leq z \leq 1$ 时：
> 
> $$F_Z(z) = P(X + Y \leq z)$$
> 
> $X + Y \leq z$ 围成的区域是一个腰长为 $z$ 的等腰直角三角形
> 
> 其面积 $S = \frac{1}{2} z^2$
> 
> $$F_Z(z) = \iint_{X+Y \leq z} f(x, y) \, dx \, dy = 2 \times S = 2 \times \frac{1}{2} z^2 = z^2$$
> 
> 求导得密度函数：$f_Z(z) = 2z$，$0 \leq z \leq 1$

3. （8 分）已知两个有序（递增）单链表 $LA$ 和 $LB$，请设计一个算法将它们合并为一个新的有序（递增）单链表 $LC$。给出算法思想、时间复杂度分析及 C 语言实现。

> [!success]- 答案 26
> **答案**：
> 
> **算法思想**：使用双指针法遍历两个链表，比较节点值大小，较小者尾插入结果链表，最后连接剩余部分。
> 
> **时间复杂度**：$O(m + n)$

> [!example]- 代码实现
> ```c
> typedef struct Node {
>     int data;
>     struct Node *next;
> } Node, *LinkList;
> 
> void MergeList(LinkList *La, LinkList *Lb, LinkList *Lc) {
>     // 复用 La 的头结点
>     *Lc = *La;
>     Node *pc = *Lc;  // 尾指针
>     Node *pa = (*La)->next;
>     Node *pb = (*Lb)->next;
>     
>     while (pa && pb) {
>         if (pa->data <= pb->data) {
>             pc->next = pa;
>             pc = pa;
>             pa = pa->next;
>         } else {
>             pc->next = pb;
>             pc = pb;
>             pb = pb->next;
>         }
>     }
>     
>     // 链接剩余部分
>     pc->next = pa ? pa : pb;
>     
>     // 释放 Lb 头结点
>     free(*Lb);
> }
> ```

4. （8 分）设计一个算法，在一个包含 $n$ 个不同元素的线性表中，同时找出最大值和最小值。要求比较次数最坏不超过 $\frac{3n}{2} - 2$ 次。给出算法思想和 C 语言实现。

> [!success]- 答案 27
> **答案**：
> 
> **算法思想**：成对比较法。
> 1. 将元素两两分组
> 2. 先比较组内两个元素，较大的与当前最大值比较，较小的与当前最小值比较
> 3. 这样每组只需 3 次比较（而不是 4 次）
> 
> **时间复杂度**：$O(n)$，比较次数为 $\frac{3n}{2} - 2$（$n$ 为偶数）或 $\frac{3(n-1)}{2}$（$n$ 为奇数）

> [!example]- 代码实现
> ```c
> void FindMinMax(int A[], int n, int *max, int *min) {
>     if (n <= 0) return;
>     
>     int i;
>     *max = A[0];
>     *min = A[0];
>     
>     // 处理奇数个元素的情况
>     if (n % 2 == 1) {
>         i = 1;
>     } else {
>         if (A[0] > A[1]) {
>             *max = A[0];
>             *min = A[1];
>         } else {
>             *max = A[1];
>             *min = A[0];
>         }
>         i = 2;
>     }
>     
>     // 成对处理
>     while (i < n - 1) {
>         int local_max, local_min;
>         if (A[i] > A[i + 1]) {
>             local_max = A[i];
>             local_min = A[i + 1];
>         } else {
>             local_max = A[i + 1];
>             local_min = A[i];
>         }
>         
>         if (local_max > *max) *max = local_max;
>         if (local_min < *min) *min = local_min;
>         
>         i += 2;
>     }
> }
> ```

5. （6 分）计算机组成原理计算题：I/O 查询 vs DMA。

（1）设备 A 使用 I/O 查询方式，数据率为 2MB/s，缓冲区大小为 32 位。CPU 时钟频率为 500MHz，每次查询需要执行 10 条指令，每条指令平均需要 4 个时钟周期。求 CPU 用于设备 A 的时间百分比。

> [!success]- 答案 28
> **答案**：$4\%$

> [!tip]- 解析 28
> **解析**：
> 
> - 数据率：2MB/s
> - 缓冲大小：32 位 = 4B
> - 查询频率：为防丢失，必须在 buffer 满之前取走。时间间隔 $T = 4\text{B} / 2\text{MB/s} = 2\mu s$，即每 $2\mu s$ 必须查询一次（频率 500kHz）
> - CPU 开销：每次查询 10 条指令，总指令数/秒 $= 500,000 \times 10 = 5 \times 10^6$ 条
> - 时钟周期数：$5 \times 10^6 \times 4 = 20 \times 10^6$ 周期
> - 百分比：$\frac{20 \times 10^6}{500 \times 10^6} = 4\%$

（2）设备 B 使用 DMA 方式，数据率为 40MB/s，每次 DMA 传输块大小为 1000B。DMA 初始化和后处理共需 500 个时钟周期。CPU 时钟频率为 500MHz。求 CPU 用于设备 B 的时间百分比。

> [!success]- 答案 29
> **答案**：$4\%$

> [!tip]- 解析 29
> **解析**：
> 
> - 数据率：40MB/s
> - 块大小：1000B
> - 中断频率：$40\text{MB/s} / 1000\text{B} = 40,000$ 次/s
> - CPU 开销：每次 DMA 预/后处理 500 周期
> - 总周期数：$40,000 \times 500 = 20 \times 10^6$ 周期
> - 百分比：$\frac{20 \times 10^6}{500 \times 10^6} = 4\%$

7. （8 分）汽车设计史上曾有过一段时间盛行"有计划的报废"（Planned Obsolescence）。请谈谈你如何看待这种产品设计思路。

> **答案**：
> 
> **定义**："有计划的报废"是指设计者故意通过限制产品寿命或频繁更改外观流行趋势，诱导消费者废弃旧产品、购买新产品的策略。
>

>
