### 一、填空题（每题 3 分，共 15 分）

1. 设 $A, B, C$ 为三个随机事件，已知 $P(\bar{A} \cup \bar{B}) = 0.85$，$P(\bar{A} \cup \bar{B} \cup \bar{C}) = 0.93$，则 $P(AB - C) =$（ ）。

> [!success]- 答案 1
> **答案**：$0.08$

> [!tip]- 解析 1
> **解析**：
> 
> 1. $P(\bar{A} \cup \bar{B}) = P(\overline{AB}) = 1 - P(AB) = 0.85 \Rightarrow P(AB) = 0.15$
> 
> 2. $P(\bar{A} \cup \bar{B} \cup \bar{C}) = P(\overline{ABC}) = 1 - P(ABC) = 0.93 \Rightarrow P(ABC) = 0.07$
> 
> 3. $P(AB - C)$ 表示事件 $A$ 和 $B$ 发生但 $C$ 不发生的概率，即 $P(AB \cap \bar{C})$
> 
> 4. 根据概率性质：$P(AB) = P(ABC) + P(AB\bar{C})$
> 
> 5. $P(AB - C) = P(AB) - P(ABC) = 0.15 - 0.07 = 0.08$

2. 将 $k$ 个同义词（散列到同一地址）连续存入一个采用线性探测法解决冲突的散列表中，为查找第 $k$ 个插入的元素，最多需要探测（ ）次。

> [!success]- 答案 2
> **答案**：$k$

> [!tip]- 解析 2
> **解析**：
> 
> 假设哈希地址为 $H$：
> - 第 1 个元素探测 $H$，空闲，存入
> - 第 2 个元素探测 $H$（冲突），探测 $H+1$，存入
> - ...
> - 第 $k$ 个元素依次探测 $H, H+1, \ldots, H+k-2$（均冲突），最后探测 $H+k-1$，存入
> 
> 查找第 $k$ 个插入的元素（即位于 $H+k-1$ 的元素）时，需要从 $H$ 开始一直探测到 $H+k-1$，共需 $k$ 次比较。

3. 数据传输中，实现收发双方时钟同步的方式有（ ）传输和（ ）传输。

> [!success]- 答案 3
> **答案**：同步（Synchronous）、异步（Asynchronous）

4. 从 1000 个无序整数中找出前 10 个最大的数，最快的算法是使用（ ）结构（或算法）。

> [!success]- 答案 4
> **答案**：堆（Heap）或小顶堆（Min-Heap）

> [!tip]- 解析 4
> **解析**：
> 
> 处理 Top K 问题，堆排序（特别是维护一个大小为 K 的小顶堆）是标准最优解，时间复杂度为 $O(N \log K)$。这里 $N = 1000, K = 10$。

5. 已知主机 A 的 IP 地址为 202.93.120.77，主机 B 的 IP 地址为 150.23.55.200。假设两台主机均采用默认的 A 类、B 类或 C 类地址分类标准（未使用子网划分）。则主机 B 所在网络的定向广播（Directed Broadcast）地址为（ ）。主机 A 向其所在本地网络发送的受限广播（Limited Broadcast）地址为（ ）。

### 二、判断题（每题 3 分，共 15 分）

1. 若随机变量 $X$ 服从正态分布，$Y$ 服从均匀分布，且 $X$ 和 $Y$ 相互独立，则 $\text{Cov}(X, Y) = 0$。（ ）

> [!success]- 答案 6
> **答案**：✓（正确）

> [!tip]- 解析 6
> **解析**：
> 
> 相互独立一定不相关（协方差为 0）。无论分布类型如何，只要 $X$ 和 $Y$ 独立，必有 $E(XY) = E(X)E(Y)$，从而 $\text{Cov}(X, Y) = E(XY) - E(X)E(Y) = 0$。

2. 采用顺序存储结构的队列和栈（即顺序队列和顺序栈）在操作时都需要判断"溢出"状态。（ ）

> [!tip]- 解析 7
> **解析**：
> 
> 顺序存储结构需要预分配固定大小的数组。当存满时继续插入会发生"上溢"（Overflow），因此必须进行判满检查。

3. 稀疏矩阵的压缩存储可以采用三元组（Triple）表示非零元素。（ ）

> [!success]- 答案 8
> **答案**：✓（正确）

> [!tip]- 解析 8

4. 设 $X, Y$ 为两个独立同分布的随机变量，且方差 $D(X) = D(Y) > 0$，则 $X + Y$ 与 $X - Y$ 两个随机变量是线性无关的（即不相关）。（ ）

> [!success]- 答案 9
> **答案**：✓（正确）

> [!tip]- 解析 9
> **解析**：
> 
> 计算协方差：
> 
> $$\text{Cov}(X + Y, X - Y) = E[(X + Y)(X - Y)] - E(X + Y)E(X - Y)$$
> $$= E(X^2 - Y^2) - [E(X) + E(Y)][E(X) - E(Y)]$$
> $$= E(X^2) - E(Y^2) - [E(X)^2 - E(Y)^2]$$
> $$= [E(X^2) - E(X)^2] - [E(Y^2) - E(Y)^2]$$
> $$= D(X) - D(Y)$$
> 
> 因为独立同分布，所以 $D(X) = D(Y)$，故协方差为 0，不相关。

5. TCP 和 UDP 协议使用各自独立的端口号空间，它们可以在同一台主机上共存而互不干扰。（ ）

### 四、名词解释题（每题 6 分，共 18 分）

1. 数据结构（Data Structure）、算法（Algorithm）、程序（Program）

> [!success]- 答案 17
> **答案**：
> 
> **（1）数据结构**：是指相互之间存在一种或多种特定关系的数据元素的集合。它包含逻辑结构、存储结构和数据的运算三个方面。
> 
> **（2）算法**：是对特定问题求解步骤的一种描述，是指令的有限序列。算法必须具备有穷性、确定性、可行性、输入和输出五个特性。
> 
> **（3）程序**：是用某种计算机语言编写的、能被计算机执行的代码序列。
> 
> **辨析**：数据结构是算法处理的对象，算法是处理数据结构的策略，而程序是数据结构和算法在计算机上的具体实现（程序 = 数据结构 + 算法）。算法是抽象的，程序是具体的。

2. OSI 参考模型（OSI Model）、TCP/IP 模型（TCP/IP Model）

> [!success]- 答案 18
> **答案**：
> 
> **（1）OSI 参考模型**：即开放系统互连参考模型，由 ISO 制定，是一个 7 层的理论模型（物理层、数据链路层、网络层、传输层、会话层、表示层、应用层）。
> 
> **（2）TCP/IP 模型**：是互联网事实上的标准协议模型，通常分为 4 层（网络接口层、网际层、传输层、应用层）。
> 
> **辨析**：OSI 模型学术性强，分层清晰，但实现复杂；TCP/IP 模型实用性强，是当前互联网的基石。两者的主要区别在于层数划分和对会话/表示层的处理（TCP/IP 将其归并入应用层）。

3. 参与式设计（Participatory Design）、严肃游戏（Serious Game）

> [!success]- 答案 19
> **答案**：
> 
> **（1）参与式设计**：一种设计方法论，强调让设计过程中的所有利益相关者（特别是最终用户）直接参与到设计决策中来，以确保产品真正满足用户需求。
> 
> **（2）严肃游戏**：指不以娱乐为主要目的，而是将游戏机制应用于教育、医疗、军事演练、企业培训等领域的游戏。
> 
> **辨析**：参与式设计关注的是设计过程（如何做设计）；严肃游戏关注的是设计目的和应用领域（设计出来做什么）。两者常结合使用，例如通过参与式设计开发一款严肃游戏。

> 
> **3. 结论**：发散思维只是设计思维工具箱中的一种工具，设计思维是一套完整的以人为本的创新方法论。

### 六、简答与计算题（共 57 分）

1. （9 分）设某电子元件的寿命 $X$（单位：小时）的概率密度函数为：

$$
f(x) = \begin{cases} \frac{100}{x^2}, & x > 100 \\ 0, & x \leq 100 \end{cases}
$$

（1）求该元件在 150 小时内损坏的概率 $p$；

> [!success]- 答案 22
> **答案**：$p = \frac{1}{3}$

> [!tip]- 解析 22
> **解析**：
> 
> $$p = P(X \leq 150) = \int_{100}^{150} \frac{100}{x^2} \, dx = 100 \left[-\frac{1}{x}\right]_{100}^{150}$$
> $$= 100 \left(-\frac{1}{150} - \left(-\frac{1}{100}\right)\right) = 100 \left(\frac{1}{100} - \frac{1}{150}\right)$$
> $$= 1 - \frac{2}{3} = \frac{1}{3}$$

（2）现有 3 个此类电子元件独立工作，求 150 小时内，a) 3 个都损坏，b) 3 个都没损坏，c) 恰好有 1 个损坏的概率。

> [!success]- 答案 23
> **答案**：
> 
> a) $P(A) = p^3 = (1/3)^3 = 1/27$
> 
> b) $P(B) = (1-p)^3 = (2/3)^3 = 8/27$
> 
> c) $P(C) = C_3^1 p^1 (1-p)^2 = 3 \times (1/3) \times (4/9) = 4/9$

> [!tip]- 解析 23
> **解析**：
> 
> 这是一个 $n = 3, p = 1/3$ 的伯努利概型。

2. （12 分）设二维随机变量 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = \begin{cases} Ax^2y, & 0 < x < y < 1 \\ 0, & \text{其他} \end{cases}
$$

（1）求常数 $A$；

> [!success]- 答案 24
> **答案**：$A = 15$

> [!tip]- 解析 24
> **解析**：
> 
> $$\int_0^1 dx \int_x^1 Ax^2y \, dy = 1$$
> 
> 内层积分：
> 
> $$\int_x^1 Ax^2y \, dy = Ax^2 \left[\frac{y^2}{2}\right]_x^1 = \frac{Ax^2}{2}(1 - x^2) = \frac{A}{2}(x^2 - x^4)$$
> 
> 外层积分：
> 
> $$\frac{A}{2} \int_0^1 (x^2 - x^4) \, dx = \frac{A}{2} \left[\frac{x^3}{3} - \frac{x^5}{5}\right]_0^1 = \frac{A}{2} \left(\frac{1}{3} - \frac{1}{5}\right) = \frac{A}{2} \cdot \frac{2}{15} = \frac{A}{15}$$
> 
> 令 $\frac{A}{15} = 1 \Rightarrow A = 15$

（2）求 $X$ 和 $Y$ 的边缘概率密度函数 $f_X(x)$ 和 $f_Y(y)$；

> [!success]- 答案 25
> **答案**：
> 
> $$f_X(x) = \frac{15}{2}x^2(1 - x^2), \quad 0 < x < 1$$
> 
> $$f_Y(y) = 5y^4, \quad 0 < y < 1$$

> [!tip]- 解析 25
> **解析**：
> 
> $$f_X(x) = \int_x^1 15x^2y \, dy = 15x^2 \left[\frac{y^2}{2}\right]_x^1 = \frac{15}{2}x^2(1 - x^2), \quad 0 < x < 1$$
> 
> $$f_Y(y) = \int_0^y 15x^2y \, dx = 15y \left[\frac{x^3}{3}\right]_0^y = 5y^4, \quad 0 < y < 1$$

（3）求 $P(0 < X < 1/2, 0 < Y < 1)$。

> [!success]- 答案 26
> **答案**：$\frac{17}{64} \approx 0.2656$

> [!tip]- 解析 26
> **解析**：
> 
> 积分区域为 $0 < x < 0.5$ 且 $x < y < 1$。
> 
> $$P = \int_0^{0.5} f_X(x) \, dx = \int_0^{0.5} \frac{15}{2}(x^2 - x^4) \, dx$$
> $$= \frac{15}{2} \left[\frac{x^3}{3} - \frac{x^5}{5}\right]_0^{0.5} = \frac{15}{2} \left(\frac{1}{24} - \frac{1}{160}\right)$$
> $$= \frac{15}{2} \cdot \frac{20 - 3}{480} = \frac{15}{2} \cdot \frac{17}{480} = \frac{17}{64} \approx 0.2656$$

3. （9 分）证明一棵高度为 $h$（$h > 1$，根节点在第 1 层）的二叉树：（1）其叶结点数一定小于等于 $2^{h-1}$；（2）其内部结点（不包括根节点和叶节点）的数量一定小于 $2^{h-1} - 1$。

> [!success]- 答案 27
> **答案**：
> 
> **（1）证明**：在二叉树中，第 $i$ 层最多有 $2^{i-1}$ 个结点。
> 
> 高度为 $h$ 的树，其叶子结点可能出现在各层，但若要叶子结点最多，该树应为满二叉树，且所有叶子都在第 $h$ 层。
> 
> 此时叶子数 $n_0 = 2^{h-1}$。对于非满二叉树，叶子数显然更少。
> 
> 故 $n_0 \leq 2^{h-1}$。得证。
> 
> **（2）证明**：满二叉树的总节点数为 $2^h - 1$。
> 
> 叶子节点数 $n_0 = 2^{h-1}$。
> 
> 根节点数 $= 1$。
> 
> 内部节点（度不为 0 且非根）数量 $N_{internal} = $ 总数 $-$ 叶子 $-$ 根。
> 
> $$N_{internal} = (2^h - 1) - 2^{h-1} - 1 = 2 \cdot 2^{h-1} - 2^{h-1} - 2 = 2^{h-1} - 2$$
> 
> 显然 $2^{h-1} - 2 < 2^{h-1} - 1$。
> 
> 对于非满二叉树，内部节点只会更少。故得证。

4. （9 分）已知两个有序（递增）线性表 $A$ 和 $B$，$A$ 采用顺序存储结构（数组），$B$ 采用链式存储结构（单链表）。请设计一个算法，将 $A$ 和 $B$ 合并为一个新的有序（递增）线性表 $C$，要求 $C$ 采用链式存储结构。给出算法思想、时间复杂度分析及 C 语言实现。

> [!success]- 答案 28
> **答案**：
> 
> **算法思想**：
> 1. 初始化新链表 $C$ 的头结点
> 2. 设置指针 $i$ 指向数组 $A$ 的起始位置 0，指针 $p$ 指向链表 $B$ 的第一个数据结点，指针 $r$ 指向 $C$ 的尾部
> 3. 循环比较 $A[i]$ 与 $p \rightarrow data$：
>    - 若 $A[i] \leq p \rightarrow data$：创建一个新结点存 $A[i]$，链接到 $r$ 后，$i++$
>    - 若 $A[i] > p \rightarrow data$：创建一个新结点存 $p \rightarrow data$，链接到 $r$ 后，$p = p \rightarrow next$
> 4. 当某一表遍历完，将另一表的剩余部分链接到 $C$ 的尾部
> 
> **时间复杂度**：$O(m + n)$，其中 $m, n$ 分别为两个线性表的长度

> [!example]- 代码实现
> ```c
> typedef struct Node {
>     int data;
>     struct Node *next;
> } Node, *LinkedList;
> 
> LinkedList MergeHybrid(int A[], int n, LinkedList B) {
>     int i = 0;
>     Node *p = B->next;  // 假设 B 带头结点
>     
>     // 创建头结点
>     LinkedList C = (Node*)malloc(sizeof(Node));
>     C->next = NULL;
>     Node *r = C;  // 尾指针
>     
>     while (i < n && p != NULL) {
>         Node *newNode = (Node*)malloc(sizeof(Node));
>         if (A[i] <= p->data) {
>             newNode->data = A[i];
>             i++;
>         } else {
>             newNode->data = p->data;
>             p = p->next;
>         }
>         newNode->next = NULL;
>         r->next = newNode;
>         r = newNode;
>     }
>     
>     // 处理 A 剩余部分
>     while (i < n) {
>         Node *newNode = (Node*)malloc(sizeof(Node));
>         newNode->data = A[i++];
>         newNode->next = NULL;
>         r->next = newNode;
>         r = newNode;
>     }
>     
>     // 处理 B 剩余部分（直接链接）
>     if (p != NULL) {
>         r->next = p;
>     }
>     
>     return C;
> }
> ```

5. （9 分）某信道的带宽为 50 kHz，信噪比（S/N）为 20 dB，且信号使用 8 个离散状态（8 种电平）进行编码。

（1）根据奈奎斯特（Nyquist）定理，该信道的最高数据传输速率是多少？

> [!success]- 答案 29
> **答案**：300 kbps

> [!tip]- 解析 29
> **解析**：
> 
> $V = 8$（信号状态数）
> 
> $$C_{Nyquist} = 2B \log_2 V = 2 \times 50\text{kHz} \times \log_2 8 = 100 \times 3 = 300 \text{ kbps}$$

（2）根据香农（Shannon）定理，该信道的理论极限数据传输速率是多少？

> [!success]- 答案 30
> **答案**：$\approx 332.9$ kbps

> [!tip]- 解析 30
> **解析**：
> 
> 信噪比 20 dB，即 $10 \log_{10}(S/N) = 20 \Rightarrow S/N = 10^2 = 100$
> 
> $$C_{Shannon} = B \log_2(1 + S/N) = 50\text{kHz} \times \log_2(1 + 100) = 50 \times \log_2 101 \approx 50 \times 6.658 \approx 332.9 \text{ kbps}$$
