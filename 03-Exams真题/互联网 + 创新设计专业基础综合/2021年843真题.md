### 四、 名词解释题

1. 连通图 (Connected Graph) 与 最小生成树 (Minimum Spanning Tree) 连通图：在无向图中，如果从顶点 *vi*到顶点 *vj*有路径，则称 *vi*和 *vj*是连通的。如果图中任 意两个顶点都是连通的，则称该图为连通图。 最小生成树：是在一个带权连通无向图中，包含图中所有顶点（*n* 个），且边的数量最少（ *n* − 1 条）并保持图连通的子图（即一棵树），且这棵树的所有边的权值之和最小。 辨析：连通图是图的一种性质状态，而最小生成树是基于带权连通图构造出的一种特殊的极 小连通子图（优化结构）。
2. 接口 (Interface), 接口电路 (Interface Circuit), 端口 (Port) 接口：是计算机系统中两个独立的子系统（如 CPU 与外设）之间进行数据、控制和状态信息 交换的交接点或连接标准。 接口电路：是实现接口功能的硬件电路。它通常包含数据寄存器、控制逻辑和状态寄存器， 用于解决 CPU 与外设在速度、电平、时序等方面的不匹配问题。 端口：是指接口电路中可以被 CPU 直接访问（读写）的寄存器。例如数据端口、状态端口和 控制端口。CPU 通过地址总线寻址这些端口来进行 I/O 操作。
3. 设计驱动式创新 (Design-Driven Innovation), 互联网思维 (Internet Thinking) 设计驱动式创新：是一种通过赋予产品新的意义 (Meaning) 和语言来创造竞争优势的创新模 式。它区别于“技术驱动”和“市场驱动”，侧重于挖掘用户深层次的、未被表达的情感和文 化需求（例如苹果 iPhone 对手机定义的重构）。 互联网思维：是指在（移动）互联网+、大数据、云计算等科技不断发展的背景下，对市场、 用户、产品、企业价值链乃至整个商业生态进行重新审视的思考方式。其核心包括用户至

上、体验为王、迭代创新、流量思维等。 辨析：设计驱动式创新侧重于“意义的重构”；互联网思维侧重于“利用数字技术重构商业模 式和效率”。

### 五、 辨析题

1. 辨析题：设计就是“产品外观的创新”。这种说法对吗？请说明理由。 判断：这种说法是错误（片面）的。 理由：
1. 定义误区：将设计等同于“美化”或“造型”是工业设计早期的狭隘理解。
2. 现代设计内涵：现代设计（特别是“互联网+”背景下的设计）已经从单纯的“造物”演 变为 “解决问题” 的系统工程。它不仅包含视觉/形态设计（外观），还包含交互设计 （易用性）、服务设计（流程体验）、商业模式设计等。
3. 核心价值：设计的核心是 “以人为本”，即发现用户的痛点，并利用技术手段提供解决方 案，而外观只是解决方案的载体之一。例如，一个外观普通的 App 如果能高效解决挂号 难的问题，它依然是优秀的设计。
2. 辨析题：“互联网思维”既是一种技术，也是一种思维方式。这种说法对吗？请说明理由。 判断：这种说法是部分正确，但不够严谨（或倾向于认为互联网思维本质是思维方式，而非 技术本身）。 理由：
1. 技术基础：互联网思维确实是建立在互联网技术（连接、大数据、云计算）高度发展的基 础之上的。没有技术作为底层支撑，这种思维无法落地。
2. 本质界定：但严格来说，“互联网思维”本身不是技术，而是一种方法论和价值观。它是 指像互联网产品一样思考：如何低成本获取用户（免费思维）、如何快速响应变化（迭代 思维）、如何连接一切（平台思维）。
3. 结论：因此，更准确的说法是：互联网思维是基于互联网技术特征而演化出的一种全新的 商业与设计思维方式。不能将“思维”直接等同于“技术”。

6. 简述影响 CPU 性能的主要技术指标，并说明高速缓存 (Cache) 在计算机系统中的主要作用。 CPU 主要性能指标：
1. 主频 (Clock Speed)：CPU 的时钟频率，单位 Hz，通常越高越快。
2. 字长 (Word Length)：CPU 一次能处理的数据位数（如 32 位、64 位），影响精度和寻 址范围。
3. 核心数 (Core Count)：物理核心的数量，影响多任务处理能力。
4. CPI (Cycles Per Instruction)：执行每条指令所需的平均时钟周期数。
5. 总线速度：数据传输带宽。
Cache 的作用： 缓解速度差异：主要用于解决 CPU 极高的运算速度 与 主存 (RAM) 相对较慢的读写速 度 之间的矛盾。

原理：利用程序的局部性原理 (Locality)，将 CPU 近期可能用到的数据和指令预先从 主存复制到速度更快的 Cache 中。CPU 访问数据时优先查找 Cache，从而减少访问主 存的次数，显著提高系统整体性能。
