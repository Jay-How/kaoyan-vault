# 反函数求法 - 换元法

> [!question] 题目
> 已知 $f(x) = \frac{1-\sqrt{1+x}}{1+\sqrt{1+x}}$，求反函数。
> 

> [!failure] 我的错误答案
> 
> 定义域：$D_f = [-1, +\infty)$

> [!success] 正确答案
> 
> **第一步：换元转化**
> 
> 设 $y = f(x)$，令 $t = \sqrt{1+x}$，则原式转化为：
> $$y = \frac{1-t}{1+t}$$
> 
> **第二步：反解中间变量**
> 
> 由 $y = \frac{1-t}{1+t}$ 反解出 $t$：
> $$t = \frac{1-y}{1+y}$$
> 
> **第三步：代回求解**
> 
> 将 $t = \sqrt{1+x}$ 代入：
> $$\sqrt{1+x} = \frac{1-y}{1+y}$$
> 
> 两边平方：
> $$1+x = \left(\frac{1-y}{1+y}\right)^2 = \frac{(1-y)^2}{(1+y)^2}$$
> 
> 解出 $x$：
> $$x = \frac{(1-y)^2}{(1+y)^2} - 1 = \frac{(1-y)^2 - (1+y)^2}{(1+y)^2} = \frac{-4y}{(1+y)^2}$$
> 
> **第四步：写出反函数**
> 
> 交换 $x$ 和 $y$，得反函数：
> $$\boxed{y = \frac{-4x}{(1+x)^2}}$$

## 错误分析

### 错误原因

**计算错误** - 求反函数的过程中，对分式进行代数运算时出现错误，特别是在将 $\sqrt{1+x} = \frac{1-y}{1+y}$ 两边平方后，展开合并同类项时出错。

### 正确思路

**核心方法：换元法简化复合根式**

1. **识别结构**：原函数含有 $\sqrt{1+x}$，属于复合根式结构
2. **设中间变量**：令 $t = \sqrt{1+x}$，将根式转化为简单的分式函数
3. **逐步反解**：
   - 先由 $y = \frac{1-t}{1+t}$ 解出 $t = \frac{1-y}{1+y}$
   - 再由 $t = \sqrt{1+x}$ 解出 $x = t^2 - 1$
4. **代入化简**：将 $t$ 的表达式代入，通分化简

**关键计算步骤**：
$$x = t^2 - 1 = \left(\frac{1-y}{1+y}\right)^2 - 1 = \frac{(1-y)^2 - (1+y)^2}{(1+y)^2}$$

展开分子：
$$(1-y)^2 - (1+y)^2 = (1 - 2y + y^2) - (1 + 2y + y^2) = -4y$$

### 知识点总结

1. **反函数求法**：设 $y = f(x)$ → 解出 $x = g(y)$ → 交换变量得 $y = g(x)$
2. **换元法适用场景**：当函数含有 $\sqrt{ax+b}$ 等根式时，令 $t = \sqrt{ax+b}$ 简化运算
3. **分式反解公式**：由 $y = \frac{a-t}{a+t}$ 可得 $t = \frac{a(1-y)}{1+y}$
4. **完全平方差公式**：$(a-b)^2 - (a+b)^2 = -4ab$
5. **反函数定义域**：反函数的定义域 = 原函数的值域（本题未要求，但需注意）
