# 函数解析式求法 - 换元法/配凑法

> [!question] 题目
> 已知 $f\left(x+\frac{1}{x}\right) = \frac{4x^2}{x^4+1}$，求 $f(x)$。

> [!failure] 我的错误答案
> ```
> 不会写（完全没有思路）
> ```

> [!success] 正确答案
> $$
> f(x) = \frac{4}{x^2 - 2}
> $$

## 错误分析

### 错误原因

**知识盲区** - 不熟悉换元法/配凑法的解题技巧。看到 $f\left(x+\frac{1}{x}\right)$ 这种复合函数形式时，不知道如何将右边的表达式变形为关于 $\left(x+\frac{1}{x}\right)$ 的形式。

### 正确思路

**第一步：转化**
观察已知条件，将等式右边的分子分母**同时除以 $x^2$**：
- 分子：$\frac{4x^2}{x^2} = 4$
- 分母：$\frac{x^4+1}{x^2} = x^2 + \frac{1}{x^2}$

得到：
$$f\left(x+\frac{1}{x}\right) = \frac{4}{x^2 + \frac{1}{x^2}}$$

**第二步：配凑**
利用完全平方公式，将 $x^2 + \frac{1}{x^2}$ 变形：
$$x^2 + \frac{1}{x^2} = \left(x+\frac{1}{x}\right)^2 - 2$$

代入得：
$$f\left(x+\frac{1}{x}\right) = \frac{4}{\left(x+\frac{1}{x}\right)^2 - 2}$$

**第三步：换元**
令 $t = x + \frac{1}{x}$，原式转化为：
$$f(t) = \frac{4}{t^2 - 2}$$

**第四步：得出结论**
将变量 $t$ 替换为习惯的字母 $x$：
$$f(x) = \frac{4}{x^2 - 2}$$

### 知识点总结

1. **配凑法核心思想**：将复合函数 $f[g(x)]$ 的表达式变形为关于 $g(x)$ 的形式
2. **常用技巧**：
   - 分子分母同除某式（如 $x^2$）
   - 利用完全平方公式：$a^2 + b^2 = (a+b)^2 - 2ab$
   - 令 $t = g(x)$ 进行换元
3. **适用场景**：已知 $f[g(x)] = h(x)$，求 $f(x)$
4. **关键公式**：$x^2 + \frac{1}{x^2} = \left(x+\frac{1}{x}\right)^2 - 2$
